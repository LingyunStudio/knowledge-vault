本篇覆盖 Markdown 的**全部常用格式及其变体**，并标注韫玉的渲染支持情况。每节先讲标准写法，再列变体。所有示例右侧或紧随其后为渲染效果。

## 标题

ATX 风格（`#` 开头）是主流写法，`#` 后的空格可省略（不推荐）：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

闭合式 Atx 变体——行尾再补一串 `#`，数量不必与开头一致：

```markdown
## 闭合式二级 ##
### 闭合式三级 #####
```

Setext 风格变体：文字下一行用 `=` 是一级、用 `-` 是二级，`-` 的数量随意：

```markdown
一级标题（Setext）
=================

二级标题（Setext）
------
```

标题可以带**属性**（本软件支持 `{#id}`，部分渲染器还支持 `{.class}`）：

```markdown
## 带锚点的标题 {#custom-anchor}
```

## 段落与换行

- 普通段落：空一行分隔
- **硬换行**（段内强制换行）三种写法：行尾两个以上空格、行尾反斜杠 `\`（Pandoc 变体）、或某些方言里直接单换行（CommonMark 默认合并为一段）

```markdown
第一行（行尾两个空格）  
第二行
```

第三种是行尾反斜杠：

```markdown
第一行\
第二行
```

## 强调

| 写法          | 效果         | 说明      |
| ----------- | ---------- | ------- |
| `*斜体*`      | *斜体*       | 星号      |
| `_斜体_`      | _斜体_       | 下划线     |
| `**粗体**`    | **粗体**     | 星号      |
| `__粗体__`    | __粗体__     | 下划线     |
| `***粗斜体***` | ***粗体斜体*** | 三星      |
| `___粗斜体___` | ___粗斜体___  | 三下划线    |
| `~~删除线~~`   | ~~删除线~~    | GFM 扩展  |
| `==高亮==`    | ==高亮==     | 部分渲染器支持 |

星号和下划线可以混搭：`**粗体中嵌 *斜体***`。想让 `*` 不被解析，用反斜杠转义：`\*不是斜体\*`。

## 划线文字

本软件支持行内高亮与彩色文字的扩展写法（span style）：

```markdown
==高亮文字==
**<span style="color:#2d990f">彩色加粗</span>**
```

## 引用

基础引用：

```markdown
> 这是一段引用。
```

> 这是一段引用。

**多段引用**（每行都加 `>`，或段间只留一个 `>` 空行）：

```markdown
> 第一段。
>
> 第二段。
```

> 第一段。
>
> 第二段。

**惰性引用**（变体：只有第一行需要 `>`，后续行可省略）：

```markdown
> 第一行
第二行也算引用
```

> 第一行
>
> 第二行也算引用

**嵌套引用**：

```markdown
> 外层
>> 内层
> > 另一种空格写法（等价）
```

> 外层
>
> > 内层

**引用内嵌套其它元素**：

```markdown
> ## 引用里的标题
>
> - 列表项一
> - 列表项二
>
> **加粗**也有效。
```

> ## 引用中的标题
>
> - 列表项一
> - 列表项二

**GFM Alert（提示块）**——本软件完整支持的五色提示，是引用的扩展变体：

```markdown
> [!NOTE]
> 有用的补充信息。

> [!TIP]
> 建议与技巧。

> [!IMPORTANT]
> 关键信息。

> [!WARNING]
> 可能出问题的警告。

> [!CAUTION]
> 高风险操作警告。
```

> [!NOTE]
> 有用的补充说明。

> [!TIP]
> 建议与技巧。

> [!IMPORTANT]
> 关键信息。

> [!WARNING]
> 警告内容。

> [!CAUTION]
> 高风险警告。

## 列表

**无序列表**三种符号等价（同一列表内不要混用）：

```markdown
- 星号项
- 减号项
* 加号项
```

- 星号项
- 减号项
- 加号项

**有序列表**：数字后跟 `.` 或 `)`（后者为变体）：

```markdown
1. 第一项
2. 第二项
3) 括号变体
```

1. 第一项
2. 第二项

**嵌套与混合**（子层缩进 2–4 空格）：

```markdown
- 顶层
  - 子项
    1. 有序子项
  2. 回到有序
```

- 顶层
  - 子项
    1. 深层
  - 另一个子项

**任务列表**（GFM）两种状态：

```markdown
- [ ] 未完成
- [x] 已完成
- [X] 大写 X 也行（变体）
```

- [ ] 未完成
- [x] 已完成

**松散与紧凑列表**：项之间空行即为「松列表」，每项渲染为 `<p>`；紧凑列表则没有。项内可续行（缩进对齐）、可含代码块：

```markdown
- 项内续行
  这是同一项的第二段文字。

- 另一项
```

- 项内续行
  这是同一项的第二段文字。

## 代码

**行内代码**：反引号包裹。含反引号时用双反引号（变体）：

```markdown
行内代码 `printf()`
含反引号 ``代码中有`这个字符``
```

**围栏代码块**：三个及以上反引号或波浪线（变体），可标注语言；缩进 4 空格的代码块是另一种变体（本软件推荐围栏）：

````markdown
```python
def hello():
    print("hi")
```

~~~js
console.log("波浪线围栏")
~~~
````

```python
def hello():
    print("hi")
```

围栏可带**元信息**（语言之外的高亮指令、行号等，视渲染器而定）：

````markdown
```rust {highlight=2}
fn main() {}
```
````

## 表格

GFM 表格：竖线分列，第二行用至少三个 `-` 分隔，冒号控制对齐（`:---` 左、`:---:` 居中、`---:` 右；两端都写也合法，是变体）：

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | c |
| 宽列 | 数据 | 123 |
```

| 左对齐 |  居中 | 右对齐 |
| :-- | :-: | --: |
| a   |  b  |   c |
| 宽列  |  数据 | 123 |

**紧凑写法变体**（分隔线最短三个连字符即可，两侧竖线可省略）：

```markdown
左列 | 右列
--- | ---
1 | 2
```

| 左 | 右 |
| - | - |
| 1 | 2 |

单元格内支持行内格式与 `<br>` 强制换行；竖线内容需写成 `\|`。

## 分隔线

以下全部等价（三个以上，`-`、`*`、`_` 均可，中间可加空格）：

```markdown
---
***
- - -
* * *
________
```

## 链接与图片

**行内链接**：

```markdown
[文字](https://example.com)
[带标题](https://example.com "悬停提示")
```

[示例链接](https://example.com)

**自动链接**（尖括号包 URL 是变体，裸 URL 依赖 GFM autolink）：

```markdown
<https://example.com>
https://example.com
```

<https://example.com>

**引用式链接**（同一链接多次出现时更整洁）：

```markdown
见 [CommonMark][cm] 与 [GFM][gfm]。

[cm]: https://commonmark.org
[gfm]: https://github.github.com/gfm
```

见 [CommonMark](https://commonmark.org)。

**内部链接**（本软件内跳转，相对路径）：

```markdown
[软件使用指南](01-software-guide.md)
```

**图片**：链接前加 `!`，支持行内与引用式两种；变体：链接里包图片、图片加尺寸片段（本软件用 `#w=` 持久化宽度）：

```markdown
![替代文字](images/pic.png)
[![可点击的图片](images/pic.png)](https://example.com)
![带宽度](images/pic.png#w=320)
```

## 脚注

引用式脚注（GFM 扩展），注脚标识与定义处数字不必一致：

```markdown
这里有一个注脚[^1]，还有长注脚[^long]。

[^1]: 简短说明。
[^long]: 可以写多段的
    长注脚内容。
```

这里有一个注脚[^1]。

[^1]: 注脚内容像这样渲染在文末。

## 行内 HTML

Markdown 允许内嵌 HTML，本软件支持常用的行内标签（完整 HTML 块级支持有限）：

```markdown
<kbd>Ctrl</kbd> + <kbd>K</kbd>
<u>下划线</u>
<mark>标记</mark>
<sub>下标</sub> <sup>上标</sup>
```

<kbd>Ctrl</kbd> + <kbd>K</kbd>、<u>下划线</u>、<mark>标记</mark>、<sub>下标</sub>、<sup>上标</sup>

## 数学公式

本软件内置 KaTeX。行内用单个 `$`，块级用 `$$`：

```markdown
质能方程 $E = mc^2$，块级公式：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
```

块级公式独立成段渲染。

## 分隔与其它块

**折叠详情**（HTML 语法，本软件支持）：

<details>
<summary>点击展开</summary>

折叠的内容在这里。

</details>

**Callout 与引用混用注意**：`> [!NOTE]` 必须紧跟 `>` 无空行；普通 `>` 是灰色引用，带 `[!TYPE]` 才是彩色提示块。

## 字符转义

以下字符在 Markdown 有特殊含义，需要显示本身时前置反斜杠：

```markdown
\ ` * _ { } [ ] ( ) # + - . ! |
```

反斜杠转义示例：`\*不是强调\*`、`\# 不是标题`、`\| 表格里的竖线`。

小于号和与符号在行内 HTML 场景用 `&lt;` `&amp;` 实体。

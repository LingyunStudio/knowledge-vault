参数估计是「从样本反推总体」的艺术：**用 1000 个样本估计一个比例、用 30 天数据估计一个转化率**——估计的核心不是「给一个数」，而是「给一个数 + 它的可信范围」。本篇讲估计量的评价框架、置信区间的精确解读、以及最大似然估计的直觉。

## 1. 估计量的框架：随机性的两层

```text
术语分层：
估计量（estimator）：估计的「公式/程序」（如 x̄ = Σx/n）—— 它是随机变量！
估计值（estimate）：代入具体样本后的数字 —— 一次实现

评价估计量的两个轴（与 [ML 的偏差方差](../ai/01-ml-overview.md)同构）：
偏差（bias）：估计量的期望与真值的差距（系统偏移）
方差：估计量在不同样本间的波动（不稳定）
好的估计量：偏差小 + 方差小（一致且高效）
```

```python
import numpy as np
true_p = 0.3
samples = [np.random.binomial(100, true_p)/100 for _ in range(10000)]
# samples 的均值 ≈ 0.3（无偏）；samples 的 std ≈ √(0.3·0.7/100) ≈ 0.046（标准误）
# —— 这 10000 个「估计值」的分布就是「估计量的抽样分布」
```

**标准误（SE）= 估计量的标准差**——它是「这个估计有多不稳定」的度量：估计值必须与 SE 一起报告（「转化率 3.2% ± 0.4%」），裸数字是不完整的科学陈述。

## 2. 置信区间：95% 的精确含义

```text
95% 置信区间 [L, U] 的频率派解读：
「重复抽样-构造区间这个流程，95% 的次数会覆盖真值」
⚠️ 不是「真值有 95% 概率在这个区间里」——真值固定、区间随机！（[第 1 篇](01-foundations.md)两派分歧的现场）

构造（大样本/正态近似）：估计值 ± z·SE
  比例：p̂ ± 1.96·√(p̂(1−p̂)/n)
  均值：x̄ ± t·(s/√n)   （小样本用 t 分布——σ 未知由 s 估计的不确定补偿）
```

区间的宽度由三件事决定：**置信水平**（95%→99% 区间变宽——更自信的代价）、**样本量**（√n 收缩——[第 4 篇](04-lln-clt.md)）、**数据本身的波动 σ**。「窄区间」的来源只有：更多数据、更低方差、降低置信要求。

> [!TIP]
> CI 的正确日常用法：**比较两个区间的重叠情况**要谨慎（重叠 ≠ 不显著——重叠判断比正式检验保守），正式比较用差值的区间/检验（[第 6 篇](06-hypothesis-testing.md)）。

## 3. 最大似然估计（MLE）：「最像」的参数

```text
似然函数 L(θ) = P(观察到这些数据 | 参数=θ)
  —— 把「数据的概率」当成「参数的函数」来看

MLE：选让「已观测数据出现概率最大」的 θ
直觉：哪个参数值「最能解释你手里的数据」，就选哪个
```

```python
# 例：10 次抛硬币 7 次正面，估计 p
# L(p) = p⁷(1-p)³ —— 逐点画这条曲线：
# p=0.3 → 小；p=0.7 → 最大（7/10 是自然峰值）；p=0.9 → 又变小
# MLE：p̂ = 7/10 —— 「频率即最大似然估计」（二项分布的通例）
```

MLE 的推导套路（对数似然 → 求导 → 置零）：log 把连乘变连加（[数值稳定性](../linalg/07-numerical.md)）、求导置零找峰值。MLE 的普适地位：**大样本下的理论最优性**（一致、渐近有效、渐近正态）——正态假设的均值/方差估计、逻辑回归（[第 2 篇](../ai/02-linear-models.md)）的训练目标全部是 MLE。

MLE 与最小二乘的连接：**高斯噪声假设下的线性回归，MLE = 最小二乘**（高斯的似然最大 ⇔ 误差平方和最小）——「两条路线在正态假设下会师」（[第 3 篇](../linalg/03-solving-systems.md)的几何 + [第 5 篇](../ai/05-nn-basics.md)的训练目标）。

## 4. 小样本与极端值：估计的诚实

```python
# 比例估计的小样本修正与边界
p̂ = 0/10 的朴素区间（√(p̂(1-p̂)/n) = 0）→ 「区间宽度为 0」显然不对！
# Wilson 区间 / Laplace 加一平滑（(成功+1)/(n+2)）是正确姿势

# 重尾数据的均值估计（[第 2 篇](02-random-variables.md)）：
# Pareto 的样本均值收敛慢、方差可能无限 → 置信区间失效
# → 分位数/极值理论/对数空间估计
```

「估计的诚实」清单：**报告 SE/CI**；**小样本用修正公式**；**重尾不用正态区间**；**多估计并存时说明口径**（中位数 vs 均值）。

## 5. 陷阱清单

- 裸数字报告（无 SE/CI）：不完整的数据陈述；「±」是标配。
- 95% CI 的贝叶斯误读：它是「流程的覆盖性质」不是「单次区间的概率」（[第 7 篇](07-bayesian.md)的后验区间才是后者）。
- 小样本比例用正态近似：p̂ 接近 0/1 或 n 小时失效；Wilson/Laplace。
- 「估计 = 真值」的心态：估计有抽样分布——用 SE 表达不确定。
- MLE 的过拟合倾向（参数多时）：正则化 = 先验（[贝叶斯桥](07-bayesian.md)）。
- 重尾数据的正态 CI：极端值低估（[第 2 篇](02-random-variables.md)）。
- 忽视估计量的偏差来源（选择偏差/幸存者偏差——数据收集层的偏差，统计方法救不了）。

## 6. 小结

- 估计量的两层随机：估计量是随机变量（抽样分布）、估计值是一次实现——SE 是「稳定性的度量」、报告必带。
- 置信区间的精确解读：95% 是「流程的覆盖频率」——区间的宽度由置信水平/n/σ 三因素决定。
- MLE 的直觉「最能解释数据的参数」：对数似然 + 求导；与最小二乘在正态假设下会师。
- 估计的诚实清单：SE/CI 随行、小样本修正、重尾换工具、口径明示。
- 「偏差-方差」的估计量版本与 [ML 同构](../ai/01-ml-overview.md)——统计与 ML 在估计框架上互通。

## 7. 练习

**1.** 抽样分布的实证：真实 p=0.3、n=100，模拟 10000 次估计值的直方图——验证「以 0.3 为中心、std≈0.046 的正态形态」；再画 n=25 与 n=1600 的对比（SE 减半/减半再减半）。

> [!TIP]
> 思路三个直方图并排：宽度按 1/√n 收缩——「SE 的平方根定律」的可视化（[第 4 篇](04-lln-clt.md)）。直方图的整体形状同时演示 CLT。

**2.** 置信区间的频率派验证：模拟「构造 100 个 95% CI」——数一数覆盖真值的次数（应 ≈95）；再故意用错的 σ 构造，看覆盖率崩坏——「95% 是流程性质」的实验证明。

> [!TIP]
> 思路覆盖率的蒙特卡洛检验是「统计方法的单元测试」——任何新方法（bootstrap/贝叶斯区间）都应过这关。覆盖率不足 = 方法有偏。

**3.** MLE 手推：泊松分布的 MLE 推导（λ̂ = 样本均值）——写对数似然、求导、置零三步；再用模拟验证（已知 λ 生成数据，MLE 收敛到它）。

> [!TIP]
> 思路泊松的 log 似然对 λ 的导数 = Σx/λ − n → 置零得 x̄。泊松的「E=Var=λ」使 MLE 恰好是样本均值（[第 2 篇](02-random-variables.md)的身份特征联动）。

**4.** Wilson 区间对比：p̂=0/10、0/100、0/1000 三种「零成功」场景，对比朴素正态区间（退化为 [0,0]）与 Wilson 区间——体会「小样本修正」的必要性。

> [!TIP]
> 思路Wilson 区间在零成功时给出「非零上限」（如 [0, 30%]）——「没观察到失败 ≠ 不存在失败」的统计表达。安全/质量场景的零事故解读同理。

**5.** 重尾估计实验：对 Pareto 数据（α=1.5）的均值做 1000 次独立估计，画估计值的分布——观察「宽且偏」的抽样分布（CLT 失效），并用中位数估计替代。

> [!TIP]
> 思路分布的形状直接告诉你「哪些估计量可用」——CLT 区间在重尾下的覆盖崩坏（[第 4 篇练习 2](04-lln-clt.md)）。

**6.** 讨论：为什么「估计必须带不确定性」在 ML 的「点预测」文化中常被遗忘？从「点预测的隐性自信」「校准的概念（[第 4 篇](../ai/04-evaluation.md)）」「不确定性量化的现代工具（保形预测/贝叶斯）」三个角度分析——「模型说 70%」与「模型说肯定」的信任差异应该如何建立？

> [!TIP]
> 思路ML 的预测同样应带不确定度（概率输出 + 校准检验）——「预测的诚实」与「估计的诚实」是同一纪律。保形预测（conformal prediction）把「分布无关的覆盖保证」带入 ML——统计学的不确定性思想对 ML 的回流。

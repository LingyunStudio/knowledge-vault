前面所有章节都是"一次实验"的概率，随机过程把时间轴拉进来：**一族随时间演化的随机变量**。股价、页面浏览路径、排队长度、系统故障——凡是"下一步取决于现在的状态"的世界，都是它的领地。

## 马尔可夫链：只记现在，忘记历史

马尔可夫性（无记忆性）：**未来只依赖当前状态，与更早的历史无关**：

```text
P(X_{t+1} = j | X_t = i, X_{t-1}, …) = P(X_{t+1} = j | X_t = i)
```

链条由两件东西完全定义：**状态空间** + **转移矩阵 P**（P[i][j] = 从 i 一步到 j 的概率，每行和为 1——这就是一个随机矩阵，第 linalg 05 篇的呼应）。

```python
# 天气链：晴/雨 的转移矩阵，预测三天后
import numpy as np
P = np.array([[0.9, 0.1],
              [0.5, 0.5]])          # P[i][j]: i→j
dist_3 = np.array([1.0, 0.0]) @ (P @ P @ P)   # 今天晴，三天后？
```

## 平稳分布：演化会停在哪里

平稳分布 π 满足 πP = π——再转移一步，分布不再变化。关键定理（遍历性）：**不可逆（状态互通）且非周期的链，从任何初始分布出发都收敛到唯一的平稳分布**——初始条件被遗忘，长期行为由 P 决定。

回到线代视角：π 是 P 的**特征值 1 对应的左特征向量**（随机矩阵最大特征值必为 1）。三个标志性应用：

- **PageRank**：网页随机游走链的平稳分布 = 每页权重（加"传送"项保证不可逆）
- **MCMC**（第 07 篇）：反着用——设计一条平稳分布 = 目标后验的链，靠收敛"采样"
- **用户留存/状态机**：活跃-流失-召回链的平稳分布，就是产品的长期用户结构

## 泊松过程：事件到达的标准模型

计数过程 N(t)（到 t 时刻累计发生的事件数）若满足：独立增量、单位时间期望 λ、瞬时多事件概率趋零——就是强度 λ 的泊松过程。三条性质把工程问题都接住了：

1. **N(t) ~ Poisson(λt)**：单位时间到达数服从泊松分布（请求量、故障数）
2. **间隔时间 ~ Exp(λ)**：相邻事件的等待时间服从指数分布——"下一个请求还要等多久"
3. **无记忆性**：等待时间不因已经等了多久而改变——指数分布独有的性质

计数与间隔是同一枚硬币的两面，这一对组合是**排队论**的地基：M/M/1 队列（泊松到达 + 指数服务 + 单窗口）的队长期望 = ρ/(1−ρ)，ρ = λ/μ（到达率/服务率）——**ρ → 1 时队长爆炸**，这就是"系统接近满载时延迟急剧恶化"的数学解释，容量规划的基本盘。

## 赌徒破产：吸收链的经典课

有限资金赌公平游戏，几乎**必然**破产（输光 absorption），期望坚持时间却可以很长——"久赌必输"不是玄学：对有抽水的赌局（不公平链），期望资金单调衰减，破产是唯一的平稳结局。吸收链分析（吸收概率、期望吸收时间）是这类"终局问题"的标准工具。

> [!WARNING]
> 套马尔可夫模型前先检查马尔可夫性是否成立——**当前状态要包含全部相关信息**（天气链里"连续下雨几天"有影响，就得把状态扩成（天气, 已连雨天数））。状态设计是随机过程建模的全部艺术：状态对了，后面只是算矩阵。

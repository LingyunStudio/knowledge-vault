概率论里有两条定理撑起了整个统计学的天空：**大数定律（LLN）说"平均下来会稳"**，**中心极限定理（CLT）说"稳的形状是正态"**。一个回答"均值靠不靠谱"，一个回答"误差有多大"。

## 大数定律：均值收敛于期望

同分布独立地重复观测，样本均值随 n 增大收敛于期望 E[X]：

```text
掷骰子：前 10 次平均可能是 3.2，前 100 次可能 3.6，
        前 10 万次——几乎必然贴在 3.5 附近
```

两个必须纠正的直觉：

- **LLN 不靠"长期平衡"**：赌徒谬误认为"输久了该赢了"——错。硬币没有记忆，是**大数把早期的运气稀释掉**（10 万次里前 20 次占比可忽略），不是"命运会找平"
- 收敛的是**均值**不是**总和**：总金额的波动越来越大（方差线性涨），靠的是基数更大才显得稳

> [!TIP]
> 检验"大数定律适用性"的关键前提是**期望存在**。重尾分布（幂律，如部分社交网络度分布）期望都不存在，均值永远不收敛——平均在线时长这类指标在长尾业务里可能毫无意义，先看分布再算均值。

## 中心极限定理：正态的诞生机制

**独立同分布、方差有限的**随机变量之和（标准化后）趋近正态——**无论单个变量是什么分布**。

```python
# 亲手让 CLT 发生：掷骰子（完全非正态）的均值
import numpy as np
means = [np.random.randint(1, 7, 50).mean() for _ in range(10000)]
# 10000 个"50 次掷骰子的平均"——直方图是漂亮的钟形
```

这就是正态分布无处不在的原因：**只要结果由大量独立小因素叠加而成**（测量误差、身高 = 基因+营养+环境…），不必知道每个因素的分布，和就近似正态。正态不是"造物主的偏好"，是叠加机制的必然形状。

CLT 的定量版直接给出工程公式：

```text
样本均值 ~ Normal(μ, σ²/n)      →  标准误 SE = σ/√n
95% 置信区间 ≈ 均值 ± 2·σ/√n
```

**精度只按 √n 变好**：误差减半要 4 倍样本——这是所有实验设计的成本底线。

## 蒙特卡洛：用 CLT 的定理反过来做计算

CLT 保证模拟平均值的误差 ∝ σ/√n，于是"**随机采样求平均**"成了通用数值方法：

```python
# 蒙特卡洛估计 π：随机撒点看落在四分之一圆的比例
import numpy as np
pts = np.random.uniform(0, 1, (10**6, 2))
pi ≈ 4 * ((pts**2).sum(1) <= 1).mean()     # 误差 ~ 1/√n，与维度无关！
```

它的杀手锏是**误差与维度无关**——高维积分（定价、贝叶斯后验、期望计算）解析方法全灭时蒙特卡洛照常工作，代价只是更多采样。

## 两者的分工

- **LLN**：回答"均值的极限是多少"——存在性问题，蒙特卡洛的理论根基
- **CLT**：回答"当前估计离极限多远"——误差条、置信区间、AB 检验（第 06 篇）的数学引擎

> [!NOTE]
> 二者都要求独立性。时间序列、用户行为流普遍**自相关**（今天的量影响明天），n 条样本的实际信息量小于 n——有效样本量缩水，置信区间要相应放宽。分析相关数据前，先估自相关。

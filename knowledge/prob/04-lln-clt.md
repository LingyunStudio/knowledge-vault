概率论的两大支柱定理分工明确：**大数定律（LLN）保证「平均值的收敛」**（多测几次就靠谱），**中心极限定理（CLT）描述「收敛过程中的波动规律」**（波动多大、什么形状）。前者是模拟与实验的合法性来源，后者是置信区间与假设检验的引擎（[第 5、6 篇](05-estimation.md)）。

## 1. 大数定律：平均值终将稳定

```text
大数定律：独立同分布的样本均值 X̄ₙ = (X₁+…+Xₙ)/n
          当 n → ∞ 时收敛到期望 E[X]

赌场视角：庄家优势（期望为负）在单局不可见，
          在百万局的平均中必然显现 —— 大数定律是赌场的商业模式
模拟视角：蒙特卡洛估计的合法性 —— 模拟 10 万次取平均 ≈ 期望（误差随 √n 缩小）
```

```python
import numpy as np
rolls = np.random.randint(1, 7, size=1_000_000)
means = np.cumsum(rolls) / np.arange(1, len(rolls)+1)
# 画出 means 的轨迹：初期剧烈震荡，逐渐「咬住」3.5 —— LLN 的可视化
```

LLN 的两个工程读法：**「样本均值的可靠性随 n 增长」**（但注意——收敛的是均值，不是分布；重尾分布的均值可能收敛极慢甚至不收敛，[第 2 篇](02-random-variables.md)）；**「单次结果不可预测、长期统计可预测」**——这就是为什么保险业、赌场、A/B 测试能工作。

## 2. 中心极限定理：波动的形状

```text
CLT：独立同分布的 X₁,…,Xₙ（任意分布！只要方差有限）
     样本均值 X̄ₙ 的分布，在 n 足够大时 ≈ Normal(E[X], σ²/n)

标准误（SE）= σ/√n                 —— 「样本均值的 std」
关键读法：均值的波动随 √n 缩小 ——
  n 大 4 倍 → 精度只提高 2 倍（平方根定律：边际收益递减）
```

CLT 的震撼在于「**对任意原始分布**」：哪怕 X 是掷硬币的 0/1、甚至是二项/指数/Pareto——它们的**均值**在 n 大后都趋于正态。这就是「**为什么正态无处不在**」：现实中的测量值几乎都是「大量微小独立扰动的总和」（身高=基因+营养+…的总和），总和服从 CLT。

```python
# CLT 模拟：掷骰子均值的收敛
means = [np.random.randint(1,7,n).mean() for n in [1]*1000] + ...  
# 画 n=1/2/5/30 时「样本均值的直方图」：n=1 是骰子形状（均匀阶梯）
# → n=5 出现钟形雏形 → n=30 几乎完美正态 —— 「正态化」的过程可视化
```

n=30 的经验法则（「30 就够正态」）的适用边界：**原始分布较对称、方差有限**时大致成立；重尾分布（[第 2 篇](02-random-variables.md)）需要大得多的 n（甚至不可用）。

## 3. 标准误的应用：从波动到推断

```text
样本均值的 95% 区间（CLT 近似）：X̄ ± 2·(σ/√n)
  解读：「真实的 μ 有 95% 的概率落在这个区间」（[第 5 篇](05-estimation.md)的频率派解读细节）

A/B 测试的核心公式（两均值差的 SE）：
SE = √(σ₁²/n₁ + σ₂²/n₂)
差异是否显著 = 差值 与 SE 的比较（[第 6 篇](06-hypothesis-testing.md)的 t 检验本质）
```

√n 定律的三个工程推论：

1. **精度减半需要 4 倍样本**——样本量的成本曲线是平方级的。
2. **提高精度靠降低 σ**（更好的测量/分层）与 **n** 同等重要——设计实验优于堆样本。
3. **A/B 测试的样本量公式**就是从 SE 与最小可检测效应反推——「跑多久才能看出 2% 提升」的答案来自这里。

## 4. CLT 的失效条件：什么时候正态假设会背叛你

```text
CLT 的前提：
① 独立（或弱相关）—— 强相关序列（时间趋势）的均值收敛行为不同
② 方差有限 —— ★ 重尾分布（[第 2 篇](02-random-variables.md)的 Pareto）方差无限 → CLT 失效
                       （样本均值的波动不缩小，极端值主导一切）
③ n 相对原始分布足够大 —— 极偏/双峰分布需要更大的 n
```

重尾数据的现实场景（[第 2 篇](02-random-variables.md)）：网页响应时间、收入、文件大小——**用正态假设的「均值±2σ」区间管理这些数据会系统性低估极端事件**。「样本均值的分布正态」与「数据本身正态」是两回事——CLT 给前者保证、不改变后者。

## 5. 陷阱清单

- 把 LLN 读成「短期会回归均值」：赌徒谬误——LLN 说的是大数平均，不是「欠账补偿」（[第 2 篇](02-random-variables.md)）。
- 「n=30 就正态」当铁律：重尾/强相关需要更大 n 或非参方法；看原始分布的形态。
- 忽略 σ：比较均值不看 SE——「差异」可能小于噪声（[第 6 篇](06-hypothesis-testing.md)）。
- √n 定律的线性误用（「样本翻倍精度翻倍」）：平方根定律——翻倍只提升 √2 倍。
- 时序数据的均值波动当独立样本：自相关让有效样本量缩水（SE 低估）。
- 重尾数据用 CLT 置信区间：极端事件的概率被低估几个量级（[第 2 篇](02-random-variables.md)）。
- 蒙特卡洛不加误差估计：模拟结果没有 SE 就是「没有完成模拟」。

## 6. 小结

- LLN 保收敛（均值→期望）：模拟与实验的合法性；「长期可测、单次不可测」。
- CLT 保形状（均值的分布→正态）：对任意方差有限的分布成立——「正态无处不在」的机制。
- 标准误 σ/√n 与平方根定律：精度翻倍要 4 倍样本——「降 σ 与增 n 同价」的实验设计观。
- CLT 的失效条件：重尾/强相关/小 n——正态假设的失效检查清单。
- A/B 与置信区间的引擎都是 CLT；重尾场景换工具（分位数/极值/非参）。

## 7. 练习

**1.** LLN 轨迹可视化：模拟掷骰子的累计均值曲线（10⁶ 次，log 横轴），观察「收敛到 3.5 但路径有波动」；再切 10 段各画一条——「不同实验路径」的波动幅度对比。

> [!TIP]
> 思路路径间的波动 = 均值估计的「抽样噪声」——单次实验的路径不保证单调逼近。「收敛」是渐近性质，不是「到某点就稳了」。

**2.** CLT 可视化：对「掷骰子」「指数分布」「Pareto(重尾)」三个原始分布，分别画「样本均值在 n=1/10/100/1000 的直方图」——前两个正态化、Pareto 拒绝正态化（方差不存在的威力）。

> [!TIP]
> 思路Pareto（α≤2）的样本均值直方图「越测越宽」——CLT 的方差有限前提被击穿。重尾识别（[第 2 篇](02-random-variables.md)）是 CLT 应用的前置检查。

**3.** 平方根定律的成本实验：估计一个 1% 比率的可信精度（SE），分别计算「精度要 ±0.1% 与 ±0.05%」各需多少样本——验证「减半精度 = 4 倍样本」，再算成真金白银的实验成本。

> [!TIP]
> 思路样本量 ∝ 1/精度² 的成本爆炸——「实验设计（降方差：分层/配对/更敏感的指标）优于堆流量」的定量依据（[第 6 篇](06-hypothesis-testing.md)）。

**4.** 自相关的有效样本量实验：生成一个强正相关的时序序列（AR(1)），对它计算「朴素的 CLT 置信区间」与「考虑自相关的修正区间」——验证朴素 SE 的低估程度。

> [!TIP]
> 思路自相关让「n 个样本的信息 < n」——有效样本量 = n/(1+2Σρₖ)。时序 A/B、监控指标的均值判断都需要这个修正（[时间序列的独立性审计](../linux/11-ops-pitfalls.md)）。

**5.** 蒙特卡洛的完整实践：用模拟估计 π（随机点落圆内的比例）——报告估计值 + CLT 置信区间 + 达到 ±0.001 精度所需样本量预测——「模拟必须带误差棒」的完整示范。

> [!TIP]
> 思路蒙特卡洛报告的规范：估计值 ± SE（来自 CLT）、与目标精度的样本量预算——「模拟一次出个数」与「模拟一个可信区间」是工程与玩具的分界。

**6.** 讨论：为什么「赌徒谬误」与「热手谬误」在人类中如此顽固，而 LLN 的正确理解恰恰要求「无记忆的平均」？从「均值回归的误读」（LLN 说大数收敛，不是说偏离后必须立刻补回）与「小样本模式的过度解读」分析，并对照 [方差可加的条件](03-joint-conditional.md)——「独立性」的直觉训练为什么比公式更重要？

> [!TIP]
> 思路两类谬误的共同根：「把随机过程的局部模式读成趋势或欠账」。LLN 的时间尺度是「渐近」——短期没有任何「回归义务」。训练方法：模拟体验（[练习 1](01-foundations.md)）+ 假值表式的「独立性审计」习惯——直觉的矫正靠反复的对撞。

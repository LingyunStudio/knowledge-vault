马尔可夫链是「**只依赖当前状态**」的随机演化模型：下一个状态的概率只由当前状态决定，与更早的历史无关（马尔可夫性质）。这个「无记忆」的简化让复杂的随机过程变成**一个矩阵的反复乘法**——PageRank、排队系统、MCMC 的共同内核。

## 1. 马尔可夫性质与转移矩阵

```text
马尔可夫性质：P(下一状态 | 全部历史) = P(下一状态 | 当前状态)
  「知道现在，过去就多余了」

转移矩阵 P：P[i][j] = 从状态 i 转到 j 的概率
  每行和为 1（离开 i 的概率总和是 1）

天气例子：晴/雨两状态
      晴   雨
晴 [ 0.9  0.1 ]        → 明天晴的概率只看今天晴或雨
雨 [ 0.4  0.6 ]
```

马尔可夫性质是**建模假设**而不是事实：「下一状态只依赖当前」在哪些场景近似成立（页面浏览/排队长度/棋局）——用历史信息能显著改善预测时（如用户行为有周期性），需要增广状态（把「上一状态」也纳入「当前」）或放弃马尔可夫假设。

## 2. 多步演化：矩阵的幂

```text
两步转移概率：P² [i][j] = Σₖ P[i][k]·P[k][j]
  （先到某中间状态 k 再到 j 的全路径求和）

P^n：n 步后的转移矩阵 —— 概率分布的演化 = 初始分布向量 × Pⁿ
```

```python
import numpy as np
P = np.array([[0.9, 0.1], [0.4, 0.6]])
dist = np.array([1.0, 0.0])              # 从晴天开始
for _ in range(50):
    dist = dist @ P                       # 分布逐步演化
# dist → [0.8, 0.2]：与初始状态无关！—— 平稳分布
```

「分布向量 × 转移矩阵」的反复迭代就是 [LLM 的嵌入空间](../llm/02-tokenizer-embedding.md)之外的另一种「状态演化」——**每步都是矩阵乘法**（[线性代数](../linalg/02-matrices.md)），收敛行为由矩阵的谱（[第 5 篇](../linalg/05-eigen.md)）决定。

## 3. 平稳分布：长期的归宿

```text
平稳分布 π：π = π·P   （分布不再变化的状态）
  几何：演化到达「不动点」——每个状态流入与流出平衡

收敛条件（遍历性）：不可约（任何状态可达任何状态）+ 非周期
  → 无论从哪开始，长期都收敛到唯一的平稳分布 π

平稳分布的求法：解 π·P = π（特征值 1 的左特征向量，[第 5 篇](../linalg/05-eigen.md)）
```

```python
vals, vecs = np.linalg.eig(P.T)         # 左特征向量 = P.T 的右特征向量
i = np.argmin(np.abs(vals - 1))          # 特征值 1 的位置
pi = np.real(vecs[:, i]); pi /= pi.sum() # 归一化 → 平稳分布 [0.8, 0.2]
```

**PageRank 的数学本质**：把「网页链接」建模为转移矩阵（沿着链接随机跳转）——平稳分布 = 「长期浏览中各网页的驻留比例」= **网页的重要性**。「被越多重要页面链接的页面越重要」由「π = π·P」的平衡方程自动实现（[第 5 篇练习 3](../linalg/05-eigen.md)的完整故事）。

### 3.1 MCMC：把平稳分布当算法用

```text
MCMC（[第 7 篇](07-bayesian.md)）的反向思维：
贝叶斯：有转移矩阵 → 求平稳分布（PageRank）
MCMC：想要某个目标分布 → 设计一个「以它为平稳分布」的转移规则
  → 随机游走的长期驻留频率 = 目标分布（复杂后验的采样）
```

MCMC 是马尔可夫链理论最漂亮的反向应用：**构造问题而不是解问题**——Metropolis-Hastings 的接受规则保证「构造的链以目标后验为平稳分布」。「马尔可夫链 + 平稳分布」的同一套数学服务「搜索排名」与「贝叶斯采样」两个世界。

## 4. 应用与边界

| 应用               | 状态是什么                 | 平稳分布的意义            |
| ------------------ | -------------------------- | ------------------------- |
| PageRank           | 当前浏览的网页             | 各网页的重要性            |
| 排队系统           | 系统中的顾客数             | 稳态的负载（平均排队长度）|
| MCMC 采样          | 游走者当前位置             | 目标后验分布              |
| 用户状态建模       | 用户的活跃/流失状态        | 长期留存/流失比例          |
| 隐马尔可夫（HMM）  | 隐藏状态 + 可观测发射      | 状态的隐式演化（语音/基因）|

马尔可夫建模的边界检查：**「无记忆假设」是否成立**——用户行为的周期性（时间依赖）、状态的路径依赖（信用历史）需要增广状态（把时间/历史编码进状态）——状态设计是马尔可夫建模的核心自由度。

## 5. 陷阱清单

- 马尔可夫假设的盲目应用：历史依赖的系统用无记忆链（预测精度受限）；状态增广。
- 非遍历链求平稳分布（吸收态/多连通分量）：收敛不唯一或不存在；检查不可约与非周期。
- 状态空间爆炸：把「过多历史」塞进状态；维度与数据的权衡。
- 转移矩阵的行/列方向混淆（行随机 vs 列随机）：PageRank 的经典实现坑；先定约定。
- 平稳分布当「快照分布」：平稳是「长期极限」，短期仍按初始条件演化（[第 2 节]的演化过程）。
- 吸收态的忽视（流失状态一旦进入永不离开）：长期全在吸收态——用户流失模型的正确形态。

## 6. 小结

- 马尔可夫性质「未来只依赖现在」：把随机过程简化为转移矩阵的反复乘法——状态设计与无记忆假设的成立性是建模核心。
- 多步演化 = 矩阵幂；平稳分布 π = πP = 长期归宿——收敛需要遍历（不可约+非周期）。
- PageRank = 链接转移矩阵的平稳分布；MCMC 反向构造「以目标分布为平稳」的链——同一数学的两个方向。
- 应用谱系（排名/排队/采样/状态建模）共享「状态 + 转移 + 平稳」的骨架；HMM 扩展隐藏状态。
- 边界检查：无记忆假设、状态空间规模、吸收态——建模假设的显式审计。

## 7. 练习

**1.** 天气链实验：两状态天气链（本篇第 1 节），分别从「全晴」「全雨」「均匀」三个初始分布迭代 50 步——验证「殊途同归」到同一平稳分布（遍历性的实验）。

> [!TIP]
> 思路三条件初始分布的收敛轨迹（初始不同、长期相同）——平稳分布的「吸引力」。再构造一个「吸收态」链（如 0.99 概率留雨）验证收敛到吸收态。

**2.** PageRank 手工版：4 个页面的小链接图（含一个悬挂页面）构造 Google 矩阵（阻尼 0.85），迭代求平稳分布——对比无阻尼版本（悬挂页问题导致概率泄漏）——阻尼的作用实验化。

> [!TIP]
> 思路阻尼（0.85 沿链接 + 0.15 均匀跳转）的双重作用：修复悬挂页的概率泄漏 + 保证不可约（全网可达）→ 收敛性保证。「工程修补」在数学上的必要性。

**3.** 排队模型：单服务台的马尔可夫链（状态=排队人数，到达 λ、服务 μ），求平稳分布与平均排队长度——验证 λ<μ 才有平稳分布（λ≥μ 队伍发散）——「负载与稳定」的边界。

> [!TIP]
> 思路λ<μ 是「稳定条件」：服务速度跟不上到达 → 无平稳分布（队伍无界）——系统容量规划的第一公式（利用率 ρ=λ/μ<1）。排队论（M/M/1）的入门体验。

**4.** 用户状态建模：月活产品的「新活/活跃/沉默/流失」四状态转移矩阵（从历史数据估计），计算平稳分布解读长期用户结构；再加「召回活动」改变转移矩阵的 what-if 分析。

> [!TIP]
> 思路从数据估计转移矩阵（频数归一化）→ 平稳分布 = 「产品如果没有增长、自然演化的最终形态」——what-if（改转移概率）是马尔可夫模型的策略沙盘。

**5.** HMM 一瞥：用 hmmlearn（或手写前向算法）对一个「隐藏情绪 + 可观测表情」的迷你序列做状态推断——理解「隐藏状态的马尔可夫演化 + 观测的发射」两层结构。

> [!TIP]
> 思路HMM = 马尔可夫链（状态演化）+ 观测（发射概率）——前向算法做「观测下的状态概率」推断。语音识别/基因序列的经典模型——「可见不可知」的建模范式。

**6.** 讨论：马尔可夫假设「遗忘历史」看似信息损失，为什么反而是强大的建模武器？从「状态设计的自由度（把必要历史编码进状态）」「计算的可处理性（矩阵幂 vs 全路径）」「平稳分布的理论红利」三个角度分析，并讨论「现代深度学习（RNN/LSTM 的隐状态，[ai 篇](../ai/07-sequence-attention.md)）如何延续马尔可夫思想」。

> [!TIP]
> 思路RNN 的隐状态就是「学习的马尔可夫状态」——把历史压缩进一个向量（状态设计的神经化）；马尔可夫假设的力量在「状态足够丰富时，现在确实概括了历史」——模型的容量与马尔可夫假设的互补。

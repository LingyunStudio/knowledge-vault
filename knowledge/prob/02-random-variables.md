随机变量是「**给每个随机结果标一个数字**」的映射——它把「事件」变成「可以计算的对象」。分布则是随机变量的「性格档案」：哪些值常见、哪些罕见、围绕什么中心、散布多宽。选对分布 = 找到「生成你数据的那个过程」的数学指纹。

## 1. 随机变量与三种描述

```text
随机变量 X：Ω → 数字 的映射（掷两硬币的正面数：0/1/2）

三种描述（离散 PMF / 连续 PDF / 通用 CDF）：
PMF（离散）：P(X=k)          如 P(正面数=1)=0.5
PDF（连续）：f(x)，P(a<X<b)=∫f(x)dx   ⚠️ 连续变量的单点概率恒为 0！
CDF（通用）：F(x)=P(X≤x)      —— 最稳的描述（离散连续通吃，单调右连续）
```

「连续变量单点概率为 0」的直觉障碍：概率密度不是概率——**f(x) 是「每单位长度」的概率浓度**（像质量密度不是质量）。P(X=精确值) 问「无限小区间装了多少概率」→ 0。实际中「正好等于某值」的查询都是「±ε 区间」。

## 2. 期望与方差：中心与散布

```text
期望 E[X] = Σ x·P(x)  或  ∫x·f(x)dx     —— 长期平均（加权重心）
方差 Var(X) = E[(X−E[X])²] = E[X²]−(E[X])²  —— 相对期望的散布（平方惩罚）
标准差 σ = √Var                          —— 与原值同单位（可读性好）

性质（可推导，不必背）：
E[aX+b] = aE[X]+b        线性变换直接缩放中心
Var(X) = Var(aX+b) → a²Var(X)    缩放平方影响散布、平移不影响
E[X+Y] = E[X]+E[Y]       ★ 恒成立（无需独立！）
Var(X+Y) = Var(X)+Var(Y)   仅当独立（或协方差为 0）
```

「期望的可加性无需独立」与「方差的可加性需要独立」——这一对差异是高频错误。期望的解释边界：**期望是长期平均，不是「最可能出现的结果」**（彩票的期望为负但每次结果都是整数金额；「平均 2.5 个孩子」没有对应实体）。

## 3. 六大分布的性格档案

| 分布         | 描述的过程                       | 参数         | 关键事实                      |
| ------------ | -------------------------------- | ------------ | ----------------------------- |
| Bernoulli(p) | 单次成败                          | p            | E=p, Var=p(1−p)               |
| Binomial(n,p)| n 次独立成败的总成功数             | n, p         | 成功数相加；np 为均值          |
| Poisson(λ)   | 单位时间的稀有事件计数             | λ            | E=Var=λ（方差=均值是身份特征） |
| Uniform(a,b) | 区间内均匀散布                    | a, b         | 「无信息」的默认形状           |
| Exponential(λ)| 独立事件间的等待时间              | λ            | 无记忆性（等了多久都像重新开始）|
| Normal(μ,σ²) | 大量独立扰动之和                  | μ, σ²        | CLT 的极限形态（[第 4 篇](04-lln-clt.md)）|

「分布 = 过程的指纹」：**计数稀有事件 → Poisson（客服电话/服务器错误）、等待时间 → Exponential（无记忆性是指数的独门标志）、多次独立成败 → Binomial**。选分布的流程：先问「数据怎么生成」（离散/连续？计数/测量？独立吗？有没有上限？）。

### 3.1 无记忆性：指数分布的独特标志

```text
P(X > s+t | X > s) = P(X > t)
等了 1 小时没等到公交车 → 还要等的时间分布 = 从头开始的分布
（真正「无记忆」的过程——灯泡老化就违反它，放射性衰变满足它）
```

无记忆性是「指数分布 vs 其他寿命分布」的分水岭：你的排队/故障建模要不要它，决定了选 Exponential 还是 Weibull/Gamma。

## 4. 变量变换与雅可比

```text
Y = g(X) 的分布：CDF 法（F_Y(y) = P(g(X) ≤ y)）或 PDF 法
连续情形：f_Y(y) = f_X(g⁻¹(y)) · |dg⁻¹/dy|
                                    ↑ 雅可比：变换的局部缩放（[线性代数](../linalg/04-determinant.md)）
例：X~Uniform(0,1)，Y = −ln(X) ~ Exponential(1)   （均匀 → 指数的生成技巧）
```

变量变换是「**分布的加工流水线**」：从 Uniform(0,1) 可以生成任何分布（逆变换采样——[随机数生成的原理](../python/02-data-model.md)）；雅可比因子在多变量下是行列式（[第 4 篇](../linalg/04-determinant.md)的面积缩放）。变换后的「支撑集」（取值范围）变化是手算的高频错误点。

## 5. 陷阱清单

- 连续变量用 PDF 值当概率：f(x) 可以 >1（密度不是概率）；用 CDF 差值。
- 期望当「典型值」：偏态分布（收入/响应时间）的期望被长尾拉偏；中位数/分位数补充。
- 方差可加性忘独立前提：相关变量的和要加协方差项（[第 3 篇](03-joint-conditional.md)）。
- 独立事件的重复独立性（「连开三次反面后该出正面了」）：赌徒谬误——无记忆过程没有「欠账」。
- 分布选择不问生成过程：先答「数据怎么来的」再选族；拟合优度检验兜底。
- 支撑集错误（变换后取值范围/指数分布的 x≥0）：PDF 的定义域核查。
- 用正态分布描述一切：重尾数据（网页延迟/收入）的正态假设会让「极端值概率」被低估几个量级（[第 4 篇](04-lln-clt.md)的中心极限条件）。

## 6. 小结

- 随机变量把事件数字化；PMF/PDF/CDF 三描述中 CDF 最通用；连续变量的密度不是概率。
- 期望是长期平均（非典型值）、方差是散布；「期望恒可加、方差可加需独立」的成对纪律。
- 六大分布是六大过程的指纹：计数（Binomial/Poisson）、等待（Exponential 的无记忆性）、求和极限（Normal）、无信息（Uniform）。
- 变量变换是分布的加工：CDF 法/雅可比；支撑集变化是手算高频坑。
- 选分布 = 识别数据的生成过程——「过程 → 指纹」而不是「形状像什么」。

## 7. 练习

**1.** 分布识别练习：给五个真实场景（网站每分钟请求数/一页 500 字的错别字数/公交等待时间/100 次投放的点击数/车间零件尺寸），各选一个分布并说明「生成过程」的匹配理由。

> [!TIP]
> 思路：请求数→Poisson（到达独立稀有）、错别字→Poisson/Binomial（n=500 有限）、等待→Exponential、点击→Binomial、零件尺寸→Normal（大量扰动之和）。判据是「过程」不是「直方图像」。

**2.** 期望 vs 中位数的实验：模拟 Pareto/对数正态分布（重尾收入）的 10 万样本，对比均值与中位数——验证「期望被长尾劫持」，并计算「需要多少样本均值才稳定」。

> [!TIP]
> 思路重尾分布的样本均值收敛极慢（方差可能不存在！）——「均值没意义」的分布族（收入/城市规模/文件大小）。 reporting 用中位数与分位数。

**3.** 无记忆性验证：模拟 Exponential(λ) 的到达间隔，检验「等了 s 之后剩余时间」的分布与「从头开始」是否一致（条件概率的模拟验证）。

> [!TIP]
> 思路模拟条件分布：先抽出 >s 的样本、再看它们的分布形状——与原始分布重合即无记忆。对照正态分布做同款实验（不重合）——无记忆性是指数的专属签名。

**4.** 变量变换练习：从 Uniform(0,1) 出发，用逆变换法生成 (a) 指数分布 (b) 任意离散分布——画出直方图与理论 PDF/PMF 对齐。理解「随机数生成器的原理层」。

> [!TIP]
> 思路逆变换：U~U(0,1)，X = F⁻¹(U) 服从 F——CDF 反函数是「均匀到目标」的映射（[python random](../python/02-data-model.md) 的底层原理）。离散版是累积概率的区间查找。

**5.** 方差可加性实验：生成两个**相关**的正态样本（相关系数 0.8），验证 Var(X+Y) = Var(X)+Var(Y)+2·Cov(X,Y)（不是简单相加）——「协方差项」的实证（[第 3 篇](03-joint-conditional.md)）。

> [!TIP]
> 思路np.cov 计算协方差矩阵后手工组装——正相关让和的方差**大于**分量和（同向波动叠加）。投资组合分散化的数学根基（负相关减方差）。

**6.** 讨论：为什么「重尾分布」在互联网时代越来越重要（响应时间/流量/收入）？从「中央极限定理的前提（有限方差/独立轻尾）」分析「正态假设失效」的场景特征，并说明「用正态假设管理重尾风险」为什么会系统性低估极端事件（[第 4 篇](04-lln-clt.md)的 CLT 条件预演）。

> [!TIP]
> 思路重尾（幂律）的极端值概率比正态大几个量级——「百年一遇」年年遇的事故模式。识别信号：log-log 图直线、样本均值不稳定、最大值远超均值多倍。应对：分位数/极值理论/压力测试替代「均值±3σ」。

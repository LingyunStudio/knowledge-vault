随机变量是把"随机实验的结果"变成数的函数。分布则是这个数的取值规律——**概率论的核心工作方式：把问题翻译成分布，在分布上推导，而不是盯着一个一个样本**。本篇给出这套语言的词汇表。

## 三种"分布"：PMF、PDF、CDF

- **PMF（离散）**：P(X = k)，质量集中在点上（掷骰子、点击次数）
- **PDF（连续）**：密度函数 f(x)，**单点概率恒为 0**，只有区间才有概率 ∫f dx；值高只表示"附近容易落"
- **CDF**：F(x) = P(X ≤ x)，两种类型统一、单调、右连续——比较与计算时最好用的形式，P(a < X ≤ b) = F(b) − F(a)

> [!WARNING]
> PDF 的高度不是概率。正态密度在 0 处约 0.4，不意味着 40% 概率取 0——概率永远是**曲线下面积**。这个误解在连续型问题里出现率接近 100%。

## 期望与方差：分布的一维摘要

```text
E[X]  = Σ k·P(X=k)          长期平均（加权中心）
Var(X) = E[(X−E[X])²]        波动大小
SD = √Var                    与原值同量纲
```

两条最有用的运算法则（对任意随机变量都成立，无需独立）：

```text
E[aX + bY] = aE[X] + bE[Y]                 期望线性
Var(X + Y) = Var(X) + Var(Y) + 2Cov(X,Y)    独立时协方差项消失
```

由此立刻得到两个工程结论：**n 个 iid 的均值方差 = σ²/n**（平均能降噪，样本越多越稳）；**保险/赌场/平台的盈利靠大数**（第 04 篇大数定律把"长期平均"变成定理）。

## 常见分布速查

| 分布 | 建模什么 | 关键参数 | 备注 |
| --- | --- | --- | --- |
| 伯努利 | 一次成功/失败 | p | 一切的砖块 |
| 二项 | n 次独立试验的成功数 | n, p | E=np, Var=np(1−p) |
| 泊松 | 单位时间事件数（低频独立） | λ | E=Var=λ；排队、故障、到访 |
| 几何 | 首次成功的等待次数 | p | 无记忆性 |
| 均匀 | 区间内等可能 | a, b | 蒙特卡洛的原料 |
| 正态 | 大量独立因素叠加 | μ, σ | CLT 保证的地位（第 04 篇） |
| 指数 | 下一个事件的等待时间 | λ | 与泊松互为"计数 vs 等待" |
| 幂律/帕累托 | 长尾：财富、网站流量 | α | 无有限方差——平均值会骗人 |

> [!TIP]
> 选分布先问两个问题：**离散还是连续？在数什么？** 数次数（固定试验次数）→ 二项；数到达数（固定时间）→ 泊松；数等待时间 → 几何/指数。三个工程里 80% 的建模都是这几种的无脑套用。

## 二项 → 泊松 → 正态：一条演化链

同一件事在不同参数区间的近似关系，比背公式更有用：

```text
二项(n, p)
├─ n 大、p 小（λ=np 适中）→ 泊松         罕见事件计数
└─ n 大（np, np(1−p) 都大）→ 正态        CLT 生效
```

例：10 万人访问、转化率 1% —— 转化人数直接按正态处理（μ=1000, σ≈31.5），置信区间、AB 显著性全由此起算（第 06 篇）。

现实的数据几乎从不孤立：用户的年龄与消费、请求的延迟与错误率——**多变量的联合行为**才是真实世界。联合分布描述「它们如何共舞」、边缘分布描述「各自独舞」、条件分布描述「看到其中一个后对另一个的新认识」——三层关系是本篇的骨架。

## 1. 联合、边缘、条件：三层结构

```text
联合分布 P(X, Y)：两个变量「同时」的取值概率（二维表/曲面）
边缘分布 P(X) = Σ_y P(X, y)   —— 把另一维「加掉/积掉」（投影）
条件分布 P(X | Y=y) = P(X, y)/P(y)   —— 固定 y 后的切片（重新归一化）

几何直观（连续情形）：联合是三维曲面 → 边缘是把曲面「压扁」投影到一条轴
  → 条件分布是「沿 y=y₀ 切一刀」的剖面再归一化
```

三层关系的恒等式：**P(X, Y) = P(X | Y)·P(Y) = P(Y | X)·P(X)**——「联合 = 条件 × 边缘」的两种拆法相等，两边同除即得**贝叶斯定理**。这个恒等式是本篇一切的源头。

## 2. 独立性：联合 = 边缘之积

```text
独立 ⇔ P(X, Y) = P(X)·P(Y) ⇔ P(X|Y) = P(X) ⇔ f(x,y) = f(x)f(y)

读法：知道 Y 的值不提供任何关于 X 的信息（[第 1 篇](01-foundations.md)的「信息不互通」）
联合的形状：独立的联合分布 = 边缘的乘积（无交互结构）
```

「联合 ≠ 边缘之积」= 存在相关结构——**联合分布包含边缘分布丢失的全部「交互信息」**。工程警示：只知道两个变量的边缘分布无法还原联合分布（相关性是额外的信息维度）——风险建模中「只看单变量分布」是结构性盲区（[尾部相关性](02-random-variables.md)）。

## 3. 协方差与相关系数

```text
Cov(X, Y) = E[(X−μ_X)(Y−μ_Y)] = E[XY] − E[X]E[Y]
  > 0 同向波动、< 0 反向波动、= 0 无线性相关

相关系数 ρ = Cov/(σ_X·σ_Y) ∈ [−1, 1]     （无量纲化的协方差）
  ρ = ±1：完美的线性关系
  ρ = 0：无线性关系 —— ⚠️ 但可能存在强非线性关系！
```

**「ρ=0 ≠ 独立」**是本篇最重要的警示：相关性只度量线性关系——经典的 Anscombe 四重奏：四组数据（均值/方差/相关系数完全相同）形状截然不同（线性/曲线/离群点/垂直线）——**先画散点图再看相关系数**是统计的第一反射。

相关性的三个边界：**线性 only**（非线性依赖测不到）、**对离群点敏感**（一个极端点可以制造或毁灭相关性）、**相关 ≠ 因果**（混杂变量/反向因果/选择偏差——冰淇淋销量与溺水率同涨，因为夏天）。

## 4. 贝叶斯定理：信念更新引擎

```text
P(H | D) = P(D | H)·P(H) / P(D)
  后验 = 似然 × 先验 / 证据

三个部件的语义：
先验 P(H)：看到数据前对假设的相信程度
似然 P(D|H)：假设为真时，看到当前数据的可能性
后验 P(H|D)：看到数据后的更新信念
```

贝叶斯的工程形态（[检测悖论](01-foundations.md)的推广）：**每条新证据按「似然比」调整信念**——P(H|D)/P(H) = P(D|H)/P(D)（证据的「提升度」）。序列更新：**昨天的后验 = 今天的先验**——信息逐条积累、信念单调演化（垃圾邮件过滤器的逐词更新，[第 1 篇练习 4](01-foundations.md)）。

先验的争论（[两学派](01-foundations.md)）的工程化解法：**先验敏感性分析**——用几个不同的先验各算一遍后验，看结论是否稳健；数据多时先验被淹没（似然主导）、数据少时先验决定结论——「先验的权重与数据量成反比」。

## 5. 陷阱清单

- 边缘分布当联合分布用：交互结构（尾部相关）丢失；风险建模的致命盲区。
- 相关系数当「关系强度」的万能度量：线性 only + 离群点敏感；散点图先行。
- ρ=0 当独立：非线性依赖（U 形关系）测不到。
- 条件分布与边缘分布混淆：「总体均值」vs「给定条件下的均值」（辛普森悖论的温床）。
- 贝叶斯先验被数据淹没的误判：小样本时先验主导——先验选择要敏感度分析。
- 把 P(数据|假设) 当 P(假设|数据) 读（[第 1 篇](01-foundations.md)的方向谬误再现）。
- 辛普森悖论：分组的相关性与合并的相关性方向相反——聚合层次的选择是分析决策。

## 6. 小结

- 三层结构：联合（共舞）、边缘（独舞投影）、条件（切片归一）——恒等式 P(X,Y)=P(X|Y)P(Y) 是一切之源。
- 独立 = 联合等于边缘之积；「联合包含交互信息」——边缘之和还原不了联合。
- 相关性度量线性关系：ρ=0 ≠ 独立、散点图先行、相关 ≠ 因果。
- 贝叶斯 = 信念更新引擎：似然比调整、序列积累（昨后验今先验）、先验敏感度分析。
- 多变量世界的第一课：**单变量统计的合奏 ≠ 联合行为**——交互结构是独立的信息维度。

## 7. 练习

**1.** 手工构建联合分布：2×2 的联合概率表（吸烟×患病），计算两个边缘分布、四个条件分布，验证独立性与否——完整走一遍三层计算。

> [!TIP]
> 思路构造一个「边缘相同、联合不同」的对照：同边缘下「正相关」与「独立」两种联合——联合分布的「额外信息」在两个表的差异中具体化。

**2.** Anscombe 复刻：用 sklearn/手工构造四组数据（均值方差相关全同、形状迥异），画散点图网格——然后回答「只用 summary 统计你能区分它们吗」——可视化先行的实证。

> [!TIP]
> 思路Anscombe 的四组是「统计量不可靠」的经典证据；现代版是 Datasaurus Dozen（恐龙形状！统计全同）。summary 之后永远看图。

**3.** 辛普森悖论构造：构造一个「分组看药物 A 在男女中都更有效、合并看 A 反而更差」的数据（组间样本量失衡）——体会「聚合层次」如何翻转结论。

> [!TIP]
> 思路机制：药物 A 更多分配给了高基线风险的群体（重症）——「组内正确、合并误导」的根源是混杂变量（病情轻重）。分层分析与随机化（[实验设计](../ai/04-evaluation.md)）是解法。

**4.** 贝叶斯更新序列化：用「三封邮件逐条更新垃圾概率」实现序列贝叶斯（先验 0.3 → 词1 → 词2 → 词3），画出概率的演化路径——「昨天的后验是今天的先验」的实操。

> [!TIP]
> 思路每步用 P(词|垃圾)/P(词|正常) 的似然比乘上去（log 域相加防下溢）——概率在 log 空间的加法是 ML 的常用技巧（[数值稳定性](../linalg/07-numerical.md)）。

**5.** 相关性陷阱全集：构造三组数据各验证一个陷阱——离群点制造相关（一点定江山）、U 形关系 ρ≈0、混杂变量（冰淇淋与溺水）——每个配一张散点图与一句教训。

> [!TIP]
> 思路三张图三句话：一点毁所有（看图剔异常）、U 形测不到（非线性相关用互信息/分段）、同涨非因果（找混杂变量）。

**6.** 讨论：为什么「相关性 ≠ 因果」的口号人人会背、因果推断却如此困难？从「因果需要干预/反事实」的角度分析（相关只描述共现，因果问「干预 X 会怎样」——没有随机化就只能靠假设），并概述因果推断的现代工具箱（随机实验/自然实验/因果图）如何「用假设换结论」——对照 [ML 的预测与因果的边界](../ai/01-ml-overview.md)。

> [!TIP]
> 思路预测（P(Y|X)）与因果（P(Y|do(X))）是两种量——ML 模型学到的是联合分布中的相关结构；干预改变分布本身（相关结构重排）。因果推断 = 在不可实验时的「假设显式化」（无混杂性等）+ 敏感性分析——「统计结论的强度 = 假设的强度」。

现实问题里变量从来成群出现：身高与体重、广告与销量、特征与标签。单个分布不够用了——**联合分布**描述它们如何共同起伏，而它的三个投影（边缘、条件、相关）各自回答一个不同的问题。

## 联合 → 边缘 → 条件：一个三角

联合分布 P(X, Y) 是完整信息，三个投影各取所需：

```text
边缘化：P(X) = Σ_y P(X, y)          "不管 Y 怎样，X 自己的分布"
条件化：P(X|Y=y) = P(X,y)/P(y)      "在 Y=y 的世界里，X 长什么样"
分解  ：P(X,Y) = P(X|Y)·P(Y)        联合 = 条件 × 先验（贝叶斯的原材料）
```

边缘分布会把联合分布里所有"关联"抹平：两个完全不同的联合分布可以有相同的边缘——**只看单变量统计，永远看不见关系本身**。

## 协方差与相关：线性关系的度量

```text
Cov(X,Y) = E[(X−μ_X)(Y−μ_Y)]        同向为正、反向为负
ρ = Cov(X,Y) / (σ_X·σ_Y)            归一化到 [−1, 1]
```

- ρ = ±1：完全线性关系；ρ = 0：**没有线性关系**（但可能有其他关系！）
- 经典反例：X ∈ [−1,1] 均匀分布，Y = X²——完美确定的关系，ρ = 0
- 独立 ⟹ 不相关；**不相关 ⇏ 独立**（正态世界里两者等价，这是正态好用的原因之一）

方差公式 Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y) 的工程读法：**不相关的东西叠加，方差才可加**——投资组合分散、随机误差合成、并行任务方差估计，都在用这一条。

## 相关 ≠ 因果：三种造假机制

"冰淇淋销量与溺水人数相关"——三条经典机制，分析时逐条排查：

1. **混杂变量**：第三个变量（夏天温度）同时驱动两者。控制变量后相关消失 = 混杂
2. **辛普森悖论**：分组内方向一致的相关，合并后反转——医院 A 总体治愈率高但每个科室都更低（重症都送 A）。**先分层看，再看合并**
3. **选择偏差**：数据本身经过筛选（幸存者偏差——二战飞机弹孔该补的是没弹孔的地方）

> [!WARNING]
> 特征选择与因果推断的分水岭就在这里：**预测只要相关就够，干预必须因果**。基于"巧克力消费量与诺奖数相关"去鼓励吃巧克力是无害的；基于"住院者死亡率更高"拒绝住院是致命的。先分清你在做哪一种。

## 条件期望与回归

E[Y|X=x] 是"知道 X 后对 Y 的最优猜测"——**回归的全部目的就是估计这个函数**。全期望公式 E[E[Y|X]] = E[Y] 把两者串起来：先验期望 = 条件期望的平均。机器学习里"模型拟合条件均值、损失函数是均方误差"的所有合理性，都站在这一条上（偏差-方差分解同理，第 05 篇）。

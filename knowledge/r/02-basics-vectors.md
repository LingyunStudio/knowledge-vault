R 里没有「标量」，单个数字就是长度为 1 的向量。这个设定决定了 R 的思维方式：代码不是「对一个个值做操作」，而是「对整列值做操作」。理解向量，等于理解了 R 一半的脾气。

## 原子类型与 c()

原子向量（atomic vector）只有四个常用类型，且所有元素必须同类型：

```r
is_logical   <- c(TRUE, FALSE)    # logical
is_integer   <- c(1L, 2L)         # integer，整数字面量要加 L 后缀
is_double    <- c(1.5, 2)         # double，日常写的数字都是它
is_character <- c("a", "b")       # character，单双引号等价
length(is_double)                 # 2，长度是向量最重要的属性
```

`c()` 把多个向量拍平拼接。类型不一致时自动向上转换，方向固定：logical → integer → double → character：

```r
c(1, TRUE)      # 1 1，TRUE 变成 1
c(1L, 1.5)      # 1 1.5，整型提升为双精度
c(1, "a")       # "1" "a"，数字变成字符串
```

> [!WARNING]
> 从 Excel 或问卷导出的「数字」列，只要混进一个空格或"缺失"字样，整列就变成 character。随时用 `class(x)` 检查列类型，别等算平均数报错才回头找。

## 下标从 1 开始

R 的下标从 1 开始（1-based），还支持负数下标表示剔除：

```r
x <- c(10, 20, 30, 40)
x[1]            # 10，第一个元素
x[c(1, 3)]      # 10 30，下标可以传向量
x[-2]           # 10 30 40，剔除第 2 个
x[x > 25]       # 30 40，逻辑下标是最常用的筛选方式
x[x > 25 & x < 40]   # 30，条件可以组合
```

越界和零下标不会报错，只会悄悄给你别的东西：

```r
x[10]     # NA，而不是报错
x[0]      # numeric(0)，空向量
```

宽容是双刃剑：别的语言筛选写错了会崩，R 的筛选写错了可能只是「结果空了」。逻辑下标 `x[条件]` 对应 SQL 的 WHERE，务必练到肌肉记忆。

## NA：缺失值会传染

NA 表示「这里缺了」，不是 0 也不是空字符串。它最重要的性质是**传染**：任何涉及 NA 的运算，结果都是 NA。

```r
x <- c(1, 2, NA, 4)
x + 1                   # 2 3 NA 5
mean(x)                 # NA，默认不忽略缺失
mean(x, na.rm = TRUE)   # 2.333，显式要求忽略
is.na(x)                # FALSE FALSE  TRUE FALSE
# x == NA              # ❌ 永远全是 NA，不能用 == 判断缺失
sum(is.na(x))           # 1，统计缺失个数的标准写法
```

> [!NOTE]
> `x == NA` 必然返回 NA：R 在问「一个未知的数等不等于另一个未知的数」，答案只能是未知。NA 参与一切比较都返回 NA，这是设计而不是 bug。判断缺失只有一个正确姿势：`is.na()`。

数据框上处理 NA 的两个高频动作：

```r
na.omit(df)                       # 剔除含 NA 的整行
df$score[is.na(df$score)] <- 0    # 条件填补
```

## 循环补齐

两个不等长的向量运算，短的从头重复补齐：

```r
c(1, 2, 3, 4) + c(10, 100)   # 11 102 13 104，长度整除，无警告
c(1, 2, 3)    + c(10, 100)   # 11 102 13，长度不整除，给警告
```

`x - mean(x)` 能对整列去均值，靠的正是长度 1 的循环补齐——这是它的正面价值。但长度不整除时结果几乎一定不是你想要的，看到 "longer object length is not a multiple of shorter object length" 的警告，先当 bug 排查。

## 命名向量

```r
scores <- c("李雷" = 90, "韩梅梅" = 85)
names(scores)                        # "李雷"   "韩梅梅"
scores["李雷"]                       # 按名字取，返回带名字的向量
sort(scores, decreasing = TRUE)[1]   # 最高分
```

命名向量是 R 里的「迷你字典」。`table()` 统计频数得到的就是命名向量，取众数、给图改标签、做映射查找都靠它。

## list：装不同类型的东西

原子向量要求同类型，list 没有这个限制，所以数据框（每列类型可以不同）、模型对象、嵌套配置，底层都是 list：

```r
person <- list(name = "李雷", scores = c(90, 85), passed = TRUE)
person$name         # "李雷"，$ 按名字取
person$scores[1]    # 90，取出元素后继续按向量操作
person[["name"]]    # "李雷"，[[ 等价 $
```

`[` 与 `[[` 的区别在 list 上最直观：

| 写法 | 返回 | 类比 |
| --- | --- | --- |
| `person[1]` | list | 拿走一个盒子 |
| `person[[1]]` | 元素本身 | 把东西从盒子里拿出来 |
| `person["name"]` | list | 带名字的盒子 |
| `person$name` | 元素本身 | 拆开包装 |

一句话：**`[` 永远返回同类型的容器，`[[` 往下剥一层**。原子向量上两者几乎等价（都得到长度 1 的向量），区别到 list 和数据框上才放大。数据框是 list 的特例，这个区别会一路用到下一篇。

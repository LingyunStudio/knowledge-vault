ML 的每个核心操作翻译回线性代数都很朴素：线性模型是**列向量的线性组合**、PCA 是**SVD/协方差分解**、训练是**矩阵微积分**。本篇把「矩阵作为数据」（[第 2 篇](02-matrices.md)的双视角之一）收束成 ML 的语法书——前面各章的工具在此全部就位。

## 1. 数据矩阵：ML 的通用形状

```text
X ∈ R^(n×d)：n 个样本、d 个特征
  行 = 一个样本（一个点：图像展平/一条用户记录）
  列 = 一个特征（全体样本在这一个维度上的取值）

y ∈ R^n：目标列（回归值/类别标签）

线性模型：ŷ = Xw      （每行 = 特征的加权求和 = 一次预测）
  —— [第 3 篇](03-solving-systems.md)的 Ax=b 同构！「找 w 使 Xw ≈ y」
```

「训练线性回归」= 解最小二乘（超定——样本多于参数，[第 3 篇](03-solving-systems.md)）：**w* = argmin ‖Xw − y‖²**——几何上是「把 y 投影到 X 的列空间」。ML 的「过拟合」在几何上的形象：**参数多到能精确穿过所有数据点**（[第 1 篇](../ai/01-ml-overview.md)的方差）——列空间包含 y 的全部细节（含噪声）。

## 2. 最小二乘的完整几何

```text
最小化 ‖Xw − y‖² 的几何：
  Xw（对固定的 w）= X 列空间中的点
  → 最优解 = y 在列空间上的正交投影点
  → 残差 (y − Xw*) ⊥ 列空间（[第 3 篇](03-solving-systems.md)的正交性）

解的三种数值路径（[第 7 篇](07-numerical.md)）：
正规方程 (XᵀX)⁻¹Xᵀy —— 条件数平方化（病态）
QR 分解 —— 数值稳
SVD —— 最稳 + 伪逆（自动处理秩亏）
```

残差的正交性是回归诊断的数学根基（[ML 的残差诊断](../ai/08-training-practice.md)）：**残差中若还有「与特征相关的结构」，说明模型没有把可解释部分提取干净**——几何上就是「残差不再垂直于列空间」。

## 3. PCA：方差最大方向的完整故事

```text
协方差矩阵 C = XᵀX/(n−1)（X 已中心化）—— 对称半正定（[第 5 篇](05-eigen.md)谱定理的舞台）
PCA = C 的特征分解 或 直接对 X 做 SVD（[第 6 篇](06-svd.md)，数值更稳）

第一主成分 = 数据方差最大的方向（C 的最大特征值对应的特征向量）
第二主成分 = 与第一正交中方差最大的方向 ……（逐层正交分解方差）
```

PCA 的三个等价视角（全部成立）：

1. **方差最大**：投影后方差最大的方向——保留最多信息（以方差度量）。
2. **重构误差最小**：投影回去的损失最小（与[低秩近似](06-svd.md)的 Eckart–Young 同定理）。
3. **去相关**：主成分坐标互不相关（协方差对角化）。

「方差 = 信息」的假设边界：PCA 的主成分对「监督任务」未必重要（方差小的方向可能正是判别特征）——**PCA 是无监督的（不看 y）**，监督降维是另一个问题（LDA/监督嵌入）。

## 4. 训练的矩阵微积分

```text
损失 L(w) = ‖Xw − y‖² 的梯度：∇L = 2Xᵀ(Xw − y)
  矩阵微积分的推导：链式法则 + 转置规则（[第 5 篇](05-eigen.md)的计算纪律）

梯度下降（[第 2 篇](../ai/02-linear-models.md)）：w ← w − η·Xᵀ(Xw − y)
  每一步 = 两次矩阵乘（前向 Xw、回传 Xᵀ·残差）
```

深度学习的每一步训练都是矩阵乘法与逐元素非线性（[第 5 篇](../ai/05-nn-basics.md)）——**GPU 的价值就是矩阵乘的并行**（[第 2 篇](02-matrices.md)的列视角在硬件上的延续）。梯度的形状检查（∇L 与 w 同形状）是 ML 调试的基本功（[第 5 篇练习](../ai/05-nn-basics.md)）。

## 5. Embedding 与注意力：现代的向量视角

```text
词/句子的 embedding（[LLM 篇](../llm/02-tokenizer-embedding.md)）：高维空间中的点
  语义相近 → 方向相近（余弦，[第 1 篇](01-vectors.md)）
注意力：Q·Kᵀ（点积矩阵）= 每对位置的相似度 → softmax 加权 V
  —— 「向量间的几何关系」直接成为「模型的信息路由」

PCA/嵌入空间的关系：embedding 模型学出来的「语义空间」
  常可用 PCA/SVD 分析（主成分=语义因子；[LLM 篇](../llm/02-tokenizer-embedding.md)的线性关系实验）
```

「语义的几何化」是线性代数在当代最重要的应用之一：**把「意义」变成「空间中的位置与方向」**——检索（余弦近邻）、类比（向量算术）、注意力（点积路由）全部建立在向量空间模型上。

## 6. 陷阱清单

- 数据矩阵忘记中心化就做 PCA：第一主成分变成「均值方向」而非方差方向。
- 方差小 = 无用的假设：判别特征可能方差小（PCA 无监督的盲区）。
- XᵀX 直接求解（条件数平方）：SVD/QR（[第 7 篇](07-numerical.md)）。
- 梯度形状/转置错位：矩阵微积分的形状检查是调试第一课（[第 5 篇](../ai/05-nn-basics.md)）。
- 高维空间的直觉滥用（[第 1 篇](01-vectors.md)维度灾难）：高维中「距离」与「近邻」的行为反直觉。
- 「PCA 降维后特征可解释」的期待：主成分是原特征的线性混合（可解释性下降）；稀疏 PCA/选择方法是补救。
- embedding 距离当语义真理：模型/领域的差异让「语义距离」是相对的（[LLM 评测](../llm/10-deploy-engineering.md)）。

## 7. 小结

- 数据矩阵视角：线性模型 = 列组合、训练 = 解最小二乘（投影）、过拟合 = 穿过噪声的几何形态。
- 最小二乘的几何 = 列空间上的正交投影；残差正交性是回归诊断的数学根基；SVD/QR 是数值正解。
- PCA 三视角等价（方差最大/重构最小/去相关）+ 「方差=信息」的边界（无监督盲区）；直接对数据 SVD。
- 训练 = 矩阵微积分 + GPU 矩阵乘；梯度的形状检查是调试基本功。
- embedding/注意力把「语义与信息路由」几何化——线性代数从「数学课」变成「AI 的语法」。

## 8. 练习

**1.** 最小二乘三路径对比：用正规方程、QR（np.linalg.lstsq）、SVD（pinv）解同一回归，对比系数一致性与（病态数据下的）数值稳定性——完成[第 7 篇](07-numerical.md)练习 4 的 ML 版。

> [!TIP]
> 思路病态数据（特征尺度悬殊/共线）下正规方程漂移、QR 稳、SVD+截断最稳。三路径的「数学等价、数值分层」是本篇的落点。

**2.** PCA 全流程手做：对鸢尾花数据（4 特征）中心化 → SVD → 计算各主成分方差占比 → 投影到前两主成分画散点（按类别着色）——验证「前两主成分是否已分开类别」与「方差=信息的边界」。

> [!TIP]
> 思路鸢尾花是「PCA 友好」的样本（前两成分大且可分）——再构造一个「判别方向方差小」的反例数据，体验无监督降维的盲区。

**3.** 残差诊断的几何验证：拟合一个线性回归，画「残差 vs 每个特征」的散点——「残差中还有结构」对应「特征还有可提取的信息」（残差不正交的视觉化，[ML 诊断](../ai/08-training-practice.md)）。

> [!TIP]
> 思路残差与特征的相关 ≠ 0 的信号 = 「该特征的非线性部分没被吸收」（加多项式项/变换）。几何诊断（正交性）与统计诊断（模式）的合一。

**4.** 梯度手推与检查：推导 MSE 损失的梯度 ∇L = 2Xᵀ(Xw−y)（矩阵微积分），手写实现并与数值微分对照（[第 5 篇](../ai/05-nn-basics.md)梯度检查）——训练「矩阵微积分的推导+验证」闭环。

> [!TIP]
> 思路矩阵微积分的推导习惯：先写标量形式、按分量求导、再聚回矩阵形式（或直接用维度核对）。数值检查兜底一切推导失误。

**5.** 注意力的向量实验：构造 4 个位置的小 Q/K/V（手工设值），手算注意力权重矩阵——验证「Query 与哪个 Key 点积大，Value 的权重就高」（[ai 篇](../ai/07-sequence-attention.md)实验的矩阵视角）。

> [!TIP]
> 思路QKᵀ 的每一行是一次「查询对全部键的打分」——softmax 归一成权重。手算一遍后，「注意力=可微的软寻址」从术语变成操作。

**6.** 讨论：为什么 ML 领域「线性代数 > 微积分 > 概率论」常被列为学习优先级？从「矩阵运算是 ML 的每一步执行（GPU 语法）」「梯度是训练引擎」「概率是评估与解释」三个角色的「使用频率×不可替代性」分析，并回答「ML 工程师最该精修的线性代数子集」是哪几章（数据矩阵/SVD/条件数/投影）。

> [!TIP]
> 思路ML 的日常数学 80% 是「矩阵形状运算 + 梯度」——微积分深水区（测度论）与概率深水区（推断理论）多在研究层；工程层的高频子集恰是本篇覆盖的（[第 1~7 篇]）：数据矩阵、投影、SVD、条件数。「深度」按需，「广度的骨架」先行。

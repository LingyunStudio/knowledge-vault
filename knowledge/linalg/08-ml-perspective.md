机器学习的数据几乎都是矩阵：行是样本、列是特征。前面七篇的所有工具——换基、分解、正交、谱——在 ML 里各有一个耳熟能详的名字。本篇做一次反向索引：从 ML 概念回查线代本体。

## 数据矩阵与"列 = 特征，行 = 样本"

n 个样本、d 个特征 → X 是 n×d。回归 Ax=b（第 03 篇）在这里是最小二乘拟合；矩阵乘 XW（第 02 篇）是神经网络的线性层——**每层网络就是把数据搬进新坐标系**。激活函数负责非线性，层与层之间纯粹是线性代数。

## PCA：谱定理的应用课

PCA 降维（第 06 篇）在线代语言里只需三句：

1. 数据去均值后算协方差 C = XᵀX/(n−1)——**对称半正定**，谱定理保证正交特征分解
2. 特征值 = 各主轴方向上的方差；特征向量 = 主轴方向
3. 取前 k 个特征向量作基，投影即降维——丢弃的是小方差（信息少）的方向

"数据椭球"的画面感：C 的特征方向就是椭球的主轴，特征值开方是各轴长度。**PCA = 换到椭球最长的几根轴上看数据**——换基思想（第 01 篇）的直接变现。

## 嵌入空间：语义就是几何

词向量、用户向量（第 llm 02 篇）都是把离散对象映进 ℝᵈ，让**语义关系变成几何关系**：内积当相似度（第 01 篇）、向量加法当语义组合（"国王 − 男 + 女 ≈ 女王"）。

训练嵌入模型的本质：找一个矩阵 W，使点积结构还原观测到的关联——低秩矩阵分解的另一件马甲（第 06 篇），推荐系统的矩阵分解同理。

## 注意力：一次线代的集大成

Transformer 的注意力（第 llm 03 篇）拆开全是本板块的零件：

```text
Attention(Q,K,V) = softmax(QKᵀ/√d) · V
```

- QKᵀ：批量内积——所有 query 与 key 的相似度矩阵（余弦相似度的无归一版）
- softmax：把内积行归一化成凸组合权重
- 权重 · V：**凸组合 = 各向量的加权平均**——输出落在数据的凸包里

没有任何新数学，只有内积、归一化、加权平均的连环套用。看懂这一点，"注意力在做语义查找"就落到了实处。

## 正则与几何

- **L2 正则（权重衰减）**：把最优解往原点拉，对应球面约束——解的范数变小、各分量摊匀
- **L1 正则**：菱形约束的角点天然让部分系数**精确为零**——稀疏性来自几何形状，不是魔法
- **最小二乘 + L2 = 岭回归**：数据病态时（第 03/07 篇）用先验压住方差——偏差换方差的经典交易

> [!TIP]
> 学习建议：遇到任何新 ML 方法，先问三个线代问题——**它在对哪块矩阵做分解/求逆？在换到什么基？用什么范数量误差？** 三个都能答上，方法就懂了一大半；都答不上，说明还在背公式。

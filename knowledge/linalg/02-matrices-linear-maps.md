初学者把矩阵当"一张数表"，乘法当"背下来的算式"。换一个视角：**矩阵是一台变换机器**——它把每个输入向量搬运到输出向量，而且是"线性地"搬。这个视角下，矩阵乘法、转置、逆，全部从"为什么"变得显然。

## 什么是线性变换

一个变换 T 线性，当且仅当：`T(u+v) = T(u)+T(v)` 且 `T(cv) = cT(v)`——加法和数乘不变形。几何上只有两件事被允许：**旋转、拉伸、投影、剪切**这类"网格线保持平行且等距"的操作；平移不线性（T(0) ≠ 0），弯曲变形也不线性。

关键事实：**线性变换被它在基向量上的行为完全决定**。T(e₁), T(e₂) 定了，任何向量 T(a·e₁+b·e₂) = a·T(e₁)+b·T(e₂) 也就定了。

## 矩阵就是"把基的落点写下来"

把变换后的基向量按列排好——这张数表就是矩阵。所以**读矩阵的列，就是读"基向量去哪了"**：

```text
A = [0  -1]     e₁=(1,0) → (0,0)   e₂=(0,1) → (-1,0)
    [1   0]     整个平面逆时针旋转 90°

A = [2  0]      e₁ → (2,0)：横向拉伸 2 倍
    [0  1]      e₂ 不动：纵向不变
```

用这个方法，四列看懂一切矩阵：

| 矩阵的列 | 几何含义 |
| --- | --- |
| 某列为零向量 | 有一个维度被**压扁**了（不可逆！信息丢失） |
| 两列平行 | 空间被压到一条线/一个平面上（同样不可逆） |
| 列长 > 1 / < 1 | 相应方向被拉伸/压缩 |
| 两列垂直且等长 | 刚性旋转（行列为 1 时纯旋转） |

**行列式 = 面积/体积的缩放因子**（第 04 篇）也来自这里：单位正方形被这个变换拉成多大。

## 矩阵乘法：变换的复合

`(AB)v = A(Bv)`——先做 B 的变换再做 A 的。所以矩阵乘法就是**函数复合**，这就是它"从右往左"读的原因，也解释了为什么它不满足交换律（先旋转后拉伸 ≠ 先拉伸后旋转）。

计算上"行乘列"只是把 A 对基向量的作用叠加到 B 的结果上：AB 的第 j 列 = A 作用于 B 的第 j 列。想清楚这点，转置的规律 `(AB)ᵀ = BᵀAᵀ` 也成了显然（复合的顺序要倒回来）。

## 逆：把变换搬回去

A⁻¹ 存在 ⟺ A 没有压扁任何维度 ⟺ 列向量线性无关 ⟺ det ≠ 0。逆变换保证每个点都能原路返回；一旦有维度被压掉，信息就永久丢失了——**不可逆不是"算不出"，是"回不去"**。

> [!NOTE]
> 线性方程组 Ax=b 的几何读法：b 是空间的某个点，x 是"哪些输入经过 A 会到达 b"。A 可逆时 x = A⁻¹b 唯一；A 把空间压扁了，b 若不在压扁后的空间里则无解，在里面则有无穷多解——解的三种情况就是空间被压的程度决定的（第 03 篇）。

## 工程视角：数据即矩阵

机器学习里，矩阵 A 的另一种日常身份是**批量数据的容器**：每行一个样本。此时 Ax=b 的"解"是最小二乘回归，Av 的"乘"是网络层的前向——同一套理论，两种读法，交替使用。

线性代数的陷阱不是「记错公式」，而是**概念之间的连接断裂**——会算但不知道「这个分解在几何上干了什么」「那个数在数值上可不可信」。本篇先画一张概念地图把全书串起来，再给应用层的审查清单。

## 1. 概念地图：一张图串起全书

```text
向量（[第 1 篇]）              几何：箭头与组合
  ↓ 线性组合编码成表
矩阵 = 线性变换（[第 2 篇]）    列=基向量去向；乘法=复合
  ↓ 变换的「输出维度」
秩与列空间 → Ax=b 的三种命运（[第 3 篇]）   满秩/降维/投影
  ↓ 变换的「体积缩放」
行列式（[第 4 篇]）            =0 坍缩、=缩放因子
  ↓ 变换的「不变方向」
特征值（[第 5 篇]）            Av=λv；对称矩阵正交分解
  ↓ 万能化（任何矩阵）
SVD（[第 6 篇]）               旋转-缩放-旋转；能量谱；伪逆
  ↓ 落到浮点世界
数值计算（[第 7 篇]）          条件数；稳定性；分解选择
  ↓ 应用于数据
ML 视角（[第 8 篇]）           数据矩阵；PCA；最小二乘；梯度
```

读图的三个连接点（最容易断的）：**秩 ↔ 可逆性 ↔ det=0**（[第 2~4 篇]的同一定义）；**对称性 ↔ 谱定理 ↔ PCA**（[第 5 篇]→[第 6 篇]→[第 8 篇]）；**条件数 ↔ 正规方程病态 ↔ SVD 正解**（[第 7 篇]贯穿）。

## 2. 六类应用审查清单

### 2.1 建模与投影（第 3、8 篇）

- [ ] 回归问题确认了「解的存在性」（超定→最小二乘；无解是常态）
- [ ] 残差诊断做过（正交性/无结构，[第 8 篇](08-ml-perspective.md)）
- [ ] 不用显式 inv（solve/QR/SVD）
- [ ] 特征缩放/共线性处理过（条件数意识）

### 2.2 数值健康（第 7 篇）

- [ ] 条件数检查过（病态 → 缩放/重参数化/正则化）
- [ ] 无灾难性抵消的公式（相近数相减的等价变形）
- [ ] 浮点比较用容差；求和考虑顺序（fsum/成对）
- [ ] 分解选择符合结构（Cholesky/QR/SVD 的选型树）
- [ ] 数值代码有「参考解/性质断言」测试（非值断言）

### 2.3 降维与分解（第 6、8 篇）

- [ ] PCA 前中心化；数据直接 SVD（非 XᵀX）
- [ ] 有效秩/成分数的选择有依据（谱拐点 + 领域知识）
- [ ] 「方差=信息」的边界声明（无监督盲区）
- [ ] 低秩近似的截断残差评估过

### 2.4 特征值与动态（第 5 篇）

- [ ] 矩阵可对角化的前提核查（对称的黄金保证/一般矩阵的局限）
- [ ] 复特征值的意义理解（旋转）而非当错误
- [ ] 动力系统的 |λ| 稳定性判断
- [ ] 大矩阵/稀疏用迭代法（eigsh/CG）而非稠密分解

### 2.5 几何与表示（第 1、2 篇）

- [ ] 高维直觉的边界意识（维度灾难）
- [ ] 基/坐标的相对性（换基与相似变换）
- [ ] 范数的选择与语义匹配（L1/L2 的度量决策）
- [ ] embedding 的余弦相似度使用正确（[LLM](../llm/02-tokenizer-embedding.md)）

### 2.6 计算实现（第 7 篇）

- [ ] 矩阵运算的形状检查（转置/维度——[ML 梯度](08-ml-perspective.md)）
- [ ] 大矩阵的分解/迭代选择与内存预算
- [ ] 库函数 vs 手写的分工（理解的用手写验证、生产的用库）
- [ ] 随机化算法（随机 SVD）的精度权衡知情

## 3. 「ML 数值事故」的诊断路线

```text
症状：训练 loss 为 NaN / 收敛诡异 / 模型对微小数据扰动极敏感

① NaN 与发散：lr 过大 / 数据有 inf/NaN / 溢出（[第 2 篇](../rust/02-variables-types.md) 的整数、float 上限）
   → 降 lr、数值范围检查、梯度裁剪（[第 5 篇](../ai/05-nn-basics.md)）
② 对扰动极敏感：条件数病态 → 缩放特征/正则化（[第 7 篇](07-numerical.md)）
③ 结果不可复现：随机种子/并行归约的非确定（[第 8 篇](../ai/08-training-practice.md)）
④ 精度问题：灾难性抵消/求和顺序 → fsum/升宽/成对求和
⑤ 形状不对：矩阵微积分的转置错位 → 维度断言 + 梯度检查
```

## 4. 反模式速查

| 反模式                                       | 一句话修复                              |
| -------------------------------------------- | --------------------------------------- |
| `np.linalg.inv` 求解/求「数值稳定性」          | solve/lstsq/分解                        |
| PCA 不中心化                                  | 先减均值（或用库的默认）                 |
| 手解 n≥3 特征多项式                            | eig 软件求解                             |
| 忽视量纲直接算距离                             | 标准化 + 范数选择                        |
| XᵀX 显式构造（条件数平方）                     | 对 X 直接 SVD/QR                        |
| 高维「最近邻」的朴素直觉                       | 维度灾难意识 + 降维/度量学习             |
| 对浮点结果断言相等                             | 容差 + 性质断言                          |
| 稀疏矩阵当稠密处理                             | sparse 结构 + 迭代法                     |
| 大矩阵 full SVD                                | thin/随机化 SVD                         |
| 「det 小 = 病态」                              | 条件数才是病态度量                       |

## 5. 学习阶段自测

```text
□ 看到 2×2 矩阵能立刻说出它的几何作用（旋转/缩放/剪切/投影的组合）
□ 能用列空间/秩的几何语言解释「方程组无解」与「模型过拟合」
□ 给任意矩阵求 SVD 并读谱：说出有效秩、能量占比、该不该截断
□ 遇到病态问题先改建模（缩放/正则）而不是换算法
□ 能解释 PCA 与协方差特征分解的等价性、以及为什么 SVD 实现更稳
□ 能对一段 ML 代码做「形状检查 + 数值风险」的快速审查
```

## 6. 小结

- 概念地图的主线：向量 → 变换（矩阵）→ 秩与解 → 行列式（缩放）→ 特征（不变方向）→ SVD（万能化）→ 数值（浮点现实）→ ML（数据视角）——每个概念都有几何身份与数值警告。
- 审查六类：建模投影、数值健康、降维分解、特征动态、几何表示、计算实现——ML 数值事故的根因多在「数值健康」与「数据矩阵」两类。
- 「好得离谱/不稳定/不可复现」的诊断路线均始于数值与数据检查——ML 事故的一半是线性代数事故。
- 双轨学习的自测：几何直觉（看图说变换）+ 数值警觉（条件数/抵消/容差）——两轨并行才完整。

## 7. 练习

**1.** 概念地图复述测试：合上教程，画出「从向量到 SVD 到 ML」的概念关系图（每个概念标注几何意义与一个应用）——画不出的连接点就是理解断点。

> [!TIP]
> 思路关键连接点的自检：秩与可逆、对称与 PCA、条件数与病态、SVD 与投影。连接点的「双向可讲」（A→B 与 B→A）是深度理解的标志。

**2.** 综合审查实战：找一个 ML 训练脚本（或你写的），用六类清单过一遍——重点核对「条件数意识」「Pipeline 防泄漏」「形状检查」三类，写出整改建议。

> [!TIP]
> 思路数值类问题的发现依赖「主动检查」而非等待报错——cond 打印/形状断言/容差比较应该成为代码的默认习惯（[C 篇的默认初始化纪律](../c/03-operators-control.md)同类）。

**3.** 「同一问题三条路」综合练习：最小二乘问题分别用（a）正规方程+手推梯度、（b）QR/lstsq、（c）SVD 截断正则化实现——三者的系数、数值稳定性、对病态的鲁棒性全面对比，写成对比报告。

> [!TIP]
> 思路报告的维度：精度（与高精度参考比）、病态鲁棒性、计算成本、正则化能力（SVD 截断独有）。一条问题三种解法是「数值意识」的综合考试。

**4.** 跨篇知识串联：解释「为什么协方差矩阵的特征分解（[第 5 篇](05-eigen.md)）与数据 SVD（[第 6 篇](06-svd.md)）在 PCA 上等价、但后者数值更优」——用「条件数平方化」（[第 7 篇](07-numerical.md)）的语言完整论证。

> [!TIP]
> 思路论证链：X 的 SVD 的奇异值² = XᵀX 特征值 → V 列相同（PCA 一致）；XᵀX 的 cond = cond(X)² → 特征分解路径的数值敏感加倍。「等价与优劣」必须分开论证。

**5.** 教学输出练习：向一个只学过高中数学的朋友解释「为什么 AI 的每一步训练都是矩阵乘法」——用「数据矩阵 + 加权求和 + 调整权重」三层类比，不使用任何公式符号。

> [!TIP]
> 思路无公式解释的能力 = 直觉的内化程度。「权重是旋钮、数据是表格、训练是拧旋钮让输出接近答案」——能讲清这三句，[第 8 篇](08-ml-perspective.md)就真的通了。

**6.** 讨论：线性代数教程的「几何优先」路线（本篇系列）在「考试计算」与「工程应用」两个目标下的表现差异是什么？从「计算的熟练度靠练习量」「直觉的建立靠图像与连接」「现代软件接管计算后直觉的相对价值上升」三个角度，给出你对「下一个要自学的数学分支」（概率论/优化/信息论）的学习策略——是否同样适用「几何/语义先行」？

> [!TIP]
> 思路概率论的「几何」对应物是「样本空间与分布的形状」（[prob 篇](../prob/01-foundations.md)）、优化是「损失地形」（[梯度下降](../ai/02-linear-models.md)）、信息论是「不确定性度量」——每个分支都有可成像的核心。「语义先行」的适用性与该分支的「图像丰富度」成正比；纯符号领域（抽象代数）则需另找锚点（计算实验）。

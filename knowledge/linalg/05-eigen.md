特征向量回答一个深刻的问题：**一个线性变换会把空间扭成各种形状——有没有「方向不变」的特殊向量？** Av = λv 的几何意义：向量 v 在变换 A 下只被**缩放**（λ 倍），方向纹丝不动。这些「不变方向」是变换的骨架——找到它们，复杂的变换行为就变得透明。

## 1. 核心概念：Av = λv

```text
Av = λv 的几何读法：
  变换 A 作用在 v 上 = 只把 v 拉伸 λ 倍（方向不变）

  λ > 1：沿该方向拉伸        λ ∈ (0,1)：压缩
  λ < 0：反向（翻转）        λ = 0：压到原点（该方向被消灭——det=0 [第 4 篇](04-determinant.md)）

例：对角矩阵 diag(3, 1/2)
  e₁=[1,0] → [3,0]     特征向量！λ=3（x 方向拉伸 3 倍）
  e₂=[0,1] → [0,0.5]   特征向量！λ=1/2
  其他向量（如 [1,1]）方向会变 —— 非特征向量
```

对角矩阵的特征向量就是坐标轴——**变换平凡（纯缩放）**。特征分解的全部意义在于：**把任意矩阵变成「某个基下的对角矩阵」来看**——找到不变方向后，复杂变换在各方向上「各自为政」的缩放。

## 2. 怎么求：特征多项式与「交给软件」

```text
Av = λv  →  (A − λI)v = 0
非零解存在 ⇔ det(A − λI) = 0        （特征多项式 = 0）
  n×n 矩阵 → n 次多项式 → n 个特征值（可能复数/重复）
```

```python
import numpy as np
A = np.array([[2, 1], [1, 2]])
vals, vecs = np.linalg.eig(A)
# vals = [3, 1]      特征值
# vecs 的列 = 对应特征向量（归一化）
```

特征多项式手解在 n≥3 就需要求根公式之外的手段（五次以上无公式）——**理解「det(A−λI)=0 的几何意义」（存在被压零的方向）+ 软件求解**是正确分工（[第 4 篇](04-determinant.md)的计算外包纪律）。

## 3. 对角化：换到「不变方向」的基

```text
若 A 有 n 个线性无关的特征向量（V 的列）：
A = V D V⁻¹        D = diag(λ₁,…,λₙ)（对角矩阵！）
读法：V（换到特征基）→ D（在各方向纯缩放）→ V⁻¹（换回来）
```

对角化的威力在**矩阵幂**：

```text
A² = V D V⁻¹ · V D V⁻¹ = V D² V⁻¹
Aᵏ = V Dᵏ V⁻¹          （矩阵幂 = 特征值的幂！对角矩阵的 k 次方易如反掌）
```

应用一：**动力系统/差分方程**。人口迁移模型 v_{t+1} = A·v_t 的长期行为：v_t = Aᵗ·v₀ = V Dᵗ V⁻¹——**|λ|<1 的方向衰减到零、|λ|>1 的方向爆炸、最大特征值主导长期行为**（[PageRank](https://zh.wikipedia.org/wiki/PageRank) 的「网页重要性」就是转移矩阵的主特征向量）。

```python
# 迁移矩阵的长期行为 = 主特征向量
A = np.array([[0.9, 0.2], [0.1, 0.8]])     # 城乡人口迁移
vals, vecs = np.linalg.eig(A)
dominant = vecs[:, np.argmax(np.abs(vals))]  # 长期人口分布比例
```

## 4. 对称矩阵：谱定理的黄金保证

```text
对称矩阵（A = Aᵀ，协方差/图拉普拉斯/距离结构）的特殊待遇：
① 特征值全为实数（无复数）
② 特征向量可以取成互相正交
③ V 正交（V⁻¹ = Vᵀ）：A = V D Vᵀ —— 谱定理

几何意义：对称变换 = 沿一组「正交方向」的纯缩放（无剪切扭曲）
—— 空间被「规规矩矩」地沿主轴拉伸
```

对称性贯穿 ML：**协方差矩阵**（对称半正定——PCA 的主角，[第 8 篇](08-ml-perspective.md)）、**核矩阵**、图拉普拉斯——它们的主特征向量（主成分）有「方差最大方向」的意义。非对称矩阵可能没有实特征向量（旋转矩阵的特征值是 ±i——**复特征值的几何意义是旋转**：一对复共轭特征值对应一个旋转缩放平面）。

## 5. 陷阱清单

- 以为所有矩阵都可对角化（缺陷矩阵/旋转矩阵不行）：实对称矩阵保证可对角化；一般矩阵看线性无关特征向量数。
- 手解特征多项式上瘾：n≥3 交给软件（[第 4 篇](04-determinant.md)纪律）。
- 特征向量不归一/不正交的困惑：软件输出已归一化；对称矩阵自动正交。
- 复特征值当「错误」：旋转的必然产物（成对出现）——几何意义是旋转平面。
- |λ| 与稳定性的判断缺失：动力系统「最大 |λ| 主导」的直觉（PageRank/人口/衰减）。
- 忘记特征向量只定义方向（可任意缩放）：软件输出的归一化只是约定。
- 非对称矩阵用 A = VDVᵀ 写：只有对称才有正交对角化；一般矩阵是 VDV⁻¹。

## 6. 小结

- 特征向量 = 变换的不变方向，特征值 = 该方向的缩放倍数——λ=0 意味着该方向被消灭（连接 det）。
- 求解 = det(A−λI)=0 的特征多项式；n≥3 交给软件。
- 对角化 = 换到不变方向的基：矩阵幂变成特征值的幂——动力系统的长期行为由最大 |λ| 主导（PageRank/迁移模型）。
- 对称矩阵的谱定理：实特征值 + 正交特征向量 = 沿正交主轴的纯缩放——协方差/PCA 的数学基础。
- 复特征值 = 旋转（成对出现）——「非对称」的几何信号。

## 7. 练习

**1.** 手工求一个 2×2 的特征值/特征向量：A=[[3,1],[0,2]]（上三角——特征值就是对角线 3 和 2），解 (A−λI)v=0 的特征向量，画图验证「这两方向只缩放不转向」。

> [!TIP]
> 思路上三角矩阵的特征值 = 对角线元素（消元的副产品）——特征向量解齐次方程。画图确认 [1,0] 与 [1,1] 方向「只伸缩」。

**2.** 对角化与矩阵幂：对 A=[[2,1],[1,2]] 做对角化（V、D），用 V D⁵ V⁻¹ 计算 A⁵ 并与 np.linalg.matrix_power 对照——体会「幂 = 特征值的幂」的效率与优雅。

> [!TIP]
> 思路D⁵ = diag(3⁵, 1⁵)——对角矩阵的幂零成本。特征分解把「连乘 5 次」变成「查表」——大矩阵幂/动力系统模拟的算法基础。

**3.** PageRank 简化版：构造 4 页面的链接转移矩阵（列归一化），求最大特征值对应的特征向量——验证它是「长期浏览分布」（迭代乘 100 次后与特征向量成比例）。

> [!TIP]
> 思路PageRank = 「随机冲浪的稳态分布 = 转移矩阵的主特征向量（λ=1）」。「幂迭代」（反复乘矩阵）收敛到主特征向量——不用解方程的特征向量算法（谷歌起家的数学）。

**4.** 对称 vs 非对称实验：取对称矩阵与旋转矩阵各一，np.linalg.eig 观察特征值（实数对 vs 复数对）与特征向量的正交性——用实验巩固谱定理与非对称的差异。

> [!TIP]
> 思路旋转矩阵 [[0,-1],[1,0]] 特征值 ±i——纯旋转无「不变方向」（除了原点），复特征值编码「旋转 90°」这个事实。

**5.** 协方差矩阵的主成分预演：构造二维相关数据（椭圆云），计算协方差矩阵的特征向量——它们正是椭圆的主轴方向——「PCA = 协方差的特征分解」的几何预览（[第 8 篇](08-ml-perspective.md)）。

> [!TIP]
> 思路特征向量指向数据云的「长轴与短轴」、特征值是各轴方差——「最大特征值的特征向量 = 数据方差最大方向」就是 PCA 第一主成分。协方差的对称性保证主轴正交（谱定理）。

**6.** 讨论：为什么「找到不变方向」的策略在数学与工程中反复出现（特征向量/PageRank/PCA/模态分析/马尔可夫稳态）？从「不变量 = 系统的骨架」（动态中的静态结构）的哲学角度，分析「变换不变量」类问题的通用解法形态（解 A v = λ v / 稳态条件），并举一个你领域内的「稳态/不变方向」问题。

> [!TIP]
> 思路不变量思维：复杂动态中最有信息量的对象是「不变的东西」（稳态分布/主轴/固有频率）——它们把「时变行为」压缩成「静态结构」。解法形态统一为「算子方程的解」（Av=λv/∂t=0）——数学的「特征问题」是工程「稳态分析」的通用语言。

Ax=b 是线性代数的"Hello World"，也是回归、电路、结构力学的公共形式。本篇把"什么时候有解、有几个解、怎么求"一次讲透——核心工具只有两个：高斯消元和秩。

## 高斯消元：系统地消灭变量

思路：用第一行的倍数去消掉下面各行第一列的系数，再对子矩阵重复——把矩阵化成上三角，然后从最后一行往回代（回代）。以行视角看，这是**对方程做合法变形**（交换、倍乘、相加），解集不变；以列视角看，是在追问"b 是各列的什么组合"。

```text
x + 2y = 5        x + 2y = 5
2x + 3y = 8   →   -y = -2      →   x=1, y=2
```

工程上从不用行列式公式（Cramer 法则）解方程——消元是 O(n³)，公式是 O(n!)。

## 秩：有效维度的计数

消元后剩下的非零行数 = **秩（rank）**。用变换视角（第 02 篇）读它：秩 = 变换后空间的维度 = 列空间的维度 = 独立信息列的条数。

- **列满秩**（rank = n，列数）：没有维度被压扁，A 可逆——任意 b 都有**唯一解**
- **行满秩 / 欠定**（方程少于未知数）：约束不够，**无穷多解**——通常配合"取范数最小"挑一个（最小范数解）
- **秩亏 / 超定**（方程多于独立未知数）：约束过载，b 落在列空间外时**无解**

> [!TIP]
> 一句话记：解的个数由 **A 压扁了多少** 和 **b 在不在输出空间里** 共同决定。"无解/唯一/无穷"三选一，秩一张嘴就知道。

## 病态系统：有解但靠不住

理论可逆 ≠ 实际可解。若 A 接近压扁（接近奇异），b 的微小噪声会放大成 x 的巨大误差。量化它的是**条件数**：

```text
cond(A) = 最大奇异值 / 最小奇异值      （第 06 篇）
误差放大倍数 ≈ cond(A)
```

cond(A) ≈ 10⁸ 的系统，双精度下解丢掉约 8 位有效数字。**实际解方程前先估条件数**——这是数值线代（第 07 篇）的第一课：坏问题不是算得慢，是根本没答案可言。

## 无解怎么办：最小二乘

超定方程（如 100 个数据点拟 2 个参数）没有精确解，退而求其次：找 x 让**残差 ‖Ax−b‖ 最小**——这就是最小二乘。正规方程给出 `(AᵀA)x = Aᵀb`，几何解释是"把 b 正交投影到 A 的列空间"。

```python
import numpy as np
x, residuals, rank, sv = np.linalg.lstsq(A, b, rcond=None)
# 实际工程用 lstsq（基于 SVD，数值稳定），而不是解正规方程
```

> [!WARNING]
> 正规方程 `AᵀA` 的条件数是 cond(A) 的**平方**——本来病态的问题直接崩。数值稳定实现（QR 分解、SVD）才是默认选项，这个坑在机器学习教材里被无数示例代码埋着。

## 解的结构

齐次方程 Ax=0 的解集是"被 A 压到零的那些方向"（零空间），非齐次解 = 一个特解 + 任意零空间向量。求逆昂贵且常不必要：**解 Ax=b 用分解（LU/QR/SVD），别求 A⁻¹**——求逆又慢又病态，是新手最常见的性能与精度双重错误。

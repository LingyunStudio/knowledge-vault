矩阵的第一身份不是「数字表格」而是**空间变换的编码**：一个矩阵完整记录了一个线性变换——**看它把基向量搬到哪，就知道它把整个空间怎么扭**。这个视角让矩阵乘法、秩、行列式、特征值全部获得几何意义（[第 1 篇](01-vectors.md)的几何路线贯穿）。

## 1. 线性变换：保持网格的两条性质

```text
线性变换 = 保持「加法」与「数乘」的变换：
T(u + v) = T(u) + T(v)      （先加再变 = 先变再加）
T(cv) = c·T(v)              （先缩放再变 = 先变再缩放）

几何特征：原点不动、网格线保持平行且等距（直线仍为直线）
旋转、缩放、剪切、投影都是；平移不是（原点动了）
```

**关键定理**：线性变换被它对基向量的作用**完全决定**——因为任何向量都是基的线性组合，变换保持组合关系：T(v) = T(x·e₁ + y·e₂) = x·T(e₁) + y·T(e₂)。

## 2. 矩阵 = 基向量的去向记录

```text
矩阵的列 = 变换后基向量的新坐标！

       ┌ x' ┐   ┌ 1  3 ┐┌ x ┐    ┌ 1 3 ┐ 列1 = e₁→(1,-2)? 
 T(e₁)=│ 1  │    │      ││   │    │ -2  │ 列2 = e₂→(3,-2)
       └-2  ┘    └-2 -2 ┘└ y ┘

矩阵 [1 3; -2 -2] 完整记录变换：任何向量 [x,y] 变换 =
  x·(变换后的 e₁) + y·(变换后的 e₂) —— 矩阵乘向量的列视角！
```

「矩阵乘向量 = 对矩阵各列做线性组合」——这个视角比「逐行点积」更有理解力：**矩阵的列告诉你空间被怎么扭**。列向量张成的空间 = 变换的**输出能到达的空间**（列空间）。

## 3. 矩阵乘法 = 变换的复合

```text
先旋转变换 A，再做剪切变换 B —— 总效果是什么？
B·A·x（先 A 后 B，从右往左读）
复合变换 C = B·A：C 的列 = B 作用在「A 的列」上的结果

矩阵乘法的定义（行乘列）就是「复合变换」的必然形式：
(B·A) 的第 j 列 = B · (A 的第 j 列)    —— 复合 B∘A 作用在基向量上
```

「为什么矩阵乘法这么定义」的答案：**因为它是复合变换的唯一自然形式**。由此自动得到的性质（对照死记硬背）：乘法**不可交换**（先旋转后剪切 ≠ 先剪切后旋转——BA ≠ AB）；**结合律成立**（复合的顺序分组不影响结果）。

```python
import numpy as np
A = np.array([[0, -1], [1, 0]])    # 逆时针旋转 90°
B = np.array([[1, 1], [0, 1]])     # 剪切
# (B @ A) 与 (A @ B) 的图像不同 —— 不可交换的几何证据
```

## 4. 列空间、秩与「降维」

```text
列空间 = 矩阵列向量的张成空间 = 变换的输出可达空间
秩 = 列空间的维数 = 「输出空间的维度」

满秩方阵（秩=n）：空间被映射到同维度（可逆——没有信息丢失）
秩亏损（秩<n）：空间被「压扁」到低维（多对一——不可逆，信息丢失）
  例：三维空间被压成一个平面（秩 2）或一条线（秩 1）
```

「秩 = 独立方向数 = 输出维度」的几何意义，让「秩亏损 = 不可逆 = 存在非零解 Ax=0」全部连通（[第 3 篇](03-solving-systems.md)）：被压扁的空间中，多个输入共享一个输出——**逆变换不存在**（无法从输出唯一还原输入）。

### 4.1 非方阵：维度之间的变换

```text
2×3 矩阵（3 列 2 行）：R³ → R²   （三维压到二维——投影类）
3×2 矩阵：R² → R³                （二维抬到三维——嵌入，但输出仍是二维的平面！）
```

非方阵的列数 = 输入维度、行数 = 输出维度；「3×2 矩阵把二维抬到三维」但列空间仍是二维（嵌入的是平面）——秩不会超过较小的维度。

## 5. 双重视角：变换 vs 数据

| 视角   | 矩阵是什么      | 乘法的意义        | 典型场景                             |
| ---- | ---------- | ------------ | -------------------------------- |
| 变换视角 | 空间的线性映射    | 变换的复合        | 图形学/微分方程/PCA（[第 6 篇](06-svd.md)） |
| 数据视角 | 一组样本/特征的排列 | 特征的线性组合/加权汇总 | 数据集（行=样本）、线性模型                   |

ML 里的 X @ w：数据视角是「每个样本的特征加权求和」、变换视角是「把样本向量搬进新空间」——**两个视角在同一符号下并存**，切换的能力就是理解能力（[线性模型](../ai/02-linear-models.md)的两面）。

## 6. 基变换一瞥：坐标是相对的

```text
同一个箭头在不同基下的坐标不同：
M·v 的「M」在变换视角是变换；在「新基坐标 → 老基坐标」的读法是基变换
A⁻¹·M·A：在 A 基下描述的变换 M 换到标准基——相似变换（[特征值](05-eigen.md)的语言）
```

基变换的解释：**矩阵的意义依赖「坐标语言」**——「对角化」（[第 5 篇](05-eigen.md)）就是找到一组基让变换的描述最简单（纯缩放）。

## 7. 陷阱清单

- 矩阵乘法死记行列规则不懂复合：不可交换、结合律全靠几何直觉自动成立。
- 把「矩阵 = 数字表」当全部：先问「这个矩阵把基向量搬到哪」。
- 秩只当「行变换数出来的数」：秩 = 输出维度 = 信息保真度（满秩可逆/降维丢失）。
- 忘记矩阵乘向量是「列的组合」：列视角是理解列空间/秩/PCA 的钥匙。
- 3×2「升维」的误解：嵌入的仍是二维平面（秩 ≤ 2）——维度由秩定不由行数定。
- AB 与 BA 不分：复合顺序（先 A 后 B）在几何里一目了然。

## 8. 小结

- 矩阵的第一身份是线性变换的编码：列 = 变换后的基向量；矩阵乘向量 = 列的线性组合。
- 矩阵乘法 = 变换复合（从右往左）——不可交换、满足结合律都是几何事实。
- 列空间 = 输出可达空间；秩 = 输出维度——满秩可逆、降维丢失是同一条几何逻辑。
- 非方阵 = 维度间的映射；「升维」嵌入的仍是低维结构。
- 变换视角与数据视角并存；基变换让「坐标语言」相对化——对角化是它的巅峰应用。

## 9. 练习

**1.** 给定矩阵 \[\[0,-1],\[1,0]]，先猜它是什么变换（把基向量 \[1,0]→\[0,1]、\[0,1]→\[-1,0]），画图验证是逆时针 90° 旋转——用「基向量去向」读矩阵的练习。

> [!TIP]
> 思路两列分别是 e₁、e₂ 的新位置：e₁→(0,1)、e₂→(-1,0)——整个空间的旋转被两列完全描述。这就是「读矩阵先读列」。

**2.** 复合验证：旋转 90°（A）与剪切（B）的 B·A、A·B 两个乘积各作用于正方形，手工画（或 numpy+matplotlib 画）四个图——直观见证不可交换。

> [!TIP]
> 思路B·A（先转后剪）与 A·B（先剪后转）的最终图形不同——「先穿衣再洗澡 vs 先洗澡再穿衣」的顺序不可换。矩阵乘法的「从右往左」读法由此自然习得。

**3.** 秩的实验：构造 3×3 矩阵（满秩/第三列是前两列之和/全同列），numpy 求 rank 并把单位向量们变换后画图——看到「空间压扁成平面/直线」。

> [!TIP]
> 思路第三列冗余（前两列的组合）→ 列空间是平面 → 秩 2 → 变换把三维压扁 → 不可逆。「列的冗余度」就是「降维程度」。

**4.** 数据视角练习：把一个 3 样本 × 2 特征的数据矩阵 X 与权重 w=\[1,2] 相乘（X\@w），解释结果向量的两个视角含义（每样本的加权得分 / 变换视角）。

> [!TIP]
> 思路X\@w = 每行的点积（样本得分）；同时是「X 的列空间中按 w 组合的向量」。同一段代码、两套解读——ML 与线性代数的语言切换。

**5.** 用变换视角解释「为什么矩阵乘向量等价于列的组合」：从「线性变换保持组合」出发两行推导完成证明——训练「用定义推性质」而不是背结论。

> [!TIP]
> 思路T(v) = T(x·e₁ + y·e₂) = x·T(e₁) + y·T(e₂)——线性两条性质 + 基向量去向 = 全部。矩阵乘法的所有「怪性质」都是「复合+线性」的推论。

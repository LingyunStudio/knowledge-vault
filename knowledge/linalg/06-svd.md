特征分解强大但只对可对角化方阵成立。**SVD（奇异值分解）则对任意矩阵都成立**——方的、扁的、长的、不可逆的，通吃。它是线代工具箱里的瑞士军刀：降维、去噪、压缩、解最小二乘、推荐系统，底层都是它。

## 分解的含义

任何矩阵 A（m×n）都能写成：

```text
A = UΣVᵀ
 U：m×m 正交矩阵，输出空间的一组新基（左奇异向量）
 Σ：m×n 对角阵，对角线是奇异值 σ₁ ≥ σ₂ ≥ …（非负，按大小排）
 V：n×n 正交矩阵，输入空间的一组新基（右奇异向量）
```

几何读法：**任何线性变换 = 旋转(V) → 沿新轴各自缩放(Σ) → 再旋转(U)**。再杂乱的变换，本质都是"对齐、拉伸、对齐"三步。奇异值是每个方向的缩放强度——最大的 σ₁ 就是这个矩阵能施加的最大拉伸，2-范数 ‖A‖₂ = σ₁。

## 为什么"通用"：与特征分解的关系

AᵀA 是对称半正定的（第 05 篇），必有正交特征分解——它的特征值开方就是 A 的奇异值，特征向量就是右奇异向量。**SVD 不是新魔法，是把谱定理借给任意矩形矩阵用**。

## 埃克特-杨定理：截断即最优

奇异值按大小排列，天然给出"重要性排序"。取前 k 个：

```text
Aₖ = σ₁u₁v₁ᵀ + … + σₖuₖvₖᵀ        （秩 k 近似，存储从 m×n 降到 (m+n)k）
```

**Aₖ 是所有秩 ≤ k 矩阵中，与 A 误差（Frobenius/2-范数）最小的一个**——这是埃克特-杨定理，SVD 一切应用的理论支柱：丢掉小奇异值 = 丢弃信息最少的部分。

### 三个直接应用

1. **PCA 降维**：数据矩阵 X 去均值后做 SVD，V 的前 k 列就是方差最大的 k 个主轴，投影即降维——"数据椭球"的主轴（第 08 篇展开）
2. **图像/矩阵压缩**：奇异值衰减极快时，前几十项就能保留 99% 能量；灰度图、协同过滤评分矩阵皆然
3. **去噪**：信号集中在大方差方向，噪声平摊在所有方向——截掉小奇异值顺带截掉大部分噪声

## 数值线代里的 SVD：最稳的工具

- **最小二乘**（第 03 篇）：SVD 直接给出伪逆 A⁺ = VΣ⁺Uᵀ，秩亏/病态也稳——`lstsq` 内部就是它
- **条件数**：cond(A) = σ₁/σₙ，一个除法拿到病态程度
- **数值秩**：小于阈值的 σ 视为 0——机器精度下"秩"本来就模糊，SVD 给出最可靠的估计

```python
import numpy as np
U, s, Vt = np.linalg.svd(A, full_matrices=False)
Ak = (U[:, :k] * s[:k]) @ Vt[:k]      # 最优秩 k 近似，一行
```

> [!WARNING]
> SVD 的代价是 O(mn·min(m,n))——比 QR/LU 贵几倍。大规模场景有随机化 SVD（randomized SVD）与增量 PCA 折中；**先想清楚你要的是"精确谱"还是"前 k 个方向"**，后者可以快一个量级。

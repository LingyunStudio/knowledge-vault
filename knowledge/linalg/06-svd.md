SVD（奇异值分解）是线性代数的「万能钥匙」：**任何矩阵**（不必方阵、不必对称）都可分解为「旋转 → 沿正交轴缩放 → 再旋转」。特征分解（[第 5 篇](05-eigen.md)）只对可对角化方阵有效；SVD 对一切矩阵有效——它的普适性让它成为 PCA、最小二乘、降维、压缩、伪逆的共同地基。

## 1. 分解与几何：旋转 → 缩放 → 旋转

```text
A = U Σ Vᵀ
  Vᵀ（输入空间旋转：把输入对齐到「主轴」）
  Σ（沿主轴的纯缩放，缩放因子 = 奇异值 σ₁ ≥ σ₂ ≥ …）
  U（输出空间旋转：把缩放后的主轴对齐到输出）

几何：任何线性变换 = 「先摆正、再拉伸、再摆到目标方向」
```

奇异值 σᵢ 是「主轴方向的缩放倍数」——**非负、按降序排列**。与特征分解的关系：SVD 的奇异值 = AᵀA 特征值的平方根——「奇异值是 AᵀA 这个对称矩阵的特征向量化身」（把任意矩阵的问题转成对称问题——[谱定理](05-eigen.md)的杠杆）。

## 2. 奇异值谱与有效秩

```python
import numpy as np
U, S, Vt = np.linalg.svd(A)      # S 按降序排列
# 奇异值谱：S 的对数图 —— 「衰减到平地」的位置 = 有效秩
```

**奇异值谱是矩阵的「能量谱」**：前 k 个奇异值的平方占比 = 前 k 个方向承载的「能量」（Frobenius 范数的比例）。衰减快 → 矩阵本质上是低秩的（少数方向承载几乎全部信息）；衰减慢 → 信息分散。**有效秩**（数值秩）= 谱上「明显大于噪声底」的个数——比形式秩（[第 2 篇](02-matrices.md)）更贴近数据的真实维度。

## 3. 低秩近似：截断的艺术

```text
最优低秩近似（Eckart–Young 定理）：保留前 k 个奇异值的 SVD
A_k = U[:, :k] Σ[:k] Vᵀ[:k,:]
—— 在所有秩 ≤k 的矩阵中，A_k 与 A 的距离（Frobenius/2 范数）最小
```

```python
# 图像压缩：灰度图 500×500 = 25 万数字
U, S, Vt = np.linalg.svd(img, full_matrices=False)
for k in [5, 20, 50, 200]:
    approx = (U[:, :k] * S[:k]) @ Vt[:k]      # 只存 k·(1+2·500) 个数字
    # k=5：轮廓可辨；k=50：质量良好 —— 25万 → 5万数字（5 倍压缩）
```

低秩近似的哲学：**「把矩阵中最重要的方向保留、其余当作噪声丢弃」**——去噪（小奇异值多是噪声）、压缩（存储只存主方向）、降维（把数据投影到主方向，[第 8 篇](08-ml-perspective.md)）。谱上「拐点」的选择是「信号与噪声」的判断（[统计估计](../prob/05-estimation.md)）。

## 4. PCA：SVD 的 ML 化身

```text
数据矩阵 X（行=样本、列=特征，已中心化）：
X 的 SVD 的 V 的列 = 主成分方向（协方差矩阵的特征向量！）
奇异值²/n = 各主成分的方差

PCA 流程：中心化 → SVD → 投影 X·V[:, :k] —— 降到 k 维
```

PCA 与「协方差矩阵特征分解」（[第 5 篇](05-eigen.md)）等价（XᵀX 的特征向量 = X 的右奇异向量），但 **SVD 数值更稳**（避免 XᵀX 的条件数平方化——[第 7 篇](07-numerical.md)）——「直接对数据做 SVD」是工程正解。PCA 的解读：**找到数据云方差最大的正交方向**（[第 5 篇练习 5](05-eigen.md)的椭圆主轴）——降维 = 沿「信息量最大的方向」投影。

## 5. 伪逆与最小二乘的统一

```text
伪逆 A⁺ = V Σ⁺ Uᵀ（奇异值取倒数、0 保留 0）
Ax=b 的解：x = A⁺b
  满秩方阵：A⁺ = A⁻¹（普通逆）
  超定（无解）：最小二乘解（[第 3 篇](03-solving-systems.md)）
  欠定（无穷解）：最小范数解
  —— 一个公式统一三种命运！
```

SVD 把[线性方程组的全部世界](03-solving-systems.md)统一：**伪逆自动给出「最优的可行解」**（无论超定/欠定/奇异）。数值实现里 `lstsq` 内部就是 SVD——「零空间的检测、病态的钝化（小奇异值截断=正则化）」都在一次分解里完成。截断 SVD 的伪逆（丢掉小奇异值）= **截断 SVD 正则化**——病态问题的正则化手段（[第 7 篇](07-numerical.md)）。

## 6. 陷阱清单

- 以为 SVD 只对可对角化方阵：**任何矩阵都有 SVD**——这正是它的普适价值。
- U、Σ、V 的维度与 full_matrices 参数混淆：thin SVD（经济版）的形状核对。
- 用 XᵀX 特征分解做 PCA（条件数平方）：直接对 X 做 SVD。
- 有效秩的阈值拍脑袋：谱的「拐点/噪声底」观察 + 领域知识。
- 低秩近似后忘了「丢了什么」：截断的残差 = 被丢弃方向上的信息（重要信息在尾部时慎截）。
- 奇异值与特征值混用：SVD 的奇异值 ≥ 0 恒成立、对应任意矩阵；特征值可负可复（方阵）。
- 大矩阵 full SVD 的开销：full_matrices=False；随机化 SVD（近似，大数据标配）。

## 7. 小结

- SVD = 任何矩阵的「旋转-缩放-旋转」分解：奇异值 = 主轴缩放因子（非负降序）——谱定理对任意矩阵的推广。
- 奇异值谱是「能量谱」：衰减速度揭示有效秩与低秩本质；截断 = 最优低秩近似（Eckart–Young）。
- PCA = 数据 SVD 的 V 列（主成分）+ 奇异值²/n（方差）——比协方差特征分解数值更稳。
- 伪逆统一三种解的命运（逆/最小二乘/最小范数）；截断 SVD = 隐式正则化。
- 「降维/去噪/压缩/解方程」四大任务共享同一个 SVD——一个分解服务一整族问题。

## 8. 练习

**1.** 几何验证：取一个 2×2 矩阵做 SVD，用 matplotlib 画「单位圆 → SVD 三步变换后的椭圆」——验证 Vᵀ（圆转正）、Σ（变椭圆）、U（椭圆转到目标方向）。

> [!TIP]
> 思路单位圆经任何线性变换变成椭圆——SVD 就是「椭圆的主轴方向（U 列）与轴长（奇异值）」。圆变椭圆 = 「旋转-缩放-旋转」的最直观演示。

**2.** 图像压缩实验：对一张 512×512 灰度图做 SVD 截断（k=5/20/50/100/200），记录每档的存储量、重建误差（Frobenius）、视觉质量——画出「k-误差」曲线与「奇异值谱」对照。

> [!TIP]
> 思路谱的「拐点」应与误差曲线的「拐点」对应——有效秩的可视化。自然图像的谱衰减快（低秩本质）——「图像可压缩」的线性代数解释。

**3.** PCA 实战：对一个二维相关数据云做「中心化 + SVD」，画出主成分方向（V 的列）与投影后的一维重构——验证第一主成分是「方差最大方向」。

> [!TIP]
> 思路投影回原空间的重构 = 「数据云在主轴上的影子」——降维丢失的是垂直方向（低方差=可能是噪声）。PCA 的「信息 = 方差」假设在这里可见（方差小 ≠ 无用，[第 8 篇](08-ml-perspective.md)的讨论）。

**4.** 伪逆统一验证：对超定/欠定/方阵三个系统分别用 `A@np.linalg.pinv(A)@b` 的思路求解，验证超定给最小二乘解、欠定给最小范数解——一个函数穿越三种命运。

> [!TIP]
> 思路欠定的「最小范数解」选择：无穷多解中挑「最短」的——没有额外偏好时的最保守答案。pinv 的零空间处理（小奇异值截断）自动避免病态放大。

**5.** 数值对比：PCA 用「X 的 SVD」vs「XᵀX 特征分解」两种实现，对相关特征数据（列尺度差异大）对比主成分的稳定性——实证「条件数平方化」的代价（[第 7 篇](07-numerical.md)预告）。

> [!TIP]
> 思路XᵀX 的条件数 = cond(X)²——尺度差异大时特征方向漂移；SVD 直接处理 X 避开平方化。「先升宽再平方」的数值陷阱在 PCA 的经典翻车。

**6.** 讨论：SVD 被称为「线性代数的顶峰」，它的「普适性」到底值多少？从「一个分解服务多任务（降维/去噪/压缩/解方程/子空间）」「任何矩阵可用（理论保证）」「数值稳定（正交变换无误差放大）」三个角度，总结「通用分解」的设计哲学，并对比[特征分解](05-eigen.md)（要求苛刻但语义特定）与 SVD 的分工。

> [!TIP]
> 思路特征分解回答「变换的本质方向」（需要方阵），SVD 回答「矩阵的能量分布」（任何矩阵）——前者语义深、后者适用广。「万能工具」与「专用工具」的共存是数学工具箱的常态：先用 SVD 保底，理解足够后按需用特征结构。

行列式大概是线代里最"公式化"的概念——一堆正负号交错的乘积，背完就忘。还原成几何后它其实非常直观：**行列式就是线性变换对体积的缩放因子**，附带一个符号表示翻转。

## 几何定义：缩放了多少，翻没翻转

2×2 时最好想象：矩阵的两列张出一个平行四边形，行列式 = 它的有向面积。

```text
A = [3 1]     两列围成的平行四边形面积 = 3×2 - 1×0 = 6
    [0 2]     det(A) = 6：单位正方形被拉大了 6 倍

A = [1 2]     det = 1×1 - 2×2 = -3：面积缩 3 倍
    [2 1]     符号为负：空间发生了翻转（e₁→e₂ 的手性反了）
```

三条几何性质立刻可验证，也立刻可理解：

1. det(I) = 1——单位变换不缩放
2. 有一列为零（或两列平行）→ 行列式为 0——**空间被压扁，体积归零**
3. det(AB) = det(A)·det(B)——连续两次变换，缩放因子相乘（翻转两次翻回来，负负得正）

**det = 0 ⟺ 不可逆**从此有了画面：压扁是单向门，被压进直线里的信息再也拿不回来。解方程组（第 03 篇）里"唯一解"的条件，本质就是这一句。

## 计算它：知道公式，但不这么算

2×2 是 `ad−bc`；3×3 起教科书教的代数余子式展开就是 O(n!) 的陷阱——n=20 已经算不动宇宙。真实世界的行列式靠 **LU 分解**：消元成上三角后行列式 = 对角元之积 × 交换次数的符号，O(n³)。

```python
import numpy as np
np.linalg.det(A)     # 底层 LU，O(n³)——但依然要慎用，见下
```

> [!WARNING]
> 实际代码里"用 det 判断矩阵可逆"是个反模式：数值上 det 是 n 个数量级不同的数相乘，浮点下**几乎没有区分度**（10⁻³⁰ 或 10³⁰ 都可能是正常矩阵）。判断可逆/病态请看秩、条件数（第 06 篇）。det 的正确用法是理论分析（特征值乘积、雅可比因子），不是数值判据。

## 它在别处露脸的地方

- **换元积分的雅可比行列式**：重积分换坐标时，det(J) 就是局部面积缩放——极坐标下的 r dθ dr 就这么来的
- **特征值的乘积**：det(A) = ∏λᵢ——所有方向缩放因子的总积（第 05 篇）
- **体积与随机采样**：多元高斯的归一化常数、协方差行列式做椭球体积——统计里的"扩散度"度量（第 prob 板块呼应）

> [!TIP]
> 记忆口诀：**行列式是"变换的性格"**——正负告诉你保不保手性，大小告诉你膨胀还是压缩，零告诉你有没有维度消失。一个数字压缩了一整个变换的全局信息，这就是它的美。

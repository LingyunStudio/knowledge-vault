行列式的几何身份只有一句话：**线性变换对「面积/体积」的缩放因子**——det(A)=3 意味着变换把单位面积放大成 3 倍；det(A)=0 意味着空间被压扁（坍缩到低维）；det(A)=−2 意味着放大 2 倍且翻转了定向。理解了这一句，行列式的所有性质都是几何推论。

## 1. 缩放因子：单位正方形经历了什么

```text
2×2 矩阵 A = [[3, 1], [0, 1]] 作用在单位正方形上：
  e₁=[1,0] → [3,0]，e₂=[0,1] → [1,1]
  单位正方形 → 平行四边形，面积 = |3×1 − 1×0| = 3

det(A) = 3：任何图形的面积都被放大 3 倍
（不只是正方形——线性变换对整个平面的缩放是均匀的）
```

```python
import numpy as np
A = np.array([[3, 1], [0, 1]])
np.linalg.det(A)        # 3.0（可能带浮点尾差）
```

三维的 det = 体积缩放因子；n 维 = 「超体积」缩放。**「面积缩放因子」这个身份让行列式出现在一切「体积」相关的地方**：雅可比行列式（积分换元的局部缩放）、多变量概率密度（[概率篇](../prob/02-random-variables.md)的变量变换）、协方差矩阵的高斯分布归一化。

## 2. 符号：定向的翻转

```text
det > 0：空间保持定向（平面的「逆时针」仍是逆时针）
det < 0：定向翻转（镜像/翻面——纸被翻了过来）

det = -2 的变换：放大 2 倍 + 翻面
（几何上：把 e₁ 与 e₂ 的相对方向关系反转了）
```

定向的实用意义：三维中 det<0 是「左手系与右手系的切换」——图形学里法线方向的翻转、物理中的手性。**符号是「空间是否被镜像」的探测仪**。

## 3. 零行列式：维度坍缩

```text
det(A) = 0 ⇔ 变换把空间压扁到更低维
  ⇔ 列向量线性相关（[第 1 篇](01-vectors.md)）
  ⇔ 不可逆（信息丢失——[第 2 篇](02-matrices.md)）
  ⇔ Ax=0 有非零解（存在被压到原点的方向）
  ⇔ 面积/体积被压缩为 0
```

det=0 的五个等价说法全部连通——**「降维」是它们的共同几何形象**。这就是「行列式是可逆性诊断器」的原因：det=0 的矩阵没有逆（压扁的空间无法恢复——[第 3 篇](03-solving-systems.md)的秩亏损）。

## 4. 性质的几何解释

| 性质                            | 几何解释                                        |
| ------------------------------- | ----------------------------------------------- |
| det(AB) = det(A)·det(B)         | 复合缩放：先放大 det(A) 再放大 det(B)             |
| det(Aᵀ) = det(A)                | 行列式的行/列对称性（转置不改变缩放因子）          |
| 交换两行 → det 取反              | 定向翻转（镜像一次）                             |
| 某行乘 k → det 乘 k              | 一个方向的伸缩直接改变体积                        |
| 某行加上另一行的倍数 → det 不变   | 剪切不改变体积（平行四边形底高不变）               |
| det(I) = 1                      | 恒等变换：什么都不做 = 1 倍缩放                    |

「某行加另一行的倍数 → det 不变」正是高斯消元（[第 3 篇](03-solving-systems.md)）不改变「可逆性判定」的原因——消元是剪切操作（保体积）。

## 5. 计算：小矩阵手算，大矩阵交给分解

```text
2×2：ad − bc                    （对角线乘积相减——够用）
3×3：对角线法则或按行展开       —— 手算上限
n×n：不手算！交给软件（内部用 LU 分解，[第 7 篇](07-numerical.md)）
```

```python
np.linalg.det(big_matrix)        # 内部走 LU：稳定高效
```

手算大矩阵行列式（按行展开的递归）是 O(n!)——纯教学用途。**「理解 det 的几何意义 + 让软件计算」是正确分工**。

## 6. 实际定位：诊断用，而非计算用

```python
# ❌ 生产代码里用 det 判断「是否可逆」：
np.linalg.det(A) != 0            # 浮点下几乎从不是精确 0；接近 0 的阈值无法定
# ✅ 用条件数/秩：
np.linalg.cond(A)                # 病态程度（[第 7 篇](07-numerical.md)）——det=1e-12 可能仍病态不可用
np.linalg.matrix_rank(A)
```

det 的实用陷阱：**它的数值范围无界**（可以 1e-20 也可以 1e20）——「det 多小算不可逆」没有答案。可逆性/病态程度的正确度量是**条件数**（[第 7 篇](07-numerical.md)）：det 告诉你「坍缩没有」，cond 告诉你「多接近坍缩」。行列式的真正高频出场是在**理论推导**（雅可比/密度变换/特征值乘积）——det(A) = 特征值的乘积（[第 5 篇](05-eigen.md)的漂亮连接）。

## 7. 陷阱清单

- 把 det 当「矩阵的一个数」死记计算：先记住「体积缩放因子」。
- 浮点下用 det 判可逆：用 cond/rank；det 的阈值无定义。
- det(A+B) = det(A)+det(B) 的幻觉：只有乘法成立（缩放复合）。
- 大矩阵手算展开：O(n!)；软件内部是 LU。
- 行列式符号与「镜像」的关联缺失：det<0 翻转定向——图形学法线问题的根源。
- 3×3 以上的展开计算练习时间投入过度：几何意义 > 手算速度。

## 8. 小结

- 行列式 = 线性变换的体积缩放因子：>0 保定向、<0 翻面、=0 坍缩——一个数概括「变换对空间的整体作用」。
- det=0 与「线性相关/不可逆/秩亏/零空间非平凡」五说一体——「降维」是共同形象。
- 性质们（乘法/剪切不变/行交换变号）全部是几何事实——理解而非记忆。
- 实用定位：雅可比与概率密度换元的理论角色 + 「诊断可逆性」的粗筛；精诊断用条件数（[第 7 篇](07-numerical.md)）。
- det(A) = 特征值之积——与下一章的漂亮连接（缩放因子 = 各主方向缩放的乘积）。

## 9. 练习

**1.** 面积验证：对 A=[[2,0],[0,3]] 与 B=[[1,1],[0,1]] 分别画「单位正方形的像」，数面积（6 与 1），验证 det 值——建立「det=面积比」的手算直觉。

> [!TIP]
> 思路A 是纯缩放（2×3=6）；B 是剪切（底不变高不变=1——剪切保体积！）。剪切「保 det」的性质在图上最直观。

**2.** 定向翻转实验：矩阵 [[1,0],[0,−1]]（垂直翻转）det=−1——画出基向量变换后的图，验证「镜像但不缩放」；再复合两次翻转观察 det 变回 +1。

> [!TIP]
> 思路两次镜像 = 转回原定向（det=(-1)²=+1）——「镜像不能通过旋转实现」的代数表达。图形学镜像变换的数学根基。

**3.** 雅可比体验：极坐标变换 (x=r·cosθ, y=r·sinθ) 的雅可比行列式是 r——解释为什么极坐标积分面积元是 r·dr·dθ（[概率篇](../prob/02-random-variables.md)的变量变换同款）。

> [!TIP]
> 思路雅可比 det = 「局部小矩形经变换后的面积缩放」——离原点越远（r 越大）同样的 dθ 对应越大的弧长。多元变量变换的「缩放因子」全部由雅可比承担。

**4.** det 的不可靠性实验：构造条件数 10¹⁰ 的矩阵（接近奇异但 det 可能正常）与 det=10⁻²⁰ 但良态的对角矩阵（diag(1e-20, 1, 1)）——理解「det 判可逆的失效」并改用 cond。

> [!TIP]
> 思路diag(1e-20,1,1) 的 det=1e-20 但它只是「一个方向极度压缩」——cond=1e20 才是病态程度的正确度量。行列式是「缩放乘积」而 cond 是「缩放比」——后者才诊断病态。

**5.** det(A)=特征值乘积的验证：取一个矩阵求特征值（numpy.linalg.eigvals），把特征值相乘与 det 对比——「总体缩放 = 各主方向缩放的乘积」的数值确认（[第 5 篇](05-eigen.md)）。

> [!TIP]
> 思路复特征值成对出现（乘积为正实数）——det 的实数性由此保证。「det = 特征值乘积」是连接「缩放因子」与「主方向缩放」的桥梁公式。

**6.** 讨论：行列式在「手算时代」是核心技能（解方程需要 Cramer 法则），在现代为什么退居「理论角色」？从「数值方法绕过 det（LU/cond）」「几何意义的保持」「教学时间分配」三个角度分析——「哪些数学概念值得手算熟练」的判据是什么？

> [!TIP]
> 思路判据：①概念的几何/统计意义是否高频复用（det 的雅可比角色是）；②手算是否增进理解（2×2 是，5×5 不是）；③软件是否完全接管（是）。行列式的「理解它」与「手算它」必须分离——计算外包给软件、直觉留给自己。

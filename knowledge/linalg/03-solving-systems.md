线性方程组 Ax=b 是线性代数的「出口问题」：前面的一切概念（组合、变换、秩）在这里变成「方程组有没有解、有几个、怎么求」。它同时是 ML 最核心的数学（线性回归就是最小化 ‖Xw−y‖ 的最小二乘）。

## 1. 两种图像：行图与列图

```text
方程组：
  2x + y = 3
  x - y = 0

行图（每行一条线）：两条直线的交点 = 解 → (1, 1)
列图（列向量组合）：x·[2,1] + y·[1,-1] = [3,0]
  → 「用列向量的线性组合凑出 b」—— 解就是组合系数！

列图的高维优势：n=100 时「100 条超平面的交点」无法想象，
  「100 个列向量的组合凑出 b」仍然是清晰的代数操作
```

列图与[变换视角](02-matrices.md)的连通：**Ax = b 问的是「哪个输入向量经 A 变换后落在 b 上」**——A 可逆时唯一（反变换回去），A 降维时可能没有或有无穷多（多个输入挤在同一输出）。

## 2. 解的三种命运

```text
命运由秩决定：
① 唯一解：rank(A) = rank(A|b) = n（满秩方阵、b 在列空间内）
② 无解：b 不在列空间里（rank(A) < rank(A|b)）—— 列向量怎么组合都够不着 b
③ 无穷多解：b 在列空间内但 A 秩亏（多个输入映射到同一输出）
   → 解集 = 一个特解 + 零空间（Ax=0 的全部解）
```

用[变换视角](02-matrices.md)一句话总结：**「b 在变换的输出空间里吗？」在 → 有解（输入可能唯一可能多个）；不在 → 无解**。零空间（Ax=0 的解）= 「被压到原点的输入集合」——变换压缩掉的信息（[第 2 篇](02-matrices.md)的秩亏损）。

## 3. 高斯消元：机械而可靠

```text
消元的三个合法操作（不改变解集）：
行交换 / 某行乘非零常数 / 一行减去另一行的倍数

  2x + y = 3      行2×2:  2x - 2y = 0
  x - y = 0  →    相减:     3y = 3  →  y = 1 → 回代 x = 1
```

消元把矩阵变成上三角（逐步消去变量），回代自下而上解出——O(n³) 的工作量。它同时是**秩与可解性的判定器**：消元后出现「0 = 非零」行 → 无解；自由变量出现 → 无穷解。数值实践里用的是它的稳定变体（LU 分配，[第 7 篇](07-numerical.md)），但手算消元是理解「解的结构」的最佳途径。

## 4. 逆矩阵：存在条件与「不该存在」的用法

```text
A⁻¹ 的存在条件：A 满秩（可逆 = 变换可完全撤销 = 无信息丢失）
A⁻¹A = I：先 A 再 A⁻¹ = 恒等变换（什么都没做）

解 Ax=b：x = A⁻¹b  —— 数学上正确
```

数值纪律（与 [C 篇](../c/02-types.md)、[MATLAB](../matlab/08-linear-algebra.md) 一致）：**永远不要显式求逆来解方程**——用 LU 分解/`solve`：

```python
import numpy as np
x = np.linalg.solve(A, b)        # ✅ LU 分解：更快更稳
x = np.linalg.inv(A) @ b         # ❌ 显式逆：多花 O(n³)、数值误差放大
```

「显式求逆」的问题：条件数被平方放大（[第 7 篇](07-numerical.md)）、算出了「你不需要的整个逆矩阵」（只需要解一次方程）。数学公式的 A⁻¹ 是「概念记号」，实现是分解求解。

## 5. 无解的出路：最小二乘与投影

```text
方程多（数据点多）于未知数（参数）→ b 大概率不在列空间内 → 无解
出路：不要求 Ax=b，改求「最近的」Ax ≈ b —— 最小化 ‖Ax − b‖²
```

```text
几何本质（[第 1 篇](01-vectors.md)的投影）：b 在列空间上的**正交投影**
解 p = A·x* 是列空间里离 b 最近的点；残差 (b − p) 垂直于列空间
正规方程：Aᵀ(Ax − b) = 0 → x* = (AᵀA)⁻¹Aᵀb
```

```python
import numpy as np
X = np.array([[1, 1], [1, 2], [1, 3]])   # 数据点（3 个方程 2 个未知数 → 超定）
y = np.array([1, 2, 2])
w = np.linalg.lstsq(X, y, rcond=None)[0]  # 最小二乘解（内部用 SVD，[第 7 篇](07-numerical.md)）
```

最小二乘 = **「把 b 的不可实现部分投影掉，保留可实现部分」**——这就是线性回归（[ML](../ai/02-linear-models.md)）的全部几何：**回归是在列空间里找离 y 最近的点**。残差垂直于列空间的性质是「回归诊断」（残差应无结构）的几何根据。

## 6. 陷阱清单

- 只会行图不会列图：高维问题必须靠列图/变换视角。
- 忘记「无解/无穷解」的存在：满秩方阵只是特例；秩判定解的命运。
- 显式 inv 解方程：数值与性能双重错误；solve/分解。
- 最小二乘的「近似解」误解：它不是「凑合的解」，是「投影意义下的精确最优」。
- 正规方程直接实现（AᵀA 病态）：条件数平方化；用 SVD/QR（[第 7 篇](07-numerical.md)）。
- 混淆零空间与列空间：零空间=被压到 0 的输入、列空间=可达的输出——对偶但不同。

## 7. 小结

- Ax=b 的两种图像：行图（超平面交点，低维直观）与列图（组合凑 b，高维可用）——列图连接变换视角。
- 解的三命运由秩定：b 在列空间内有解（满秩唯一/秩亏无穷）、不在则无解——「可逆性=信息保真度」。
- 高斯消元是解与判定的机械过程；数值实现走 LU/QR/SVD 分解，**显式 inv 是纪律禁项**。
- 无解的出路是投影：最小二乘 = 列空间上的正交投影 = 线性回归的几何本质。
- 「解方程」从「求交点」到「找投影」的扩展，是线性代数通向统计与 ML 的桥梁。

## 8. 练习

**1.** 对同一方程组画行图与列图：2x+y=3, x−y=0——在两张图上分别找到解 (1,1)，验证「交点」与「组合系数」是同一个东西。

> [!TIP]
> 思路行图的 (1,1) 是两线交点；列图的 (1,1) 是「1 份 [2,1] + 1 份 [1,-1] 恰好凑出 [3,0]」的系数。解的双重身份在图上同时可见。

**2.** 解的命运判定：对三个方程组（方阵满秩/超定无解/欠定无穷解）用「秩比较」判定，再用 numpy 的 solve/lstsq 验证（无解时 solve 报错、lstsq 给投影解）。

> [!TIP]
> 思路`np.linalg.matrix_rank` 比较秩；lstsq 对超定/欠定都给最小范数的最小二乘解——「工具的默认行为」要知道：solve 只管唯一解。

**3.** 最小二乘投影验证：用三个数据点拟合直线（[第 5 节]的 X,y），计算残差向量并验证「残差与 X 的每一列点积为 0」——正交性是投影的定义性检查。

> [!TIP]
> 思路`X.T @ (X@w - y) ≈ 0`——正规方程的向量形式。残差「无结构」的几何根源：任何残差中的可解释成分都应已被投影吸收。

**4.** 「显式 inv 的数值灾难」实验：构造一个条件数 10⁸ 的矩阵（[第 7 篇](07-numerical.md)），比较 solve 与 inv@b 的解误差——量化「条件数平方化」的代价。

> [!TIP]
> 思路病态矩阵上 inv 的误差放大 ~10⁸ 倍 vs solve 的 ~10⁴ 倍——「数学等价 ≠ 数值等价」的典型现场（[第 7 篇](07-numerical.md)展开）。

**5.** 零空间的意义实验：构造一个秩 2 的 3×3 矩阵，求零空间（numpy 或手算），验证零空间向量被 A 变换后确实落在原点——「被压缩掉的信息」的具象化。

> [!TIP]
> 思路零空间向量 = 「变换后消失的方向」——它解释了为什么解有无穷多（任何零空间向量加到解上仍是解）。欠定系统的「解自由度」由零空间维度度量。

**6.** 讨论：为什么「超定方程组」（数据多于参数）在实际中是常态而非麻烦？从「数据的统计噪声」（恰好穿过所有点 = 拟合噪声，[ML 过拟合](../ai/01-ml-overview.md)）与「投影解=最优折中」的角度分析——最小二乘的「无解」为什么其实是「特性」？

> [!TIP]
> 思路数据点恰好决定唯一曲线 = 拟合噪声（过拟合的几何形态）；「无解」迫使模型寻找「统计最优的折中」——超定是统计学习的前提结构。无解不是失败而是「噪声存在的数学表达」。

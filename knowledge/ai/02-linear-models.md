线性模型是机器学习的「字母表」：结构最简单（加权求和）、求解最成熟（凸优化）、行为最可解释（系数即贡献）。工程纪律的第一条：**任何新问题先跑线性基线**——它给复杂模型树立「必须打败的门槛」，也常常证明自己就够了。

## 1. 线性回归：拟合加权求和

```text
模型：ŷ = w₁x₁ + w₂x₂ + ... + wₙxₙ + b        （权重 w + 偏置 b）
损失：MSE = (1/n) Σ (yᵢ - ŷᵢ)²                 （均方误差）
```

「拟合」就是**找让 MSE 最小的 w**——一个[凸优化](../linalg/03-solving-systems.md)问题（只有一个全局最优）。两条求解路线：

```python
# 路线①：闭式解（正规方程）—— 直接求导置零
# w = (XᵀX)⁻¹ Xᵀy    —— 一次矩阵运算（[线性代数](../linalg/03-solving-systems.md)的最小二乘）
# 特征多/共线时 (XᵀX) 不可逆或病态 → 数值问题

# 路线②：梯度下降 —— 迭代逼近
w = w - learning_rate * ∂MSE/∂w     # 沿负梯度方向走一小步，重复
```

```python
# sklearn 的封装
from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X_train, y_train)
print(model.coef_, model.intercept_)     # 系数可解释：「每多一间房 +价格 X」
```

## 2. 梯度下降：ML 的通用引擎

```text
地形比喻：损失函数是一片山地（高度=误差），你要走到最低谷。
梯度 = 当前位置最陡的上坡方向 → 反方向走一小步 → 重复
```

```python
# 手写一次（理解机制，[第 5 篇](05-nn-basics.md)的反向传播就是它的多层版）
for epoch in range(1000):
    pred = X @ w + b
    grad_w = 2/n * X.T @ (pred - y)      # 损失对 w 的梯度
    w -= lr * grad_w                      # 负梯度方向更新
```

**学习率（lr）是第一超参数**：太大 → 来回震荡不收敛（跨过谷底）、太小 → 收敛极慢（每步挪一毫米）。变体：**SGD**（每次一个样本，噪声大但快——噪声还有逃离局部平坦区的妙用）、mini-batch（折中，深度学习默认）。梯度下降是**深度学习唯一的训练引擎**（[第 5 篇](05-nn-basics.md)）——在这里理解它一劳永逸。

## 3. 逻辑回归：分类的线性模型

分类要输出「概率/类别」，线性输出是任意实数——套一个 sigmoid 压到 (0,1)：

```text
模型：p(y=1|x) = σ(w·x + b)，σ(z) = 1/(1+e⁻ᶻ)      （S 形，输出概率）
损失：交叉熵 = -[y·log(p) + (1-y)·log(1-p)]          （预测对→损失小，错→惩罚大）
```

为什么不用 MSE 做分类损失？交叉熵的梯度与「预测错误程度」成正比（错得越离谱学得越快），MSE + sigmoid 会有梯度消失（错得离谱也学不动）。「**模型输出概率 + 交叉熵对齐**」是分类的标准组合。

```python
from sklearn.linear_model import LogisticRegression
model = LogisticRegression().fit(X_train, y_train)
model.predict_proba(X_test)          # 输出概率（阈值 0.5 只是默认——可按业务调）
```

「逻辑回归是线性模型」：决策边界（p=0.5 等高线）是线性的——特征与边界的非线性关系靠特征工程（多项式/交叉特征）注入。

## 4. 正则化：给复杂度上税

```text
目标 = 拟合数据 + λ × 模型复杂度惩罚

L2 正则（Ridge）：λ Σwᵢ²          —— 权重整体缩小（保留所有特征，削峰）
L1 正则（Lasso）：λ Σ|wᵢ|         —— 权重稀疏化（把没用的权重压成 0 → 特征选择）
```

直觉：**过拟合的权重通常「大而疯狂」**（[第 1 篇](01-ml-overview.md)的疯狂系数追噪声）——正则化惩罚大权重，迫使模型用「平缓」的方式拟合。λ 是「拟合 vs 简单」的旋钮（λ=0 退回普通回归；λ 太大欠拟合）——验证集调它。

```python
from sklearn.linear_model import Ridge, Lasso
Ridge(alpha=1.0).fit(X, y)            # L2
Lasso(alpha=0.1).fit(X, y)            # L1：系数稀疏化 → 特征选择的副产品
```

正则化的思想贯穿全 ML：决策树限制深度（[第 3 篇](03-trees-ensembles.md)）、神经网络的 dropout/weight decay（[第 5 篇](05-nn-basics.md)）、早停——**全是「容量上税」的不同税种**。

## 5. 特征缩放：梯度下降的隐形前提

```text
特征 A ∈ [0, 1]，特征 B ∈ [0, 100000]（如收入）
→ 损失面是狭长椭圆：梯度下降在 B 方向大幅震荡、A 方向龟速爬行
标准化后：损失面接近圆形 → 各方向均衡收敛
```

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler().fit(X_train)     # 只在训练集 fit！（防泄漏 [第 1 篇](01-ml-overview.md)）
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test)         # 测试集用训练集的 μ/σ
```

纪律：**fit 只碰训练集**（scaler 的 μ/σ 来自训练集）——测试集也 fit 就是数据泄漏。树模型不需要缩放（按阈值分裂，与量纲无关）——线性/神经网络/聚类的必需品。

## 6. 陷阱清单

- 新问题直接上深度学习：线性/树基线先行——基线打不过的复杂模型是自欺。
- 学习率不调：太大震荡太小慢；loss 曲线是最直接的诊断。
- 分类用 MSE：交叉熵是分类的本命损失。
- 缩放器在全集 fit：泄漏；Pipeline 化（[第 10 篇](10-toolbox.md)）防手滑。
- L1/L2 混淆：L1 选特征（稀疏）、L2 稳模型（缩权重）。
- 把系数当因果：「控制了房间数后，地段系数 +X」是相关性语言；因果要实验设计。
- 多重共线性不管：系数不稳定且不可解释；L2 或特征剔除。

## 7. 小结

- 线性回归 = 加权求和 + MSE；闭式解（正规方程，共线时病态）与梯度下降（迭代通用）两条求解路。
- 梯度下降是全 ML 的引擎：学习率是第一超参数，SGD 的噪声是特性；逻辑回归 = sigmoid + 交叉熵（输出概率、线性边界）。
- 正则化 = 容量上税：L2 缩权重、L1 稀疏化选特征；λ 旋钮在验证集上拧。
- 特征缩放是线性/神经网络的前提（fit 只碰训练集）；树模型免疫。
- 工程纪律：线性基线先行——可解释的系数 + 不败的门槛。

## 8. 练习

**1.** 手写梯度下降拟合一维线性回归（不用 sklearn），画「损失随迭代下降」曲线；故意把 lr 调大 10 倍观察震荡——亲历学习率的两面。

> [!TIP]
> 思路损失曲线的形态诊断：正常单调下降、lr 大震荡发散、lr 小长尾缓慢。曲线阅读是训练诊断的第一技能（[第 8 篇](08-training-practice.md)）。

**2.** 闭式解与梯度下降对比：对同一数据分别用正规方程与 sklearn 求解，比较系数——再故意加一组共线特征（x3 = 2*x1）看正规方程的数值不稳（病态，[线性代数](../linalg/03-solving-systems.md)）。

> [!TIP]
> 思路共线性下正规方程系数爆炸（互相抵消的巨大系数）、Ridge 稳定——正则化的数值动机比统计动机更直观。

**3.** L1 vs L2 实验：构造 20 个特征（只有 3 个有用）的回归，各跑 Ridge/Lasso——看 Lasso 把无关系数压到 0、Ridge 只缩小。总结两者的特征选择语义。

> [!TIP]
> 思路L1 的稀疏性来自 |w| 在 0 处的尖角（次梯度直通 0）、L2 的平方在 0 处平缓（只缩不灭）——几何解释比公式好记。

**4.** 概率阈值实验：逻辑回归在一个「漏判代价高」的场景（疾病检测），把阈值从 0.5 降到 0.2——观察 precision/recall 的此消彼长（[第 4 篇](04-evaluation.md)），写出业务化阈值选择逻辑。

> [!TIP]
> 思路阈值是「业务成本」的编码：漏诊（假阴）代价 >> 误报（假阳）→ 降阈值提 recall。0.5 从来不是神圣的。

**5.** 用 Pipeline 重组「缩放+回归」（[第 10 篇](10-toolbox.md)），交叉验证对比「缩放器在全集 fit」的泄漏版——量化泄漏对指标的虚增。

> [!TIP]
> 思路泄漏版的指标虚高来自「测试集信息进入了缩放参数」——小数据集上可达数个点。Pipeline 的结构化防泄漏是 sklearn 的核心设计。

**6.** 讨论：为什么「线性基线」在深度学习时代仍是工程纪律？从「数据规模的匹配」（小数据复杂模型过拟合）、「可解释性的需求」「调试的锚点」三个角度分析，并给出你判断「线性够用」的三个信号（特征线性可分性/数据量/延迟预算）。

> [!TIP]
> 思路线性的不可解释优势：系数即贡献、审计友好（金融/医疗的合规刚需）。判断信号：特征与目标的散点关系近线性/样本量小/推理延迟预算紧。「够用的简单模型」在工程上优于「不透明的复杂模型」。

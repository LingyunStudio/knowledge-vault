线性模型是机器学习的起点，也是工业界至今存活最久的模型之一：训练快、可解释、在特征工程到位时效果不输复杂模型。本章的几个概念——损失、概率输出、正则化——会在后面所有模型里反复出现，值得在这里一次吃透。

## 线性回归：加权求和就是预测

模型假设目标值是特征的加权和：

```python
y_pred = w1 * 面积 + w2 * 房龄 + w3 * 距地铁 + b   # w 是权重，b 是偏置项
```

训练就是找一组 w 和 b，让所有样本的预测误差（通常用均方误差）最小。这个问题有闭式解（最小二乘法），也可以用梯度下降迭代逼近——后者是深度学习的通用套路，在这里先见一面。

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression().fit(X_train, y_train)
print(model.coef_)        # 各特征权重：系数大 → 该特征影响大
print(model.intercept_)   # 偏置项 b
```

线性模型最大的优点直接写在系数里：每个权重就是"其他条件不变时，该特征每变化一个单位，预测值变化多少"。风控、定价这类需要向业务方解释结论的场景，这是硬需求。

## 梯度下降：先在简单模型里认识它

线性回归可以公式直解，但值得故意用迭代法跑一遍——因为这就是所有深度学习训练的原型：

```python
w, b, lr = 0.0, 0.0, 0.01
for step in range(1000):
    y_pred = w * X + b
    grad_w = ((y_pred - y) * X).mean()   # 损失对 w 的梯度（均方误差求导）
    grad_b = (y_pred - y).mean()         # 损失对 b 的梯度
    w -= lr * grad_w                     # 沿梯度反方向小步走
    b -= lr * grad_b
```

三行核心逻辑：算预测 → 算梯度 → 更新参数。第 5 章的神经网络、第 9 章的优化器，讲的都是怎么把这三行做得更聪明：梯度怎么算得快（反向传播）、步子怎么迈得稳（优化器与学习率）。

## 逻辑回归：名字带"回归"，干的是分类

分类任务需要的是概率而不是裸分数。逻辑回归分两步：先算线性分数，再用 **Sigmoid** 函数把分数压到 (0, 1) 区间当概率：

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))      # 把任意实数压到 (0,1)，当概率使用

z = X @ w + b                        # 第一步：线性打分
p = sigmoid(z)                       # 第二步：翻译成"是正类的概率"
y_pred = (p >= 0.5).astype(int)      # 0.5 只是默认阈值，可按业务上下调
```

Sigmoid 曲线两端平滑趋近 0 和 1，中间陡峭——它把"打分高低"翻译成"把握大小"，并让交叉熵损失处处可导。训练目标随之变成：真实为正的样本概率拉高、真实为负的压低（交叉熵损失）。

> [!NOTE]
> 逻辑回归的**决策边界仍然是线性的**。Sigmoid 只是给分数套了概率外壳，分类的分界面依旧是 w·x + b = 0 这张超平面。所以它解决不了异或（XOR）这类非线性问题——想要弯的边界，要么手工造非线性特征（下一节的思路），要么换模型。

## 想要弯的边界：特征变换

线性模型学不了曲线，但可以**先把特征变成非线性的**，再在线性模型里学——比如手动加一列 x²：

```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline
from sklearn.linear_model import Ridge

model = make_pipeline(
    PolynomialFeatures(degree=3),   # 生成 x、x²、x³ 及特征交叉项
    Ridge(alpha=1.0),
)
model.fit(X_train, y_train)
```

模型在"扩展后的特征空间"里仍是线性的，映射回原空间就成了曲线。代价是特征数按阶数组合爆炸（高维小样本，过拟合风险陡增，degree 是必须用验证集调的超参数）。这也是神经网络存在的理由之一：让网络自己学特征变换，而不是人工枚举。

## L1 与 L2 正则化：给权重戴上镣铐

特征一多，线性模型就容易过拟合：把训练集里的巧合当规律，权重抖得很大。**正则化**的思路很直接——在损失函数里加一项"权重大小"的惩罚，逼模型把权重压小：

```text
总损失 = 数据误差 + λ × 权重惩罚
```

两种惩罚方式，性格完全不同：

| | 惩罚项 | 效果 | 适用 |
| --- | --- | --- | --- |
| L2（Ridge） | λ·Σw² | 权重整体缩小，但几乎不为 0 | 默认选择，特征都有点用 |
| L1（Lasso） | λ·Σ\|w\| | 把没用的权重**直接压成 0** | 特征多且大量可能无用，顺带特征选择 |

为什么 L1 能把权重压到恰好为 0 而 L2 不能？直觉：L2 对权重的拉力与权重自身成正比——权重越小拉力越小，永远差最后一口气；L1 的拉力是恒定的，不管权重多小都以同样的力往 0 推，小权重最终会被推穿 0 点。

```python
from sklearn.linear_model import Ridge, Lasso

ridge = Ridge(alpha=1.0).fit(X_train, y_train)   # L2：系数整体变小
lasso = Lasso(alpha=0.1).fit(X_train, y_train)   # L1：系数里会出现真正的 0
```

> [!TIP]
> α（即公式里的 λ）越大约束越强：太小等于没加，太大把信号也压没了。它是典型的超参数，用验证集来选，别拍脑袋。特征量纲不一致时先做标准化，否则惩罚对不同特征不公平——量纲大的特征天然系数小，几乎不受罚。

## 线性模型的边界与生存空间

线性模型学不出弯的边界，这是天花板；但它握着四张底牌：

- **训练快**：亿级样本也能在单机上跑，复杂模型的迭代速度没法比
- **可解释**：系数即结论，能过合规和审计
- **小数据友好**：参数少，几百条样本也能训出像样的结果
- **稳定**：没有复杂的优化过程，结果可复现

所以工程上的真实分工是：表格类、样本少、要解释的任务，线性模型和树模型（下一章）仍是首选；图像、文本这类需要自动学特征的任务，才轮到神经网络出场。别因为"简单"就看不起它——逻辑回归至今活跃在推荐系统和风控的排序层里，亿级特征稀疏打分正是它的舒适区。

> [!WARNING]
> 特征之间高度相关（如"面积"和"房间数"）时，最小二乘的系数会变得不稳定且难以解释——预测可能还不错，但"哪个特征重要"的结论不可信。常规处理是加正则化（Ridge 对共线性的容忍度好得多）或先做特征筛选。

序列数据（文本/语音/时间序列）的建模难题：**变长 + 长程依赖**（第 100 个词依赖第 1 个词）。这条技术线的演化是一条清晰的因果链：RNN 的循环结构（能记但记不长）→ LSTM 门控（记长了但难并行）→ 注意力（直接建立任意距离的连接）→ Transformer（全注意力 + 并行化）——最后一步是 [LLM 时代](../llm/01-what-is-llm.md)的地基。

## 1. RNN：循环的状态机

```text
RNN 的循环：h_t = tanh(W_h·h_{t-1} + W_x·x_t + b)
（隐状态 h 是「记忆」：每一步读入新词、更新记忆）

输入:  x₁ → x₂ → x₃ → ... → xₜ
        ↓     ↓     ↓          ↓
状态:  h₁ → h₂ → h₃ → ... → hₜ      （h 逐步传递）
```

RNN 用**同一个权重**逐步处理序列——天然处理变长、参数量与序列长度无关。它的致命弱点是**长程依赖的训练困难**：梯度沿时间步回传时连乘（[第 5 篇](05-nn-basics.md)的链式法则），小于 1 的导数连乘 100 步 → 梯度消失（远处的信息学不到）、大于 1 → 爆炸。

## 2. LSTM/GRU：门控的记忆

```text
LSTM 的门控设计：
遗忘门：决定旧记忆保留多少        f = σ(W_f·[h,x])
输入门：新信息写入多少            i = σ(W_i·[h,x])
输出门：记忆输出多少              o = σ(W_o·[h,x])
细胞状态：c_t = f⊙c_{t-1} + i⊙候选记忆   （★ 加法更新：梯度 highway）
```

LSTM 的核心补救是**加法式的细胞状态**（c 逐层「加」而不是「乘」）——梯度沿加法通路近似无衰减地流过（与 [ResNet 残差](06-cnn.md)同思想：残差连接就是「加法通路」的架构版）。GRU 是 LSTM 的精简版（两门）。

工程现实：LSTM 在 2017 年前是序列任务的主流——**但它是串行的**（t 时刻依赖 t-1 的状态），GPU 的并行能力被浪费。

## 3. Seq2seq 与信息瓶颈

```text
机器翻译的 seq2seq：
输入句 → [编码器 RNN] → 上下文向量 c → [解码器 RNN] → 输出句

瓶颈：整个输入句被压进「一个固定维度的向量 c」——
长句的信息必然丢失（20 个词的句子压进 512 维）
```

信息瓶颈催生了注意力：**解码器的每一步直接「回看」编码器的全部中间状态**，按相关性加权取用——不再依赖一个压缩向量。

## 4. 注意力：QKV 的直觉

```text
注意力 = 加权的「查字典」：
Query（查询）：我现在（解码到某个词）需要什么信息？
Key（键）：   每个输入位置的「索引标签」
Value（值）： 每个输入位置的实际内容

权重 = softmax(Q·Kᵀ / √d)      ← 查询与每个键的相关度（缩放防 softmax 饱和）
输出 = 权重 · V                 ← 相关内容的加权和
```

直觉版：**在图书馆找资料**——你的问题（Q）与每本书的标签（K）匹配度越高，那本书的内容（V）在你的答案里占比越大。注意力把「固定压缩」变成「按需检索」——**每个输出位置动态地决定关注输入的哪些部分**（且是可微的——注意力权重本身可训练）。

## 5. Transformer：自注意力 + 并行

```text
Transformer 块（[Attention Is All You Need, 2017]）：
x → [多头自注意力] → [+残差&归一化] → [前馈网络] → [+残差&归一化] → 下一块
   （所有位置同时计算注意力——无循环！）
```

**自注意力（self-attention）**：序列内部互相注意——每个位置作为 Query 去查所有位置（包括自己）。「第 3 个词关注第 1 个词」不再需要经过 99 步循环——**任意距离一步直达**（长程依赖问题消失）。多头（multi-head）= 多组 QKV 并行（每组学一种关系：语法/指代/语义）。

位置编码（positional encoding）是必要的补丁：注意力本身「无序」（集合运算），序列顺序信息要显式注入（正弦编码/可学习编码/旋转位置编码 RoPE——[LLM 篇](../llm/03-transformer-llm.md)）。

**取代 RNN 的决定性优势是并行**：自注意力的所有位置同时算（矩阵乘法），训练吞吐量碾压串行 RNN——**大规模预训练（[LLM](../llm/01-what-is-llm.md)）在工程上因此可行**。代价：O(n²) 的注意力计算与显存（序列长度的平方）——长上下文的持续战场（稀疏注意力/FlashAttention/滑动窗口）。

## 6. 陷阱清单

- RNN 处理长序列的幻觉（LSTM 能记住几百步）：梯度流仍是瓶颈；长依赖任务先测注意力。
- 忽略位置信息（Transformer 无序假设）：位置编码缺失时模型是「词袋」（顺序打乱输出不变）。
- 注意力权重的误读（「权重高=因果重要」）：注意力是「模型关注的」不必然是「决策依据」——可解释性要谨慎。
- O(n²) 的长序列暴力：显存与时间的平方爆炸；长上下文用稀疏/窗口/FlashAttention。
- 缩放因子 √d 忘记：点积过大 → softmax 饱和 → 梯度消失。
- 残差与归一化的位置（pre-norm vs post-norm）：深层训练稳定性差异（现代默认 pre-norm）。
- 用小模型硬跑长上下文：先算显存（注意力矩阵 n² × 头数）。

## 7. 小结

- 序列建模的困难：变长与长程依赖；RNN 的循环优雅但梯度连乘限制记忆、串行限制吞吐。
- LSTM 的加法门控是「梯度高速路」思想的首演——残差连接是它的架构化传承（[ResNet](06-cnn.md)）。
- 注意力的 QKV 直觉「按需加权检索」解决 seq2seq 的信息瓶颈；可微且可训练。
- Transformer = 自注意力（任意距离一步直达）+ 多头（多关系）+ 位置编码（注入顺序）——并行化让大规模预训练可行，直接开启 LLM 时代（[LLM 篇](../llm/01-what-is-llm.md)）。
- 架构演化的元规律：**每一步都在解决上一步的特定瓶颈**（记忆→并行→长上下文）——读懂瓶颈就读懂架构史。

## 8. 练习

**1.** 手写一个单头自注意力（numpy）：随机 Q/K/V 矩阵走一遍 softmax(QKᵀ/√d)V——检查输出形状与注意力行和为 1；改变 √d 缩放观察 softmax 的饱和度。

> [!TIP]
> 思路不除 √d 时点积方差随维度增长（d=64 → 点积 ~ 数十）→ softmax 进入饱和区（梯度近 0）。「√d 是注意力的梯度健康保险」。

**2.** 注意力权重可视化：对一个小 Transformer（或在线工具）输入一句话，画注意力热图（词×词）——观察指代消解（"it" 关注哪个名词）与语法关系的学习。

> [!TIP]
> 思路不同头的关注模式不同（有的盯相邻词、有的抓指代、有的看全局）——多头分工的可视化。注意「注意力可视化≠解释」的限定（[第 7 节陷阱]）。

**3.** RNN vs Transformer 的长程依赖实验：构造一个「复制第 1 个 token 到末尾」的任务（序列长 50/200），训练 LSTM 与小型 Transformer——比较两者在长序列上的收敛差异。

> [!TIP]
> 思路LSTM 在 200 长度上明显吃力（梯度经过 200 步连乘）、Transformer 一步直达。「长程依赖」从理论描述变成精度曲线的差异。

**4.** 位置编码实验：把 Transformer 的位置编码去掉（置零），输入「猫追狗」与「狗追猫」观察输出是否相同——验证「无位置编码=词袋」的论断。

> [!TIP]
> 思路注意力对输入集合置换等变——没有位置信息时「猫咬狗」与「狗咬猫」同分。位置编码是 Transformer 表达「序列」而非「集合」的必要注入。

**5.** 用 PyTorch 搭一个迷你 Transformer 块（自注意力+FFN+残差+LayerNorm），数一数参数量与计算量（序列长 n）——验证注意力的 O(n²) 与 FFN 的 O(n·d²) 主导地位。

> [!TIP]
> 思路参数大头在 FFN（4d² 级）；计算在长序列时注意力主导（n²·d）。形状分析（[第 5 篇](05-nn-basics.md)练习 6）在架构成本估算的直接应用。

**6.** 讨论：注意力机制的「万物皆可注意力」现象（视觉 ViT/推荐系统/生物序列）说明了什么？从「注意力 = 可微分的软检索/软路由」的抽象本质分析——它与 [卷积的硬先验](06-cnn.md)在「数据适配性」上的光谱关系，以及「注意力通用但贵」的工程边界。

> [!TIP]
> 思路注意力是「数据依赖的加权聚合」——极弱先验、极强通用性；卷积是「强先验、数据少时高效」。光谱的两端 = 数据量的函数（[第 6 篇练习 6](06-cnn.md)）。工程边界：序列短/结构强 → 卷积/RNN 仍高效；长上下文/多模态 → 注意力统治。

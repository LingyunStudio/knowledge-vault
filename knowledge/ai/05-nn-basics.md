神经网络 = **很多个线性变换 + 非线性激活的堆叠**，用梯度下降（[第 2 篇](02-linear-models.md)）训练。它的威力来自堆叠（深度）与非线性的组合——能逼近任意连续函数；它的训练核心是**反向传播**——链式法则的系统化应用。本篇手把手拆到 numpy 层面。

## 1. 神经元与多层感知机

```text
单个神经元：z = w·x + b；a = σ(z)          （加权求和 + 非线性激活）

多层感知机（MLP）：
x → [线性层1] → σ → [线性层2] → σ → ... → [输出层] → ŷ
    W₁·x+b₁        W₂·a₁+b₂
```

```python
import numpy as np

def forward(X, W1, b1, W2, b2):
    h = np.tanh(X @ W1 + b1)          # 隐层：线性 + tanh
    return h @ W2 + b2                # 输出层（回归：线性输出）
```

**为什么必须非线性激活**：没有 σ 的话，两层线性叠加 = 一个线性变换（W₂(W₁x+b₁)+b₂ = W'x+b'）——再深也只是线性模型（[第 2 篇](02-linear-models.md)）！激活函数（tanh/ReLU）让网络「弯」起来——深度 = 逐层弯曲表达能力。

激活函数速览：**ReLU**（max(0,x)：简单、不饱和、现代默认）、**sigmoid**（(0,1) 概率输出——深层易梯度消失）、**tanh**（(-1,1)）、**softmax**（多分类输出概率分布）。

## 2. 反向传播：链式法则的系统化

训练 = 找让损失最小的权重（梯度下降）——需要**损失对每个权重的梯度**。反向传播就是**从输出层往回，用链式法则逐层算梯度**：

```text
前向：x → [W₁] → h → [W₂] → ŷ → 损失 L
反向：∂L/∂W₂ ← 直接算
      ∂L/∂h  ← ∂L/∂ŷ · ∂ŷ/∂h          （链式：先算「对 h 的敏感度」）
      ∂L/∂W₁ ← ∂L/∂h · ∂h/∂W₁          （继续往回传）
```

直觉：**反向传播把「每个参数对损失的贡献」分层分摊**——梯度像「责任信号」从损失端逐层回传，每层只算自己的局部导数乘以上游传来的信号（计算图的自动微分——[PyTorch](10-toolbox.md) 的 autograd 就是它的通用实现）。

```python
# 手写反向传播（两层网络，交叉熵略——以 MSE 回归为例）
def train_step(X, y, W1, b1, W2, b2, lr=0.01):
    # 前向
    h = np.tanh(X @ W1 + b1)
    pred = h @ W2 + b2
    loss = ((pred - y) ** 2).mean()

    # 反向（链式法则逐层）
    d_pred = 2 * (pred - y) / len(y)      # ∂L/∂pred
    d_W2 = h.T @ d_pred                   # ∂L/∂W2 = ∂L/∂pred · ∂pred/∂W2
    d_h = d_pred @ W2.T                   # 责任传回隐层
    d_W1 = X.T @ (d_h * (1 - h ** 2))     # tanh 的导数：(1 - tanh²)

    # 更新（SGD）
    W1 -= lr * d_W1; W2 -= lr * d_W2; b1 -= lr * d_h.sum(0); b2 -= lr * d_pred.sum(0)
    return loss
```

`d_h * (1 - h**2)` 里藏着 tanh 的导数——**每个激活函数都带着自己的导数参与回传**。sigmoid 的导数最大 0.25（连乘后趋零）——深层网络的「梯度消失」根源；ReLU 的导数是 1 或 0（不缩水）——它成为现代默认的原因。

## 3. 优化器：SGD 的进化

| 优化器   | 机制                                  | 特点                       |
| -------- | ------------------------------------- | -------------------------- |
| SGD      | 沿梯度走                              | 简单、需要好 lr、可加动量   |
| Momentum | 累积速度（惯性）                       | 冲过小坑、加速收敛          |
| Adam     | 自适应每参数学习率（一阶+二阶动量）     | **默认首选**：对 lr 不敏感  |

```python
# Adam 的直觉：给每个参数「自适应的步长」——梯度一直大的参数走小步（防止越界），
# 梯度小的参数走大步（别停）。深度学习的默认优化器（lr=1e-3 起步）。
```

调参的实操顺序：**Adam + lr 1e-3 起步** → 跑通 → 有精力再试 SGD+momentum（泛化有时更好，但难调）。学习率调度（warmup + 余弦衰减）是大模型训练的标配（[LLM 篇](../llm/04-pretrain-sft-rlhf.md)）。

## 4. 正则化三件套

| 手段          | 机制                                     | 直觉                       |
| ------------- | ---------------------------------------- | -------------------------- |
| Dropout       | 训练时随机丢一部分神经元                  | 网络不能依赖任何单一神经元（集成效应）|
| Weight decay  | 权重衰减（L2 的优化器实现）               | 权重别长大（[线性正则化](02-linear-models.md)）|
| BatchNorm     | 每层归一化输入分布                        | 稳定训练、可大 lr；推理用滑动统计 |

```python
# PyTorch 的形态
nn.Dropout(0.5)          # 训练时随机置零 50%
nn.Linear(...)           # weight_decay 在 optimizer 参数里
nn.BatchNorm1d(128)      # 通常放在线性层后、激活前
```

「训练误差好、验证差」的过拟合（[第 1 篇](01-ml-overview.md)）三板斧：**dropout（结构正则）+ weight decay（权重正则）+ 早停**——数据增强是第四板（领域相关：图像翻转/文本回译）。

## 5. 用 PyTorch 重写：同款网络的现代形态

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 64), nn.ReLU(),
    nn.Linear(64, 1),
)
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.MSELoss()

for epoch in range(100):
    pred = model(X_tensor)
    loss = loss_fn(pred, y_tensor)
    opt.zero_grad()          # 清梯度（默认累加！）
    loss.backward()          # ★ 反向传播：autograd 自动算全部梯度
    opt.step()               # 更新

# 三步曲：前向算损失 → backward 自动微分 → step 更新
```

PyTorch 的 **autograd** 让「手推梯度」成为历史——你只写前向计算，反向传播自动完成（[第 5 篇](../cpp/07-templates.md)模板元编程的同思想：编译期/框架期生成机械代码）。`zero_grad` 忘调是新手第一坑（梯度累加，loss 不降反升）。

## 6. 陷阱清单

- 无激活的深层网络：等价于单层线性；每层必须非线性。
- 梯度消失（sigmoid 深层）：ReLU/残差连接（[第 7 篇](07-sequence-attention.md)）。
- 忘 optimizer.zero_grad()：梯度累加，训练发散。
- 数据没 shuffle/没分 batch：mini-batch 的噪声是训练的「探索力」。
- 学习率拍脑袋：loss 曲线诊断（[第 2 篇](02-linear-models.md)）+ lr finder/调度。
- 忽略初始化：权重全 0 → 对称性不破（所有神经元学一样的东西）；默认初始化（Kaiming/Xavier）别乱改。
- BatchNorm 与小 batch 的配合问题：batch 太小统计不稳（考虑 LayerNorm/GroupNorm）。

## 7. 小结

- 神经网络 = 线性层 + 非线性的堆叠：非线性是深度的前提（否则退化为线性模型）；ReLU 是现代默认激活。
- 反向传播 = 链式法则的逐层系统化：梯度从损失回传、每层乘局部导数——autograd 把它自动化。
- 优化器演进：SGD → Momentum（惯性）→ Adam（自适应 lr，默认起步）；lr 调度是大模型的标配。
- 正则化三件套：dropout（结构）/weight decay（权重）/batchnorm（稳定训练）——配早停与数据增强。
- 手写一遍 numpy 反向传播是理解 ML 框架的最短路径——「框架三步曲」背后的每一行都该见过。

## 8. 练习

**1.** 完整手写（numpy）一个两层网络做二分类（含 sigmoid 输出与交叉熵的梯度推导），与 sklearn 的 MLPClassifier 对比精度——验证你的手写实现是对的。

> [!TIP]
> 思路交叉熵对 logits 的梯度 = pred - y（优美的结果，sigmoid 与交叉熵的导数恰好抵消）——这就是「交叉熵是分类本命」的数学原因（[第 2 篇](02-linear-models.md)）。

**2.** 梯度检查：用数值微分（(f(x+ε)-f(x-ε))/2ε）验证你的反向传播梯度——机器学习代码调试的黄金手段（autograd 的正确性自信由此建立）。

> [!TIP]
> 思路相对误差 <1e-6 即正确。手写反传的 bug（如忘记转置）在梯度检查下无处遁形——比「跑起来看效果」科学得多。

**3.** 激活函数实验：同一网络换 sigmoid/ReLU/tanh，比较收敛速度与最终精度——亲历梯度消失（sigmoid 深层不动）。

> [!TIP]
> 思路sigmoid 深层的 loss 几乎不动（每层导数 0.25 连乘）；ReLU 快速收敛。「激活函数的选择 = 梯度流的健康度」。

**4.** dropout 消融：同一个过拟合明显的任务，对比「无正则/dropout/weight decay/早停」四版的训练-验证曲线——画出「验证误差最低点」的漂移。

> [!TIP]
> 思路无正则版训练误差趋 0 验证误差回升（分叉口=过拟合开始）；各正则版分叉点后移。早停的「停在哪」与正则强度联动。

**5.** 学习率扫描：Adam 的 lr 从 1e-5 到 1 扫 6 个数量级，画最终 loss 曲线——找出「甜点区间」，验证「太大发散、太小停滞」的双侧失败。

> [!TIP]
> 思路lr 扫描（LR range test）是训练前的标准动作——曲线的 U 形底就是甜点。大模型训练的 warmup（[LLM 篇](../llm/04-pretrain-sft-rlhf.md)）解决「初始 lr 太大」的同一问题。

**6.** 讨论：为什么「手写一遍反向传播」仍是理解深度学习的不可替代练习？从「调试能力（知道 autograd 里在发生什么）」「架构设计的直觉（每层的形状/参数量与计算量）」「对框架的祛魅」三个角度分析，并说明哪些现代概念（残差连接/注意力）用「矩阵形状检查」就能理解。

> [!TIP]
> 思路手写一遍后，「形状不匹配」「梯度消失」「参数量」都变成可推演的机械问题（如注意力 O(n²) 从矩阵乘的形状直接看出）。框架是杠杆——支点的理解来自手写。

在表格数据（业务数据的主场）上，**梯度提升树（GBDT/XGBoost/LightGBM）至今仍是多数排行榜与工业基线的冠军**——深度学习在图像/文本称王，表格数据是树的天下。本篇从单棵决策树讲到为什么集成能赢。

## 1. 决策树：一连串的 if-else

```text
                [收入 > 5万?]
               /            \
            是/              \否
      [年龄 < 30?]        [拒绝]
       /       \
     是/         \否
  [批准]      [人工审核]
```

决策树就是**学出来的 if-else 树**：每个节点问一个「特征 > 阈值」的问题，叶子给出预测。学习过程是**递归选分裂**：在每个节点，尝试所有特征的所有切分点，选「让子节点最纯」的：

| 指标              | 含义                             | 用于     |
| ----------------- | -------------------------------- | -------- |
| Gini 不纯度       | 随机抽两个样本类别不同的概率      | 分类     |
| 信息增益（熵）    | 分裂后不确定性的减少              | 分类     |
| 方差减少          | 分裂后组内方差的下降              | 回归     |

```python
from sklearn.tree import DecisionTreeClassifier, export_text
tree = DecisionTreeClassifier(max_depth=3).fit(X, y)   # ★ max_depth：防过拟合的第一旋钮
print(export_text(tree, feature_names=names))          # 树本身就是可读的规则！
```

树的过拟合是天然的（无限分裂 = 每个叶子一个训练样本 = 完美记住训练集）：**限制深度/叶最小样本数/剪枝**是纪律（[第 1 篇](01-ml-overview.md)的容量控制）。树的额外红利：**无需缩放、天然处理混合类型、缺失值友好、规则可读**——表格数据的友好度满分。

## 2. 集成学习：三个臭皮匠的两种哲学

单棵树过拟合（方差大）或欠拟合（剪过头偏差大）——**集成（ensemble）**把多个弱模型组合成强模型，两条路线对应偏差-方差的两端：

| 路线       | 哲学                          | 代表          | 治什么 |
| ---------- | ----------------------------- | ------------- | ------ |
| Bagging    | 多个**独立**模型投票平均——方差互相抵消 | 随机森林 | 方差（过拟合）|
| Boosting   | 多个模型**串行纠错**——每个学上一个的残差 | GBDT/XGBoost | 偏差（欠拟合）|

```text
Bagging：100 棵树各自乱学（每人看不同的数据子集）→ 投票 → 个体错误互相抵消
Boosting：树1 学完剩 3 分误差 → 树2 专攻那 3 分 → 树3 专攻剩余……逐步逼近真相
```

## 3. 随机森林：Bagging 的代表作

```python
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=200, max_depth=10).fit(X, y)
```

随机森林 = Bagging + **双重随机**：每棵树看**随机抽样的行**（bootstrap 采样）+ **每个节点只用随机子集的特征**（默认 √p 个）——让树之间尽量「不同」（相关性越低，投票平均消方差的效果越好）。它几乎不需要调参、抗过拟合、开箱即用——**新手表格任务的第一只手**。

## 4. 梯度提升：Boosting 的代表作

```text
GBDT 的迭代：
f₀ = 常数（初始预测）
第 m 轮：计算残差 rᵢ = yᵢ - f_{m-1}(xᵢ)      （当前模型错在哪）
        训练新树 hₘ 拟合残差                  （专攻错误）
        f_m = f_{m-1} + η·hₘ                  （加上新树，η 是学习率）
```

「每棵新树拟合上一轮的**残差**（更准确地说是损失函数的负梯度）」——梯度下降（[第 2 篇](02-linear-models.md)）在函数空间的版本：**每一步在「函数空间」沿梯度走一小步**。树越加越准，但过拟合风险同步上升——小学习率 + 早停 + 限制树深是调参三角。

```python
from xgboost import XGBClassifier
model = XGBClassifier(n_estimators=500, learning_rate=0.05, max_depth=6,
                      early_stopping_rounds=50, eval_set=[(X_val, y_val)])
```

XGBoost/LightGBM 在 GBDT 思想上做了工程化（二阶梯度、正则化项、直方图分裂、并行）——它们是 Kaggle 与工业表格任务的默认答案。**表格数据上打不过 GBDT 时再考虑神经网络**（TabNet 等虽有进展但工程稳定性仍是树的天下）。

## 5. 可解释性：树模型的透明红利

```python
rf.feature_importances_           # 特征重要性（分裂贡献）——但注意「重要性≠因果」

# SHAP：每个预测的逐特征贡献分解（现代标准）
import shap
explainer = shap.TreeExplainer(model)
shap_values = explainer.shap_values(X_sample)
shap.summary_plot(shap_values, X_sample)
```

树模型的可解释性阶梯：**单树可读规则 → feature importance（全局粗粒度）→ SHAP（逐预测的特征贡献，博弈论基础）**。SHAP 解决了 importance 的两大缺陷（偏向高基数特征、只给全局不给出预测）——金融/医疗的模型审计刚需（[线性可解释性](02-linear-models.md)的树版）。

## 6. 陷阱清单

- 单树不限制深度直接用：完美训练误差 + 泛化灾难；max_depth/叶子数纪律。
- 随机森林当万金油不调参：n_estimators 拉大 + 深度限制的基线配置要会。
- GBDT 学习率与树数不联动：小学习率配大树数 + 早停（eval_set）。
- 测试泄漏进目标编码（category encoding 用全量数据）：编码也要 fit 训练集。
- 把 feature_importance 当因果：重要性是「对模型的贡献」，不是业务因果。
- 表格数据无脑上深度学习：先跑 GBDT 基线——大量场景打平或完胜。
- 高基数类别特征裸 one-hot（几万列）：目标编码/frequency 编码/lightgbm 原生类别支持。

## 7. 小结

- 决策树 = 学出来的 if-else：递归选分裂（Gini/熵/方差），过拟合靠深度/叶样本数纪律；可读、免缩放、缺值友好是表格友好度的来源。
- 集成两哲学：bagging 降方差（随机森林：行+列双随机让树互异）、boosting 降偏差（GBDT：逐棵拟合残差/负梯度——函数空间的梯度下降）。
- XGBoost/LightGBM 是 GBDT 的工业形态：表格任务的默认冠军；调参三角 = 学习率×树数×深度 + 早停。
- 可解释性阶梯：规则 → importance → SHAP（逐预测贡献）——审计场景的刚需能力。
- 表格数据的分工地图：GBDT 首选、随机森林做稳健基线、线性模型做可解释基线——深度学习留给非结构化数据。

## 8. 练习

**1.** 用 sklearn 的 export_text 打印一棵浅决策树的完整规则，人工「审计」每条路径的业务合理性——体验树模型的「白盒」能力，并找出一条业务上可疑的分裂（过拟合信号）。

> [!TIP]
> 思路深叶子的规则常是「噪声驱动的分裂」（如「年龄=27.5」这种精确阈值）——训练集的特异样本在树里的痕迹。限制深度后对比规则数量与合理性。

**2.** bagging 效果实验：单独 100 棵深树的测试误差 vs 随机森林（同样 100 棵）——量化「投票平均消方差」的收益；再画「树数量-误差」曲线看边际递减。

> [!TIP]
> 思路单树误差高且方差大（换 seed 波动大）、森林误差稳定降低——「集体的稳定性」可见。曲线平台就是「树够多了」的信号（继续加只费计算）。

**3.** boosting 的残差可视化：手写一个 3 轮的 GBDT 简化版（每轮拟合残差），画每轮预测的演化——看预测如何逐步「逼近」目标。

> [!TIP]
> 思路第 1 轮大偏差 → 每轮残差缩小 → 预测曲线逐步贴合。「boosting = 残差接力」用图看最直观（XGBoost 内部还叠加二阶信息与正则）。

**4.** 类别特征实验：对高基数特征（如用户 ID/城市名）分别用 one-hot（爆炸）/ label encoding（错误序关系）/ 目标编码（泄漏风险）/ LightGBM 原生——对比效果与陷阱（目标编码必须 fit 训练集 + 交叉）。

> [!TIP]
> 思路label encoding 给无序类别注入假序关系（树会按 3>2>1 分裂）——「编码方式的语义错配」是表格任务的暗坑。目标编码的泄漏版实验（[第 1 篇练习 2](01-ml-overview.md)）值得重做一次。

**5.** SHAP 实战：对一个信贷模型画 summary_plot（全局）与单个预测的 waterfall（局部）——回答「模型为什么拒绝了这个申请」——把可解释性从「全局平均」推进到「单例解释」。

> [!TIP]
> 思路SHAP waterfall 的逐特征加减（base value → 最终预测）是监管答辩的语言。「单例可解释性」是树模型在金融风控的统治力来源之一。

**6.** 讨论：为什么表格数据上 GBDT 打得过神经网络？从「归纳偏置的匹配」（表格特征异构无空间/序列结构 vs 神经网络的归纳偏置面向连续结构）、「小样本效率」「类别与缺失值的原生处理」三个角度分析，并说明「表格神经网络的探现」（TabPFN/FT-Transformer）为什么仍不成熟。

> [!TIP]
> 思路神经网络的先验（平移不变/序列连续）在表格上无用武之地——树的不变性假设（特征独立阈值分裂）恰好匹配。TabPFN 等用「预训练+上下文学习」的新范式在尝试破局——但工程稳健性（部署/增量/可解释）仍是树的时代。

把一张 224×224 的彩色图拉平成 15 万维向量喂给全连接网络：参数爆炸、丢掉"相邻像素有关系"这个基本事实，图像稍作平移整个输入就面目全非。卷积神经网络（CNN）用两个设计回应这些问题：**局部连接**和**权值共享**。

## 卷积：一个小窗口扫全图

卷积层用一个小的权重矩阵（**卷积核**，常见 3×3）在图像上滑动，每到一个位置就与覆盖区域做点积得到一个数；扫完整张图，输出一张**特征图**（feature map）。

```python
import torch.nn as nn

conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1)
# 输入 3 通道彩色图 → 输出 16 张特征图
# 参数量：3×16×3×3 + 16 = 448 个
# 若用全连接从 224×224×3 连出 16 个单元，参数约 24 万个还看不到局部结构
```

两件事在这里同时发生：

- **局部连接**：每个输出只看 3×3 的邻域——图像特征本来就是局部的（边缘、色块、纹理）
- **权值共享**：同一个核扫遍全图——"识别竖向边缘"这种能力在左上角和右下角是同一种

一个核只提取一种特征，所以一层通常并列几十上百个核，输出多张特征图。注意：**参数量与图像大小无关，只与核的大小和个数有关**——这是 CNN 能扛住大图的关键。

滑动机制还有三个旋钮：`padding`（边缘补零，控制输出尺寸）、`stride`（步长，大于 1 时输出缩小，可代替池化）、`dilation`（扩张卷积，不增参数地扩大感受野）。平时用默认值就够，读论文时会频繁遇到。

## 层层堆叠：从边缘到语义

CNN 的"深度"有明确的语义：卷积-激活-池化反复堆叠，特征逐层升级：

```text
第 1-2 层：边缘、颜色、简单纹理等低级特征
第 3-5 层：角点、纹理组合、局部形状
更深层：  物体部件 → 整体语义（"这是一只猫"）
```

每往深一层，感受野（一个输出能"看到"的原图范围）就扩大一圈。这种**层级化特征**不是人为设计的，是训练自己涌现的——"深度学习"里"深度"的价值，在图像上体现得最直观。读任何 CNN 论文先看三件事：卷积核多大、通道数怎么变、空间尺寸怎么变——形状表看懂了，网络就懂了七八成。

## 追踪一次前向传播的形状

调试 CNN 的基本功是盯住张量形状：

```python
import torch

x = torch.randn(1, 3, 224, 224)   # (batch, 通道, 高, 宽)
y = conv(x)                       # (1, 16, 224, 224)——padding=1 保住空间尺寸
z = pool(y)                       # (1, 16, 112, 112)——宽高各减半
```

形状对不上是 CNN 报错的头号原因：batch 维忘了带、通道数搞错、空间尺寸差一个像素。整体趋势要记牢：**通道数（特征图个数）随深度增加，空间尺寸随深度减小**——信息从像素空间逐渐搬运到特征空间。形状之外还常看计算量（FLOPs）：一层 3×3 卷积约等于 输入通道 × 输出通道 × 输出面积 × 9 次乘加，它和参数量一起决定模型能不能上端侧。

```python
print(sum(p.numel() for p in conv.parameters()))   # 448：一个卷积层的全部参数，与输入图大小无关
```

## 池化：平移不变性的来源

池化层把小窗口压缩成一个数，最常用 2×2 最大池化：四个值里只留最大的。

```python
pool = nn.MaxPool2d(2)   # 特征图宽高各减半，数据量变为 1/4
```

它带来两个好处。一是**平移不变性**：特征在小范围内挪动一两个像素，池化后的输出不变，模型对"猫在图的左边还是右边"不敏感；二是压缩尺寸，让计算量和感受野同时改善。现代架构也常用步长为 2 的卷积替代池化，效果类似。池化还有均值版本，而分类网络末端的"全局平均池化"（GAP）是它的极端形式：整张特征图直接压成一个数，省掉大块全连接层。

> [!NOTE]
> 平移不变性是一种刻意保留的"不精确"：模型知道这里有只猫，但不纠结它挪了几像素。分类任务要的正是这个；定位、检测任务还需要精确位置信息，所以有专门的架构在特征图上回归框坐标（目标检测的思路）。

## 经典脉络：LeNet → AlexNet → ResNet

CNN 三十年的进化史，浓缩成四个名字：

| 网络 | 年代 | 关键贡献 |
| --- | --- | --- |
| LeNet | 1998 | 确立"卷积+池化+全连接"模板，用于手写数字识别 |
| AlexNet | 2012 | ImageNet 竞赛夺冠引爆深度学习：ReLU、GPU 训练、Dropout |
| VGG | 2014 | 证明"用小卷积核反复堆深度"简单有效：两层 3×3 叠加的感受野等价于一层 5×5，但参数更少、非线性更多 |
| ResNet | 2015 | 残差连接，让上百层的网络可以训练 |

AlexNet 的意义常被低估——它夺冠靠的不只是结构，还有 ReLU、GPU 训练、Dropout 这一整套工程组合拳：深度学习的复兴是算力、数据和算法三者同时到位的结果。

ResNet 则解决了"深度"本身的问题。当时人们发现网络加深后性能不升反降——不是过拟合，而是**退化**：梯度传不回去，深层的参数根本学不动。ResNet 的解法是在层与层之间加一条"捷径"，把输入直接加到输出上：

```python
class Residual(nn.Module):
    def __init__(self):
        super().__init__()
        self.block = nn.Sequential(
            nn.Conv2d(64, 64, 3, padding=1), nn.ReLU(),
            nn.Conv2d(64, 64, 3, padding=1),
        )

    def forward(self, x):
        return x + self.block(x)   # 输出 = 变换(x) + 原始输入，捷径直达
```

这条捷径给了梯度一条无损回传的通道，最坏情况下网络"学成恒等映射"也没有负担。残差连接从此成为所有深层架构的标准组件——包括下一章之后的 Transformer。

## 从特征图到任务输出

主干网络提取的特征图是通用表示，接不同的"头"就变成不同任务：

- **分类**：全局平均池化把特征图压成一个向量，接线性层输出类别
- **目标检测**：在特征图上同时预测"哪里有物体（框）+ 是什么类别"
- **图像分割**：逐像素分类，输出与原图同尺寸的类别图

预训练 + 换头微调之所以普适，正是因为主干学到的东西在不同任务间高度复用。微调时那句最常见的 `model.fc = nn.Linear(512, num_classes)`，换的就是这个"头"。

> [!TIP]
> 今天做图像任务没人从零设计 CNN。正确姿势是拿预训练模型（torchvision、timm 里现成的 ResNet 系列）做**迁移学习**：换掉最后的分类层，用自己的小数据集微调——每类几十张图也能得到体面的效果。

## 适用场景

CNN 的主场是任何"局部结构重要"的数据：图像分类、检测、分割，以及部分音频任务（把频谱图当图处理）。近年视觉 Transformer（ViT）在大数据量场景与 CNN 分庭抗礼，但 CNN 凭借参数效率和对小数据的友好，在工业部署中依然大量使用——端侧、低算力场景尤其如此。判断方法也简单：数据有"网格状局部结构"（像素、频谱、甚至棋盘），卷积就值得先试。

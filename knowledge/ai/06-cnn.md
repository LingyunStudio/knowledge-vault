CNN 的成功不是「网络更深了」这么简单——它的核心是把**图像的结构先验**编码进网络架构：局部相关性、平移不变性、层次组合性。这个「归纳偏置」的设计思想（用架构知识替代海量数据）是理解 CNN 乃至所有架构创新（[注意力](07-sequence-attention.md)）的钥匙。

## 1. 卷积的三个归纳偏置

用全连接层处理 224×224×3 的图像：输入 15 万维 → 第一层就要亿级参数（且相邻像素的关系完全被无视）。**卷积**用三条假设替代暴力连接：

| 先验             | 含义                                   | 卷积的实现                |
| ---------------- | -------------------------------------- | ------------------------- |
| 局部性           | 像素的语义来自邻域（边缘/纹理是局部的）  | 小卷积核（3×3）只看局部    |
| 平移不变         | 猫在左上角与右下角都是猫                | 同一个核滑过全图（权重共享）|
| 层次组合         | 边缘 → 纹理 → 部件 → 物体               | 逐层堆叠，低层特征组合成高层 |

```text
卷积运算：3×3 的核在图像上滑动，每个位置做「对应元素乘加」
输入 5×5 ⊛ 核 3×3 → 输出 3×3（无 padding）
参数量：3×3×通道数（与图像大小无关！）—— 全连接层的亿级 vs 卷积的千级
```

**参数共享**是卷积的效率魔法：一个 3×3 核在整图复用——既拟合了平移不变，又把参数从面积解耦。

## 2. 卷积的参数与尺寸计算

```python
import torch.nn as nn

nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, stride=1, padding=1)
# 输出尺寸 = (输入 - kernel + 2*padding) / stride + 1
# 224×224, k=3, p=1 → 224×224（padding=1 保持尺寸的「same 卷积」惯用法）

nn.MaxPool2d(2)      # 2×2 最大池化：尺寸减半（下采样 + 平移鲁棒性）
```

尺寸三参数：**stride**（步长：>1 即下采样）、**padding**（边缘补零：控制尺寸）、**kernel_size**（感受野原子）。现代网络的趋势是**用 stride=2 的卷积替代 pooling**（下采样同时可学习）。

**感受野（receptive field）**：一个高层神经元「能看到」的输入区域——两层 3×3 卷积的感受野是 5×5、三层是 7×7。深层网络的「看懂整图」靠感受野逐层扩大。

## 3. 经典架构演化：每一步解决一个问题

```text
LeNet(1998)  → 手写数字，CNN 概念验证
AlexNet(2012)→ ImageNet 破局：ReLU + GPU + dropout
VGG(2014)    → 统一 3×3 小核堆深（两个 3×3 = 一个 5×5 感受野，参数更少非线性更多）
ResNet(2015) → ★ 残差连接：解决「深了反而不行」的退化问题
```

**ResNet 的残差连接**是深度学习最重要的架构创新之一：

```python
class ResBlock(nn.Module):
    def forward(self, x):
        return x + self.blocks(x)        # ★ 输出 = 输入 + 变换(x)
```

「让网络学**残差**（F(x) = H(x) - x）而不是完整变换」——最差情况下残差学 0（恒等映射），网络加深至少不变差。梯度的「高速公路」（identity 通路让梯度直达浅层）解决了深层网络的梯度消失与退化——**百层千层网络由此可行**（[Transformer](07-sequence-attention.md) 的残差连接直接继承）。

## 4. 迁移学习：预训练 + 微调

```python
import torchvision

model = torchvision.models.resnet50(weights="IMAGENET1K_V2")   # 预训练权重
for p in model.parameters(): p.requires_grad = False           # 冻结主干
model.fc = nn.Linear(2048, num_classes)                        # 只换最后的分类头

# 只训练新头（小数据）；数据多时解冻部分层微调（小学习率）
```

迁移学习的原理：**预训练学到的「通用视觉特征」（边缘/纹理/部件）可跨任务复用**——你的小数据集只需要学「任务专属的最后几层」。实践配方：

| 数据量        | 策略                                       |
| ------------- | ------------------------------------------ |
| 几百张        | 冻结全部主干，只训分类头                     |
| 几千张        | 解冻后几层微调（小 lr：主干 1e-4、头 1e-3）  |
| 几万张+       | 全网络微调（极小 lr 或分层 lr）              |

「预训练 + 微调」是现代 ML 的范式（[NLP 的预训练](../llm/04-pretrain-sft-rlhf.md)把它推到极致）——**从零训练只在数据与算力充裕时才有意义**。

## 5. 数据增强：图像任务的免费午餐

```python
from torchvision import transforms as T
train_tf = T.Compose([
    T.RandomResizedCrop(224),        # 随机裁剪缩放
    T.RandomHorizontalFlip(),        # 水平翻转
    T.ColorJitter(0.2, 0.2),         # 颜色抖动
    T.ToTensor(), T.Normalize(mean, std),
])
```

数据增强（[第 1 篇](01-ml-overview.md)的正则化第四板）用「保持语义的变换」免费扩充数据——**翻转/裁剪/颜色抖动**是图像标配；注意语义保持的边界（数字 6 翻转变 9、医学影像的翻转可能改变病理）。AutoAugment/RandAugment 是增强策略的自动化。

## 6. 陷阱清单

- 忘记输入归一化（用预训练模型的 mean/std）：预训练模型的输入分布假设被破坏。
- 微调学习率过大：预训练权重被冲垮（灾难性遗忘）；分层小 lr。
- 卷积尺寸算错：same 卷积（padding=(k-1)/2）保持尺寸的惯用法。
- 过早上深网络：小数据先 ResNet18 迁移——架构越大越好是幻觉。
- 增强破坏语义（数字翻转/医学影像旋转）：增强变换要与领域语义一致。
- 忽略类别不平衡（[第 4 篇](04-evaluation.md)）：医学影像的病灶区域占比极小。
- 只看准确率：F1/AUC（[第 4 篇](04-evaluation.md)）+ 混淆矩阵看错分模式。

## 7. 小结

- CNN 的归纳偏置三件套（局部性/平移不变/层次组合）把「图像先验」写进架构——参数共享让参数量与图像面积解耦。
- 尺寸三参数（kernel/stride/padding）与感受野逐层扩大；same 卷积保持尺寸的惯用法。
- 架构演化史 = 问题解决史：AlexNet（工程三件套）→ VGG（小核堆深）→ **ResNet 残差连接**（退化问题——学残差 + 梯度高速路，现代架构的通用组件）。
- 迁移学习是实践标配：冻结/解冻的分层策略按数据量选；预训练权重的输入分布假设要遵守。
- 数据增强是图像的免费午餐——但变换必须保持任务语义。

## 8. 练习

**1.** 手写一个 2D 卷积（numpy 双循环），与 PyTorch 的 Conv2d 输出对齐——理解「滑动窗口乘加」与 padding/stride 的每一步。

> [!TIP]
> 思路先实现 stride=1/padding=0 的朴素版，再加 padding 与 stride——尺寸公式的每个符号都在代码里有对应。手写一遍后「输出尺寸算错」不再是事故。

**2.** 感受野可视化实验：搭一个 4 层 3×3 网络，检查「第 4 层单个神经元的反向梯度在输入图上的分布」（反传一次，看梯度非零区域）——直观验证感受野扩大。

> [!TIP]
> 思路第 1 层神经元的梯度只在 3×3 邻域、第 4 层扩散到 9×9——「高层看全局」的机制图。感受野与「多大物体能被识别」直接相关。

**3.** 迁移学习对照实验：同一小数据集（几千张）跑「从零训练 ResNet18」与「ImageNet 预训练 + 微调」——记录两者收敛速度与最终精度。

> [!TIP]
> 思路预期：从零训练在小数据上精度低且要更多 epoch、迁移版几个 epoch 就超越。「预训练权重 = 别人替你跑的几万 GPU 小时」。

**4.** 数据增强消融：训练/验证曲线对比「无增强/标准增强/过度增强」——验证增强的正则化收益与「语义破坏」的反例（如数字数据集垂直翻转）。

> [!TIP]
> 思路过度增强（把 6 翻成 9）让训练集「语义噪声化」——增强强度也是超参数，且必须过领域语义关。

**5.** ResNet 消融：同一个 20 层网络「有/无残差连接」各训练一遍——复现「无残差的深层网络反而比浅层差」（退化问题）的著名实验。

> [!TIP]
> 思路退化问题（degradation）不是过拟合（训练误差也高）——深层网络的优化困难本身。残差连接让「加深至少不变差」——这是「为什么现代网络都长满残差」的答案。

**6.** 讨论：CNN 的「归纳偏置」与「ViT（视觉 Transformer）」的对比说明了什么？ViT 用更少先验+更多数据达到/超越 CNN——分析「架构先验 vs 数据规模」的交换关系，并与 [线性模型 vs 深度学习](02-linear-models.md)的「归纳偏置匹配数据结构」讨论呼应。

> [!TIP]
> 思路归纳偏置 = 「免费的知识」：先验强时小数据高效（CNN），数据无限时强先验反而限制上限（ViT 的全局注意力更通用）。数据规模与架构先验是可互换的两极——「先验换数据」是架构设计的第一性原理。

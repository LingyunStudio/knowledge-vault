"神经网络"这个名字容易让人联想到大脑，但工程上它就是一件事：把很多个"加权求和 + 非线性"的小函数层层堆叠成一个大函数，再用梯度下降整体调参。本章拆开看它的每个零件，零件都很简单，组合方式才是重点。

## 从一个神经元到一层

单个神经元做三件事：输入加权求和、加偏置、过激活函数：

```python
y = activation(w1 * x1 + w2 * x2 + ... + b)   # 权重 w 决定"多在意"每个输入
```

一"层"网络就是一批并行神经元，写成矩阵形式就是一次矩阵乘法加一次逐元素激活：

```python
import torch
import torch.nn as nn

layer = nn.Linear(4, 8)              # 输入 4 维 → 输出 8 维
out = layer(torch.randn(1, 4))       # 内部就是 x @ W.T + b，输出形状 (1, 8)
```

深度学习框架里所有"层"的底层都是这套矩阵运算，GPU 加速的正是它。所谓"训练网络"，更新的是这些矩阵里的每一个元素。

## 激活函数为什么必需

假设不要激活函数，把两层线性层叠起来会发生什么？

```python
# 第一层：y1 = W1 @ x
# 第二层：y2 = W2 @ y1 = W2 @ (W1 @ x) = (W2 @ W1) @ x —— 还是一次线性变换！
```

线性套线性还是线性——叠一百层等价于叠一层，网络没有任何表达力的提升。**激活函数的非线性是"深度"有意义的前提**：夹在层与层之间把结果"掰弯"，网络才能逼近复杂函数。

最常用的是 ReLU，简单到粗暴：`max(0, x)`——负数归零，正数原样通过。它计算便宜，且在正区间梯度恒为 1，避开了老牌激活函数（sigmoid、tanh）在两端饱和、梯度趋零的毛病。

> [!NOTE]
> sigmoid 和 tanh 并没有因此退役：sigmoid 常用在需要输出概率或门控开关的位置（比如下一章 LSTM 的三个门），tanh 在某些循环网络和传统小网络里仍有市场。它们的问题只在"两端饱和、梯度趋零"，不适合做深层网络的默认中间层激活。

## MLP：堆起来的多层感知机

把"线性层 + 激活"反复堆叠、最后一层线性输出，就是**多层感知机**（MLP），深度学习最朴素的形态：

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 128),   # 输入层：784 维（如 28x28 的图片拉平）
    nn.ReLU(),             # 非线性层
    nn.Linear(128, 10),    # 输出层：10 个类别的分数（logits）
)
```

理论上，一个足够宽的隐藏层就能逼近任意连续函数（万能近似定理）。但"理论上能"和"实际训得动"是两回事——实践中更深的网络往往比更宽的网络更省参数、也更好训练，这是大家不断加深度而不是无限加宽的原因。

输出层那 10 个分数叫 **logits**（原始得分）。训练时把 logits 直接喂给 `CrossEntropyLoss`——它内部先做 softmax 把分数归一化成概率分布，再算交叉熵，一步到位；推理时想要概率，就手动过一次 `torch.softmax(logits, dim=-1)`。分类网络的"最后一公里"长这样，记住能省掉很多困惑。

## 参数有多少：算一笔账

对上面的模型数一数参数：

```python
sum(p.numel() for p in model.parameters())
# 784*128 + 128（第一层）+ 128*10 + 10（第二层）= 101,770
```

约十万参数，放到今天属于"玩具"级别：LeNet 约 6 万，AlexNet 约 6000 万，主流大语言模型在千亿量级。参数量近似代表模型**容量**：太少学不动（欠拟合），太多容易背题（过拟合），训练的艺术就在这两个极端之间找平衡。

## 反向传播：梯度从哪来

训练网络需要回答：损失对上亿个参数中的**每一个**，梯度是多少？答案就是**反向传播**（backpropagation）。它不是新的优化方法，只是高效计算梯度的算法：

1. **前向传播**：输入沿网络逐层计算，得到输出和损失
2. **反向传播**：从损失出发，沿计算图**反向**用链式法则逐层算出每个参数的梯度——中间结果全部复用，总代价约等于一次前向
3. **参数更新**：优化器沿梯度反方向小步调整参数

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
criterion = nn.CrossEntropyLoss()

out = model(x_batch)         # 1. 前向：算预测
loss = criterion(out, y_batch)
loss.backward()              # 2. 反向：autograd 沿计算图算出所有参数的梯度
optimizer.step()             # 3. 更新：每个参数 -= lr * 梯度
optimizer.zero_grad()        # 清空梯度，准备下一批（不清会累加，经典 bug）
```

> [!TIP]
> 你不需要手推反向传播公式，框架的 autograd 会替你完成。但必须理解它的含义：**只要损失可导，任何网络结构的梯度都能自动算出来**——这是深度学习能"端到端训练"的根基，换损失、换结构都不用改求导代码。

## 完整的训练循环：epoch 与 batch

把概念对齐：数据集太大无法一次算完，实际按 **batch**（一小批样本，如 64 条）切片更新参数；全部数据完整过一遍叫一个 **epoch**。

```python
for epoch in range(10):                      # 全量数据过 10 遍
    for xb, yb in train_loader:              # 每次取一小批
        out = model(xb)
        loss = criterion(out, yb)
        loss.backward()                      # 反向传播
        optimizer.step()                     # 更新参数
        optimizer.zero_grad()                # 清空梯度
    evaluate(model, val_loader)              # 每个 epoch 结束在验证集上评一次
```

batch 大小、epoch 数量都是超参数。训练代码的骨架就是这十几行——深度学习工程的复杂度不在循环本身，而在数据和评估。

## 神经网络的位置

MLP 是通用积木：全连接的它对输入结构一无所知，图片拉平、文本对齐都能塞进去——但也因此浪费了数据的结构信息，参数效率低。以 MNIST 为例：把 28×28 的图拉平成 784 维向量，左右相邻像素的关系在输入里已经荡然无存。

后续两章的 CNN 和序列模型，本质上都是**给 MLP 加上结构先验**：CNN 假设"相邻像素相关"，序列模型假设"相邻时刻相关"。先验对了，需要的参数和数据就少。而表格数据没有这种可利用的结构，所以树模型至今仍是那里的王者——第 4 章的结论没有过时。

选型记忆法：结构化表格 → 树集成；图像 → CNN；序列 → Transformer 系；拿不准 → 先跑基线再说话。

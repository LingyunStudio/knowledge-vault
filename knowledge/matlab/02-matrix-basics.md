MATLAB 没有独立的"标量、向量、数组"类型：一个数是 1×1 矩阵，一行数是 1×N 行向量，一切数据都是矩阵。这个统一模型是它语法简洁的根源——把创建、下标、冒号切片练熟，MATLAB 的地基就打好了。

## 创建矩阵

```matlab
A = [1 2 3; 4 5 6]        % 分号换行、空格/逗号分列 → 2×3
v = 1:2:9                 % 起点:步长:终点 → [1 3 5 7 9]
w = 10:-2:1               % 步长可为负 → [10 8 6 4 2]
z = zeros(3, 1)           % 全 0，预分配的常用件
I = eye(3)                % 单位矩阵
R = randn(2, 3)           % 标准正态；rand 是 [0,1) 均匀分布
```

函数建矩阵给两个参数是"行×列"，给一个参数则是方阵：`zeros(3)` 是 3×3。常用建矩阵函数速查：

| 函数 | 作用 | 典型场景 |
| --- | --- | --- |
| `zeros(m,n)` / `ones(m,n)` | 全 0 / 全 1 | 预分配、初始化 |
| `eye(n)` | 单位阵 | 线性代数 |
| `linspace(a,b,n)` | [a,b] 等距取 n 点 | 画图取样（比冒号可控） |
| `rand / randn / randi` | 随机数三件套 | 造测试数据 |
| `diag(v)` | 向量放对角 | 构造对角阵 |
| `magic(n)` | 幻方 | 演示、出题 |

等距取样优先 `linspace`：它保证端点与点数精确；而 `0:0.1:0.3` 这类小数步长有累积误差，末点可能取不到。`size(A)` 返回 [行, 列]，`numel(A)` 数元素个数，判断"有没有元素"用 `isempty(A)`。

## 下标从 1 开始

下标从 **1** 开始，不是 0。这是从数学传统一脉相承的设计，也是所有人第一天都会写错的地方：

```matlab
A = [1 2 3; 4 5 6];
A(1, 1)          % ✅ 左上角元素，值 1
% A(0, 1)        % ❌ 索引必须为正整数，直接报错
A(end, end)      % end 是该维度最后一个下标 → 6
A(4)             % 线性索引：按列展开后第 4 个 → 5
```

矩阵在内存里**按列存储**（列优先），所以 `A(4)` 数到的是第 2 列第 2 行。线性下标与行列下标可互换：

```matlab
[r, c] = ind2sub(size(A), 4)   % 线性下标 4 → 行列下标 (2, 2)
k = sub2ind(size(A), 2, 3)     % 行列下标 (2, 3) → 线性下标
```

> [!WARNING]
> 读取越界会报错，但**写入越界不报错**：`A(2,4) = 9` 会把 A 自动扩成 2×4，空位补 0，并触发整块内存重新分配。循环里无意识的越界写入既是性能杀手，也是错误结果的常见来源。

`end` 关键字在切片里几乎无孔不入，它代表"该维度的末尾"，比写死尺寸的代码更抗修改——数组变长变短都不用改下标。

## 冒号切片

冒号是 MATLAB 的灵魂运算符，切片、步进、翻转一气呵成：

```matlab
A(:, 2)              % 第 2 列（整个维度）
A(1, :)              % 第 1 行
A(1:2:end, :)        % 奇数行，步长 2
A(:, end:-1:1)       % 列倒序（水平翻转）
A(2, :) = []         % 赋空即删除该行
A(1:2, 1) = 0        % 标量自动扩展，一次改多个位置
```

逻辑掩码与冒号并列为核心习惯——用一个同尺寸的逻辑矩阵直接筛选：

```matlab
x = [3 -1 4 -1 5];
x(x > 2)             % [3 4 5]，掩码筛选
sum(x > 0)           % 3：逻辑值求和即计数
A(A < 0) = 0         % 把所有负元素清零
```

掩码索引天然替代"循环 + if"，这是 MATLAB 写法的分水岭，性能话题在[稀疏与性能](09-performance.md)展开。三维及更高维数组同理：`A(:,:,1)` 取第一页，`cat(3, A, B)` 沿第 3 维拼接，图像处理里 `A(:,:,1:3)` 取 RGB 三通道就是这么来的。

切片语义要先想清楚：MATLAB 的切片是**拷贝**，不是视图：

```matlab
b = A(:, 1);         % b 是一份新数组
b(1) = 99;           % 改 b 不影响 A，A(1,1) 仍是 1
```

与 NumPy 的视图语义相反。好处是不会误改原矩阵，代价是大数组的切片拷贝有内存成本，频繁切片要掂量。

函数传参同理：数组传进函数是传值拷贝，函数内改动不会影响调用方的变量——结果一律靠返回值带出，这是 MATLAB 函数的通用约定，也顺手避免了大量的隐式耦合。

## 拼接、变形与转置

拼接用方括号：横向拼要求行数一致，纵向拼要求列数一致：

```matlab
B = [A, A]           % 横向拼接 2×6（逗号可换空格）
C = [A; A]           % 纵向拼接 4×3
D = repmat(A, 2, 3)  % 按 2×3 块平铺
E = reshape(A, 3, 2) % 改形状，元素仍按列依次排
col = A(:)           % 全部拉成一列向量，超高频用法
```

`reshape` 不搬数据只改"形状标签"，但元素顺序永远按列优先——结果"看起来乱了"时，先想想列优先。翻转也有具名版本：`flipud` 上下翻、`fliplr` 左右翻，语义比 `end:-1:1` 更可读。转置有两个，含义完全不同：

```matlab
G = [1+2i, 3];
G'        % 共轭转置：转置且每个元素取共轭 → [1-2i; 3]
G.'       % 纯转置：只换行列，不动复数 → [1+2i; 3]
```

> [!NOTE]
> 实数矩阵下 `A'` 与 `A.'` 结果相同，所以这个坑在复数场景才炸——比如信号处理里对复频谱转置，用错符号会悄悄引入共轭。建议养成习惯：只想"换行列"就写 `.'`。

行向量与列向量也是转置的日常：`1:5` 是行向量，`(1:5)'` 才是列向量。很多函数结果的形状跟随输入方向，代码里保持向量方向一致（比如统一用列向量），能省掉大量补救用的 `'`。

> [!TIP]
> 拼接或运算报"维度不一致"时，第一反应永远是 `size(A)` 逐个查。眼睛会骗人，size 不会；确认尺寸后再回头修代码，比盯着报错干瞪眼快得多。

MATLAB = **Mat**rix **Lab**oratory。这个名字就是它的世界观：语言里没有一个「裸标量」——`x = 5` 创建的是 1×1 矩阵；字符串是字符矩阵；函数默认逐元素作用于整个矩阵。为「把矩阵当数来算」而生的语言，这正是数值计算（线性代数是它的核心）需要的形状——1970 年代 Cleve Moler 给学生写的教学工具，最终变成工程与科学计算的行业标准。

学 MATLAB 的正确姿势是**先接受它的默认值**：下标从 1 开始、存储列优先、乘法就是矩阵乘法（逐元素要另加个点）。这些「怪癖」全部服务于同一个目标——让数学式子几乎原样翻译成代码。

## 1. 三层交互：命令窗、脚本、函数

MATLAB 的使用形态是「命令行 + 脚本」的双轨：

```matlab
% 命令窗（Command Window）：即时求值，像计算器
>> A = [1 2; 3 4]
A =
     1     2
     3     4
>> det(A)
ans =
    -2
```

- **命令窗**：交互实验——试一行、看结果、改一行。`ans` 是未赋值结果的自动接收者。
- **脚本（.m 文件）**：顺序执行的一段代码，共享基础工作区（base workspace）——像「预先敲好的命令序列」。
- **函数（.m 文件）**：有独立工作区，参数进出——**真正的程序单元**（[第 5 篇](05-functions.md)）。

```matlab
%% demo.m —— 脚本：分节（%%）可单独运行（Ctrl+Enter）
x = linspace(0, 2*pi, 100);      % 100 个点铺满 [0, 2π]
y = sin(x);
plot(x, y)                        % 立即出图
```

工作流惯例：**命令窗试语法、脚本攒逻辑、函数装抽象**。编辑器里的 `%%` 分节（cell mode）是 MATLAB 特有的「分步执行」——写脚本像写实验记录。

## 2. 一切皆矩阵：类型的默认值

```matlab
x = 5;                class(x)      % double —— 1×1 矩阵
s = 'hello';          size(s)       % 1×5    —— 字符矩阵（char 数组）
v = [1, 2, 3];        size(v)       % 1×3    —— 行向量
c = {1, 'a', [2 3]};  class(c)      % cell —— 元胞数组：装任意东西的容器
st = struct('n', 1);  class(st)     % struct —— 结构体
```

| 类型       | 是什么             | 什么时候用                     |
| ---------- | ------------------ | ------------------------------ |
| `double`   | 双精度矩阵（默认）  | 一切数值计算                    |
| `single`   | 单精度             | 大数组省内存/GPU                 |
| `int8..64` | 整型（运算有溢出！）| 图像像素、需要整型语义的接口      |
| `char`     | 字符矩阵            | 短文本；长文本用 string（R2016b+）|
| `string`   | 字符串数组          | 现代文本处理                     |
| `cell`     | 异构容器           | 不同类型/尺寸的东西装一起         |
| `struct`   | 带字段的结构        | 命名数据（记录）                 |
| `table`    | 列式表格            | 表格数据（统计/导入，[第 7 篇](07-data-io.md)）|

「标量即 1×1」的推论：`size(5)` 是 `[1 1]`；`x(1)` 合法（矩阵有第一个元素）；`sum(5)` 是 5。**不要和这个模型对抗**——它是全语言函数签名统一的原因（`sin` 接受任何形状的 double 数组并逐元素作用）。

## 3. 1-based 索引与列优先：两个默认值的来历

### 3.1 下标从 1 开始

```matlab
v = [10 20 30];
v(1)        % 10 —— 第一个是 1 不是 0
A = [1 2 3; 4 5 6];
A(2, 3)     % 6 —— 第 2 行第 3 列
A(6)        % 6 —— 线性索引：按列数第 6 个（列优先！）
A(4)        % 4 —— 线性索引的第 4 个 = 第 2 列第 1 个
```

数学传统（线性代数里第 1 行第 1 列）+ 简单实现（FORTRAN 底子）——对学过数学的人这是「自然」，对学过编程的人是「别扭」。**混用两种语言时（MATLAB↔Python/C）这是头号 bug 源**：翻译公式时下标跟着数学走（+1），翻译代码时才用 0-based。

### 3.2 列优先存储（column-major）

```matlab
A = [1 2 3; 4 5 6];
A(:)          % [1; 4; 2; 5; 3; 6] —— 展开顺序：先列后行
```

MATLAB 内存里矩阵按**列**连续存放（沿袭 FORTRAN）。工程含义：

- `A(i, :)` 取一**行**要跨列跳（不连续），`A(:, j)` 取一**列**连续——大规模数据时「按列操作」缓存友好。
- 线性索引与子矩阵的混用、`reshape` 的形状解释，全部以列优先为基准。
- 与 C/NumPy（行优先或类似 C 序）交换二进制数据时要注意转置或用 `reshape` 参数声明顺序。

## 4. 为什么是 MATLAB：数值计算的生态位

MATLAB 的竞争力不在语言（语法确实古旧），在**「数值计算的全家桶闭环」**：

| 层         | 提供的东西                                       |
| ---------- | ------------------------------------------------ |
| 语言       | 矩阵为一等公民、自动内存管理                       |
| 内核       | LAPACK/BLAS（分解、求解的工业标准实现）直接可用     |
| 可视化     | plot/surf/交互图表内置，无需第三方                 |
| 工具箱     | 信号、控制、图像、优化、Simulink——领域模型全家桶    |
| 硬件       | 支持代码生成 C/CUDA、与硬件（Arduino/FPGA）直连     |

「数学公式 → 代码」的距离最短：`x = A\b` 就是解线性方程组，`fft(x)` 就是傅里叶变换——工程验证原型、控制系统仿真、信号处理教学是它的统治区。开源对位的是 Python + NumPy/SciPy（[python 篇](../python/01-python-model.md)）：语法更现代、生态更开放，但「矩阵即语言」的一体化体验与 Simulink 这类领域工具仍是 MATLAB 的护城河。

## 5. 帮助系统

```matlab
doc plot         % 完整文档（图形界面，最详细）
help det         % 命令行速查
lookfor eigen    % 按关键词搜函数名
% 函数名后悬停 F1；编辑器里 F1 同 doc
```

MATLAB 文档质量极高（示例可复制运行）——**先 doc 后写码**是高效路径。每个工具箱的「Getting Started」文档值得通读。

## 6. 陷阱清单

- Python/ C 与 MATLAB 互译时下标差 1：读公式用数学下标、写代码前先定「这次用谁的约定」。
- 线性索引忘了列优先：`A(4)` 不是第 4 行——先列后行。
- `i`/`j` 被覆盖：`for i = 1:10` 之后 `i` 是 10 不是虚数单位；需要复数时用 `1i`（更稳）或恢复 `clear i`。
- 标量思维写代码：忘了「函数自动矩阵化」，`if x > 0` 对向量报错（要用 `if all(x > 0)` 或逻辑索引）。
- clear 滥用清理工作区：脚本里 `clear all` 拖慢运行还可能删掉需要的；交给工作流管理。
- 分号丢失刷屏：语句尾不加 `;` 会打印结果——脚本里每条赋值带分号。
- 把 MATLAB 当通用语言：字符串处理、Web、并发不是它的主场；数值计算之外的活用配套语言。

## 7. 小结

- 一切皆矩阵：标量是 1×1、char 是矩阵、函数默认逐元素——类型模型为「数学式直译」服务。
- 三层工作流：命令窗试、脚本攒（%% 分节）、函数装抽象；ans 接收未赋值结果。
- 1-based 索引与列优先存储是两个必须内化的默认值——跨语言互译时的头号 bug 源。
- 生态位：数值计算的全家桶闭环（LAPACK 内核 + 可视化 + 工具箱 + Simulink + 代码生成）；Python+NumPy 是开源对位。
- doc/help/lookfor 是文档三件套——MATLAB 文档是它的核心竞争力之一。

## 8. 练习

**1.** 在命令窗里验证「一切皆矩阵」：分别对 `5`、`'h'`、`[1 2]` 执行 `size`、`class`、`ndims`，解释每个结果。

> [!TIP]
> 思路`size(5)=[1 1]`、`class(5)='double'`；`'h'` 是 1×1 char；`[1 2]` 是 1×2 double。标量/向量/矩阵的区分在 MATLAB 里只是「形状」差异，类型层面都是数组。

**2.** 构造一个 3×4 矩阵，分别用 `A(7)` 线性索引与 `A(2,3)` 下标索引取到同一个元素，用 `A(:)` 验证列优先顺序。

> [!TIP]
> 思路列优先展开 `A(:)` 后，线性下标 = 展开向量的下标：`A(7)` = 展开后第 7 个 = 第 2 列第 3 个 = `A(3,2)`。sub2ind/ind2sub 两个函数在两种索引间转换。

**3.** 用 `%%` 分节写一个脚本：生成 1 秒的 1kHz 采样正弦波、画图、播放（sound）。体会「脚本即实验记录」的工作流。

> [!TIP]
> 思路`fs=1000; t=0:1/fs:1; y=sin(2*pi*440*t); plot(t(1:100), y(1:100)); sound(y, fs)`。分节执行让「采样参数调整→重画→重放」的循环丝滑——这是 MATLAB 交互式开发的核心体验。

**4.** 把同一个数学式子分别用 MATLAB 与 Python+NumPy 写出：`y = e^{-x²/2}`，注意下标约定、逐元素运算符（`.*` vs `*`）与数组创建的差异，列一张互译对照表。

> [!TIP]
> 思路MATLAB：`x=linspace(-3,3,100); y=exp(-x.^2/2)`；NumPy：`x=np.linspace(-3,3,100); y=np.exp(-x**2/2)`。对照表维度：下标起点、逐元素符号、列/行优先、文档入口。这张表值得长期维护。

**5.** 探索 doc：读 `doc colon`（冒号运算符的完整语义）与 `doc punct`，找出三个「从没用过但很常用」的语法点。

> [!TIP]
> 思路常见收获：`a:step:b` 的负步长、`end` 关键字（`x(end-2:end)`）、`.'` 与 `'` 的区别。MATLAB 的「符号函数」文档（doc punct）是语法速查的金矿。

**6.** 讨论：你的课程/团队为什么选 MATLAB（或为什么不该）？从「领域工具（Simulink/工具箱）、开源要求、团队既有代码、学习曲线」四个维度给出选型论证。

> [!TIP]
> 思路选型不是语言优劣题而是生态匹配题：控制系统教学（Simulink 无替代）、企业授权成本、Python 的通用性引力。「用 MATLAB 写 Web 后端」与「用 Python 复刻 Simulink 仿真」都是错位——工具与任务对齐是元答案。

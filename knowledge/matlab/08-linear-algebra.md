MATLAB 的 `\` 是整个软件的招牌：一个符号背后是**根据矩阵结构自动选择的标准算法**（LAPACK）。本篇讲它的调度逻辑、决定数值精度的条件数、五大分解的选型，以及稀疏矩阵——理论细节在[线性代数篇](../linalg/01-vectors.md)，这里是工程操作与判断。

## 1. \ 的调度逻辑：为什么从不用 inv

```matlab
x = A \ b;              % 解 Ax = b
x = b / A;              % 解 xA = b（行向量版）
```

`\` 内部的决策树（你从不手写这些选择）：

```text
A 的形态                    走的算法                       复杂度
三角阵                      直接回代                        O(n²)
对称正定                    Cholesky（chol）                 O(n³)/3
带状/稀疏                   稀疏 LU/Cholesky                 视稀疏度
一般方阵                    LU 分解 + 前后代入                O(n³)
长方阵（m>n）               QR 最小二乘                      O(n²m)
长方阵（m<n）               欠定（正则化/基础解）              警告
```

对比错误姿势：

```matlab
x = inv(A) * b;         % ❌ 显式求逆：多一次 O(n³)、数值稳定性差、算了一堆你不要的逆
```

**inv 只在理论里**——工程上解方程永远 `\`（文档原话级别的纪律）。要解多个右端项 `A \ [b1 b2 b3]`（一次分解多次回代，这也是 `\` 相对重复求解的效率优势）。

## 2. 条件数：解「靠不靠谱」的预报器

```matlab
cond(A)              % 条件数：κ = σmax/σmin（2 范数）
rank(A)              % 秩
norm(A) / norm(A, 'fro')     % 各类范数
```

条件数的含义：**输入的相对误差最多被放大 κ 倍**。κ=100 的系统解出 8 位有效数字已经不错（double 有 16 位）；κ=10¹⁰ 的系统解出的数字基本是噪声。

```matlab
A = [1 1; 1 1.0001];  b = [2; 2.0001];
x = A\b                % x = [1; 1] —— 但把 b 微扰一点点：
A \ [2; 2.0002]        % x = [0; 2] —— 解天翻地覆（cond(A)≈4×10⁴）
```

工程纪律：**解大系统前先 `cond`（或估算 `rcond`）**——病态时先怀疑建模（数据尺度差几个量级？行/列几乎线性相关？），缩放（对角预处理）常能把 κ 降几个数量级，比换算法有效。

## 3. 分解家族：五大件的选型表

```matlab
[L, U, P]  = lu(A)     % LU：一般方阵、多次求解
[R, p]     = chol(A)   % Cholesky：对称正定（p=0 即验证了正定性！）
[Q, R]     = qr(A)     % QR：最小二乘、正交基、数值最稳
[V, D]     = eig(A)    % 特征分解：AV = VD（动力学/主成分）
[U, S, V]  = svd(A)    % 奇异值分解：秩/条件数/伪逆/降维的全能选手
```

| 需求                           | 选     | 理由                                |
| ------------------------------ | ------ | ----------------------------------- |
| 反复解 Ax=b（固定 A）           | lu/chol | 分解一次，回代多次                   |
| 对称正定（刚度阵/协方差阵）      | chol   | 快一倍 + 正定性检验副产物             |
| 最小二乘（长方阵）              | `A\b` 或 qr | QR 稳定；\ 自动选                |
| 振动模态/稳定性分析             | eig    | 特征值即固有频率/增长率               |
| 数据降维/噪声估计/求有效秩      | svd    | 奇异值衰减画像即「能量谱」             |

## 4. SVD 实战：秩、伪逆与降维

```matlab
[U, S, V] = svd(A);
s = diag(S);                        % 奇异值：按降序
plot(s, 'o-'); set(gca, 'YScale', 'log')    % ★ 奇异值谱：衰减到「平地」的位置 = 有效秩

tol = max(size(A)) * eps(max(s));   % MATLAB 的秩判据（rank 内部就是这么算的）
r = sum(s > tol);                   % 有效秩

A_r = U(:,1:r) * S(1:r,1:r) * V(:,1:r)';   % 截断 SVD：最佳秩 r 近似（Eckart–Young 定理）

% 图像压缩的一页演示：
img = im2double(imread('cameraman.tif'));
[U,S,V] = svd(img);
for r = [5 20 50]
    imshow(U(:,1:r)*S(1:r,1:r)*V(:,1:r)'); title(sprintf('rank %d', r))
end

pinv(A)                 % 伪逆：SVD 的直接应用（病态/奇异系统的「正则化解」）
```

奇异值谱（对数轴）是数据科学最有信息量的图之一：**衰减越快 → 数据有效维度越低 → 截断越激进**。

## 5. 稀疏矩阵：结构化省略

```matlab
% 满矩阵存 n=10⁵ 的三对角阵 = 80GB；稀疏存 ≈ 3×10⁵×16B ≈ 5MB
A = sparse(i, j, v, n, n)      % (行,列,值) 三元组建
A = spdiags(B, d, n, n)        % 带状构造（差分算子的标配）
spy(A)                          % 看稀疏模式（结构一眼可见）

x = A \ b;                      % ★ \ 对稀疏自动走稀疏算法（迭代/稀疏LU）
nnz(A) / numel(A)               % 稠密度；full(A)/sparse(A) 转换
eigs(A, 5, 'largestabs')        % 稀疏特征值（eig 对稀疏不适用）
```

纪律：**矩阵维度过千且非零元素占比低（<10%）就该 sparse**——「从满矩阵意外落到稀疏」会让内存与时间同时爆炸。注意 `sparse * full` 结果自动稀疏、满矩阵运算会「稀释」稀疏性（`A + rand(n)` 变满）——稀疏性是需要维护的属性。

## 6. 数值稳定性的三个体感

1. **尺度差 = 病态温床**：行向量量纲相差 10⁶（米 vs 微米）→ κ 爆炸。预处理（行归一化/列均衡）是免费的精度。
2. **正规方程 AᵀAx = Aᵀb**：条件数变成 κ²——数学等价、数值不等价。长方阵最小二乘走 QR（`\` 自动做）。
3. **迭代法的收敛看谱**：Jacobi/Gauss-Seidel 收敛与否由迭代矩阵谱半径决定（[线性代数篇](../linalg/05-eigen.md)）——`eigs` 可以直接估算。

## 7. 陷阱清单

- inv(A)*b：慢且不稳；永远 `A\b`。
- 病态系统直接信结果：解前 cond；κ 大先查数据尺度与冗余列。
- chol 对非正定矩阵报错当「麻烦」：它是免费的对称正定性检验；p>0 的位置就是「非正定开始处」。
- 稀疏与满混算稀释稀疏性：构建时就 sparse；混合运算后 nnz 复查。
- eig 用于稀疏大矩阵：内存爆炸；eigs（Lanczos 类迭代）。
- 最小二乘用正规方程手写：κ² 代价；QR（即 `A\b` 对长方阵）。
- 忘记列优先对「按行遍历大矩阵」的惩罚：大循环按列走（或先转置让内层沿列）。

## 8. 小结

- `\` 是结构感知的求解调度器：三角回代、Cholesky、稀疏 LU、QR 最小二乘全自动；inv 在数值线性代数里没有位置。
- 条件数 κ 是「输入误差放大倍数」——解之前看 cond，病态先修数据（缩放/去冗余）再修算法。
- 分解选型：反复求解 lu/chol、正定检验 chol、最小二乘 qr、模态 eig、降维与秩 svd；SVD 谱是有效秩的可视化。
- 截断 SVD 是图像压缩/去噪/降维的统一形态；pinv 是它的解析推论。
- 稀疏矩阵的收益在「构建时决定」：spdiags/spy/nnz 是日常三件套，eigs 处理稀疏特征问题。
- 数值稳定性的工程体感：尺度均衡、避免 κ² 的正规方程、按列访问大数组。

## 9. 练习

**1.** 构造随机 1000×1000 系统，比较 `A\b`、`inv(A)*b`、`[L,U]=lu(A); U\(L\b)` 三种解法的耗时与精度（残差范数），解释差异来源。

> [!TIP]
> 思路\ 与显式 lu 差不多（都做 LU），inv 多一步且损失精度（乘逆矩阵）。`norm(A*x-b)` 是唯一诚实的精度指标——比「看起来对」强一万倍。

**2.** 构造 Hilbert 矩阵（hilb(10)），观察 cond 随维度的爆炸（hilb(12) 已超 double 有效范围）；解一个 Hilbert 系统并检查残差与真实解的偏差——「残差小 ≠ 解准确」的现场演示。

> [!TIP]
> 思路残差 ‖Ax−b‖ 衡量的是「满足方程」，解的误差是 κ 倍放大后的输入误差——病态时残差漂亮而解离谱。这就是「数值精度讨论必须区分残差与误差」的原因。

**3.** 用 SVD 做图像压缩链：读入图像 → 不同秩的截断重建 → 画出「秩 vs 重建误差与压缩比」曲线，找出拐点。

> [!TIP]
> 思路压缩比 = (m·r + r + r·n)/(m·n)；误差 = 被丢弃奇异值的平方和的根。曲线的拐点（误差停止快速下降处）就是「数据的有效秩」——SVD 谱分析的操作化版本。

**4.** 把一维泊松方程（−u'' = f）差分离散成三对角系统，用 spdiags 构建稀疏矩阵求解，与满矩阵版本对比内存与耗时（n = 10⁵）。

> [!TIP]
> 思路三对角 = spdiags(repmat([a b c],n,1),[-1 0 1],n,n)。满矩阵 10⁵ 需要 80GB（装不下）而稀疏几十 MB——「稀疏不是优化，是可行性」的证明。

**5.** 给病态系统「治病」：构造行向量尺度差 10⁶ 的最小二乘问题，比较直接 `A\b`、行归一化后再解、qr 三者的解与 cond 变化。

> [!TIP]
> 思路行归一化（每行除以自身范数）把 κ 常降几个数量级——数据预处理是数值稳定性的第一杠杆，比换分解类型有效。

**6.** 讨论：为什么 MATLAB 文档说「inv 几乎不该被使用」，但教科书的公式全是 A⁻¹B？从「数学表示 vs 数值实现」的层次差异分析，再举一个「公式里写逆、代码里用分解」的对位表（伪逆、协方差、二次型）。

> [!TIP]
> 思路数学的 A⁻¹ 是「满足 AA⁻¹=I 的算子」概念，不必真的造出矩阵。对位：解方程 A⁻¹b→A\b；A⁻¹B→A\B；A⁻¹AB→实为相似变换的分解视角。公式是意图声明，代码是稳定性实现——两层语言的翻译能力就是数值素养。

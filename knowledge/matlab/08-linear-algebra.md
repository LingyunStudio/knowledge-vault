解方程组、求特征值、算相关系数，是 MATLAB 的老本行，也是它起家的理由。这一篇要背的口号只有一句：**别求逆**——反斜杠 `\` 就是答案。

## 解 Ax=b：三种方式

```matlab
A = [2 1; 1 3];
b = [5; 10];
x = A \ b          % 左除：一行解出方程组
```

| 写法 | 做法 | 评价 |
| --- | --- | --- |
| `A\b` | 内部自动选分解算法 | ✅ 首选：快且数值稳定 |
| `inv(A)*b` | 先求逆再相乘 | ❌ 慢一个量级，精度更差 |
| `pinv(A)*b` | 伪逆 | 奇异、秩亏矩阵的兜底 |

`\` 的聪明之处在于看矩阵下菜：方阵走 LU 分解（对称正定走 Cholesky 加速），超定方程直接返回最小二乘解，欠定方程返回基本解——这些分支你完全不用管。

```matlab
A = [1 1; 1 2; 1 3];       % 3×2，超定（方程比未知数多）
b = [1; 2.1; 2.9];
x = A \ b                  % 直接得到最小二乘拟合的 [截距; 斜率]

r = A*x - b;               % 残差：拟合好坏看 norm(r)
```

右除 `b/a` 是 `x*a = b` 的解，等价于 `(a'\b')'`；实际代码里九成五的场合只需要 `\`。

> [!WARNING]
> `inv(A)*b` 不只是慢：显式求逆把条件数放大一次，数值稳定性更差，条件数大的矩阵解会明显偏离。教科书用 inv 讲原理可以，工程代码里见到它就该起疑。

## 特征值与分解

```matlab
A = [4 1; 2 3];
e = eig(A)                 % 特征值向量
[V, D] = eig(A)            % V 各列是特征向量，D 对角存特征值
A*V - V*D                  % 验证：残差在机器精度级即正确
```

对称矩阵有实特征值且特征向量正交，数值上也更稳，处理前可先对称化 `As = (A + A')/2`。广义特征值问题同样一行：

```matlab
[V, D] = eig(A, B)         % A·v = λ·B·v，振动模态分析的标配
```

SVD 是最贵也最万能的分解：

```matlab
s = svd(A)                 % 奇异值，降序排列
[U, S, V] = svd(A);        % A = U*S*V'
```

一句话记住各分解的用途：**LU** 解线性方程，**Cholesky** 对称正定加速，**QR** 最小二乘与正交化，**SVD** 万能——低秩逼近、主成分、伪逆都从它出。

> [!WARNING]
> 用 `det(A) == 0` 判断方阵奇异是经典错误：浮点下行列式对尺度极其敏感，几乎不会精确等于 0。判断奇异或病态用 `rank(A)` 或 `cond(A)`。

## 拟合：polyfit 的本质

多项式拟合是"构造矩阵 + 最小二乘"的教科书案例，polyfit 一行搞定，但值得知道它的里子：

```matlab
t = (0:0.1:2)';  y = 3*t.^2 + 0.5*t + 1 + 0.2*randn(size(t));

p = polyfit(t, y, 2)       % 二次拟合，系数从高次到低次
yfit = polyval(p, t);      % 代回求值

% polyfit 的本质：凡德蒙矩阵 + 反斜杠
V = [t.^2, t, ones(size(t))];
coef = V \ y               % 结果与 polyfit 一致
```

理解了这一层，遇到加权拟合、鲁棒拟合、自定义基函数时，就能自己搭矩阵交给 `\`，而不是四处找现成函数。

## 矩阵体检速查

| 操作 | 函数 | 备注 |
| --- | --- | --- |
| 范数 | `norm(x)` / `norm(A)` | 向量与矩阵两种语义 |
| 秩 | `rank(A)` | 按数值容差数非零奇异值 |
| 条件数 | `cond(A)` | 1 最好，越大越病态 |
| 行列式 | `det(A)` | 理论用，判断奇异见上文警告 |
| 逆 | `inv(A)` | 演示用；解方程永远 `\` |
| 伪逆 | `pinv(A)` | 奇异、秩亏时的兜底 |
| 零空间 | `null(A)` | Ax=0 解空间的标准正交基 |
| 迹 | `trace(A)` | 对角元之和 |
| 正交基 | `orth(A)` / `qr(A)` | 列空间正交基 / 正交三角分解 |

## 统计速查

所有聚合函数默认**按列**（dim=1）操作，按行算显式传 dim=2：

```matlab
A = randn(100, 4);         % 100 个样本、4 个变量
mu = mean(A)               % 1×4，每列均值
sd = std(A)                % 每列标准差，默认除以 N-1
sd0 = std(A, 1)            % 除以 N：总体标准差
med = median(A)            % 中位数，抗离群点
rowMax = max(A, [], 2)     % 每行最大值
[sm, si] = min(A)          % 同时返回极值所在行号
c = corrcoef(A)            % 4×4 列间相关系数矩阵
C = cov(A)                 % 协方差矩阵，与 corrcoef 同源
cs = cumsum(A)             % 累积和，尺寸不变
m = movmean(x, 5)          % 5 点滑动均值（R2016a+），时间序列常用
```

> [!NOTE]
> `std` 默认归一化除以 N-1（样本标准差），与多数统计软件一致；要总体口径记得 `std(x, 1)`。`corrcoef` 算 Pearson 相关，约定每一列是一个变量、每一行是一个观测。

生成测试数据的常用件：`rand`（均匀）、`randn`（标准正态）、`randi(10, 3, 4)`（整数矩阵）、`randperm(n)`（随机排列）。写示例和冒烟测试时先造随机数据，比硬编码三行数更能暴露边界问题。

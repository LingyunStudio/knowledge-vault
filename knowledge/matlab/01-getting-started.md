MATLAB = Matrix Laboratory，整套设计都围绕矩阵与数值计算展开。开工前先花十分钟搞清两件事：界面四区各管什么，"命令行试探、脚本沉淀"的分工怎么用——后面所有章节都建立在这个工作流上。

## 界面四区

默认布局四块，各司其职：

| 区域 | 职责 | 关键操作 |
| --- | --- | --- |
| 命令行窗口 | 即输即算 | 敲表达式回车执行 |
| 工作区 | 查看当前变量 | 双击变量打开表格编辑器 |
| 当前文件夹 | 文件管理器 | 双击 .m 文件进编辑器 |
| 编辑器 | 写脚本/函数 | 新建脚本 Ctrl+N，运行 F5 |

工作区里用 `whos` 看变量清单（名字、大小、类型、占用内存），比肉眼扫列表快：

```matlab
clear; clc; close all    % 经典开场三连：清变量、清屏、关图窗
x = rand(3);

whos
%  Name      Size            Bytes  Class
%  x         3x3                72  double
```

布局被拖乱后在"布局"菜单选"默认"一键复原；字体、缩进、配色在"预设项"（偏好设置）里改，一次配置长期受益。

## 命令行与脚本

**命令行适合试探**：验证函数用法、看一眼矩阵形状、算个数。**脚本适合流程**：可保存、可复现、可迭代的分析步骤。实验代码最终都要落进脚本，命令行历史不算成果。

```matlab
% 命令行里试探：
A = magic(3)      % 不加分号：回车后回显结果
b = sum(A, 1);    % 加分号：执行但抑制输出，适合中间步骤
```

分号是 MATLAB 的第一个"性格设定"：加分号抑制输出，不加则回显。正式代码的中间步骤一律加分号，调试时再临时摘掉看中间值。

脚本是一列按顺序执行的语句，运行方式三种：编辑器按 F5、命令行敲文件名、右键 Run。脚本运行在**基础工作区**，产生的变量直接留在工作区里——所以脚本开头 `clear` 是好习惯，保证每次运行状态干净。想要"文字 + 代码 + 结果"同屏的笔记形态，用实时脚本（.mlx），详见[控制流与脚本](04-control-flow.md)。

脚本里用 `%%` 划分节（Cell），光标放某节内 Ctrl+Enter 只运行该节：

```matlab
%% 第 1 节：读数据
M = readmatrix('data.csv');

%% 第 2 节：画图
plot(M(:, 1), M(:, 2), '-o')
```

> [!TIP]
> 命令行里按 ↑ 翻历史命令，先敲前几个字母再按 ↑ 只翻匹配项；Tab 补全函数名和变量名。这两手练熟，试探效率翻倍。

## help 与 doc

MATLAB 的文档质量是它的核心竞争力，查文档的能力比背函数名重要得多：

```matlab
help sum          % 命令行速查：调用格式 + 一句话说明
doc sum           % 完整文档页：参数表、算法说明、可复制的示例
lookfor integral  % 只记得关键词时按内容搜函数（全库扫描，偏慢）
```

`doc` 是主入口。每个函数页底部都有 Examples 区，示例可以直接复制运行——学一个新函数的最快路径是先跑示例，再回头读参数说明。

```matlab
help          % 不带参数：列出按主题分类的帮助目录
help elmat    % 矩阵主题下的函数清单，当目录用
```

> [!NOTE]
> 帮助浏览器支持全文搜索，并内置各主题入门教程（如 "Matrix Indexing"）。进陌生领域先在文档里搜主题词，往往比网上零散搜索更成体系。

## 当前目录与搜索路径

MATLAB 按固定顺序找文件（脚本、函数、数据）：

1. 先找**当前文件夹**（`pwd` 查看，`cd` 切换）
2. 再按**搜索路径**（path）里的目录逐个找

```matlab
pwd                       % 显示当前目录
cd('D:\proj\matlab')      % 切换目录（写正斜杠 D:/proj 也行）
which mean                % 查看 mean 实际调用的是哪个文件
addpath('D:\proj\lib')    % 把自己的工具目录加进搜索路径
savepath                  % 保存路径修改，重启后仍有效
```

`which` 是排查"函数行为不对"的第一反应：它告诉你实际生效的是哪个版本，而不是你以为的那个。

项目组织建议：一个项目一个文件夹，脚本、数据、输出都放里面，靠"当前目录"解决九成的文件查找问题；`addpath` 留给跨项目共用的工具函数，别把搜索路径堆成一锅粥。

> [!WARNING]
> 变量会遮蔽同名函数：`sum = 3` 之后，`sum(A)` 直接报错，因为查找时变量优先于内置函数。永远别用 sum、max、mean、table 这类名字当变量名；中招后 `clear sum` 解除。

## 显示格式与命名细节

`format` 只改显示精度，不影响内部计算：

```matlab
format long     % 显示 15 位有效数字
pi              % 3.141592653589793
format short    % 默认 4 位小数，改回去
```

三条铁规矩提前立好：索引从 **1** 开始（不是 0）；变量名区分大小写；`ans` 是未赋值表达式的默认去向——依赖 `ans` 传值的代码很脆弱，正式代码永远显式赋值。写长语句用行尾 `...` 续行，多行注释用 `%{` 与 `%}` 单独成行包裹：

```matlab
s = 1 + 2 + ...      % 行尾三个点：下一行是本行的延续
    3 + 4;           % s = 10

%{
块注释：中间几行
都不参与执行
%}
```

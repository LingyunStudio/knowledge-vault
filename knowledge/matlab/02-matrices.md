MATLAB 的生产力来自两个「肌肉记忆」：**快速造出需要的矩阵**与**精准取出需要的数据**。本篇把这两件事的全部惯用形态过一遍——重点是**逻辑索引**（MATLAB 最优雅的特性）与**形状函数族**（reshape/repmat/cat）。

## 1. 创建矩阵：六族方法

```matlab
% ① 手工：方括号内，空格/逗号分列，分号分行
A = [1 2 3; 4 5 6];
v = [1, 2, 3];                 % 行向量（1×3）
col = [1; 2; 3];               % 列向量（3×1）

% ② 冒号：等差序列（起:步长:终）
1:5             % [1 2 3 4 5]
0:0.5:2         % [0 0.5 1 1.5 2]
10:-2:2         % [10 8 6 4 2]  步长可为负

% ③ 等距/对数等距：指定「点数」而不是「步长」
linspace(0, 1, 11)      % 11 个点铺满 [0,1]（含端点！）
logspace(-2, 2, 5)      % 10^-2 到 10^2 的对数等距

% ④ 常量/特殊矩阵
zeros(3, 4)     ones(2)     eye(5)      % 单位阵
magic(4)        diag([1 2 3])           % 对角阵
meshgrid(x, y)  % ★ 2D 网格坐标（画曲面/二维场的标配）

% ⑤ 随机
rand(3)         % [0,1) 均匀
randn(3)        % 标准正态 —— 仿真/蒙特卡洛的主角
randi([1, 6], 2, 5)   % 2×5 的随机整数（骰子）

% ⑥ 拼接：方括号即拼接运算符
[A, B]          % 水平拼接（列数增加）＝ [A B]
[A; B]          % 垂直拼接（行数增加）
cat(3, A, B)    % 沿第 3 维叠（多维数组的通用拼接）
repmat(A, 2, 3) % 平铺复制：2×3 块
```

选型直觉：**实验造数据用 randn/linspace，算法初始化用 zeros/eye（预分配！），构造结构用拼接**。linspace 与冒号的分工：**知道点数用 linspace，知道步长用冒号**（两者端点语义不同：`0:0.1:1` 可能不含 1（浮点），`linspace(0,1,11)` 必含）。

## 2. 索引：三种体系与 end

### 2.1 下标与范围

```matlab
A = magic(4);
A(2, 3)             % 单元素：第 2 行第 3 列
A(1:2, :)           % 前 2 行全部列
A(:, [1 4])         % 全部行的第 1、4 列
A(end, :)           % 最后一行（end = 该维的最后一个下标）
A(end-2:end, 2)     % 最后一行的上两行同列（相对索引）
```

### 2.2 逻辑索引：MATLAB 的灵魂语法

「条件成立的位置」直接当下标用——**过滤、替换、提取一气呵成**：

```matlab
v = [5, -3, 8, -1, 0];
v(v > 0)                 % [5 8] —— 取出所有正数
v(v < 0) = 0             % 把负数置零 —— 就地条件替换
A(A > 5)                 % 矩阵同样适用（结果按列优先拉成列向量）

% 找位置而非取值：
[row, col] = find(A > 10);    % 满足条件的坐标
idx = find(v < 0);            % 线性下标

% ismember/ismember 类谓词与逻辑索引的组合是数据处理的主力：
data(data.StatusCode == 500, :)     % 表格式过滤（数组版）
```

逻辑索引的等价物在 Python 是布尔掩码（NumPy 同款思想）——**「按条件说话」优于「按下标算术」**：可读、免边界计算、不怕尺寸变化。MATLAB 代码向量化（[第 9 篇](09-vectorization.md)）的一半技巧就是逻辑索引。

### 2.3 线性索引与转换

```matlab
A(6)                 % 按列数第 6 个元素
sub2ind([3 4], 2, 3) % (行,列) → 线性下标
ind2sub([3 4], 7)    % 线性下标 → (行,列)
```

## 3. 修改：赋值、扩展、删除

```matlab
A(1, 1) = 99;
A(3, :) = [1 2 3 4];        % 整行赋值
A(5, 5) = 1;                % ⚠️ 越界赋值 = 自动扩展（补 0）——隐式增长性能杀手
B = A;  B(:, 2) = [];       % 删除第 2 列（[] 赋值即删除）
C = A([1 3], :);            % 提取行（原矩阵不动）

x = [];
x(end+1) = 5;               % ⚠️ 循环里逐步追加 = 每次重分配 —— 预分配（[第 9 篇](09-vectorization.md)）
```

「越界自动扩展」是 MATLAB 的便利与陷阱的结合体：写起来方便，循环里用就是 O(n²) 内存拷贝。**数组尺寸先定后填（zeros 预分配）**是性能纪律。

## 4. 形状操作：size / reshape / transpose

```matlab
size(A)          % [行 列]
size(A, 1)       % 行数；length(v) = max(size(v))（向量长度）；numel = 总元素数

B = reshape(A, 2, 6);      % 重排形状（元素按列优先重新填）
A.'                        % 非共轭转置（换位置）
A'                         % 共轭转置（复数时会取共轭！实数时两者相同）

repmat([1 2], 2, 1)        % 平铺
squeeze(M(1, :, :))        % 去掉长度为 1 的维度（多维数组常用）
flipud(A)  fliplr(A)  rot90(A)     % 翻转旋转
```

`A'` 与 `A.'` 的区分是复数世界的暗雷：信号处理里向量是复数，`'` 会共轭——**纯转置一律写 `.'`** 是安全习惯。

## 5. 元胞与结构体的访问语法

```matlab
C = {1, 'text', [1 2 3]};   % 元胞：异构容器
C{3}          % [1 2 3] —— 花括号：取「内容」
C(3)          % 1×1 cell  —— 圆括号：取「元胞」（仍是容器）
C{2}(1:2)     % 'te'      —— 链式：取元胞内容再切片

S = struct('name', {'a','b'}, 'score', {90, 85});
S(1).name     % 'a' —— 结构体数组按 .字段 访问
[S.score]     % [90 85] —— 汇总字段
```

`{}` 与 `()` 的分工一句话：**花括号解包、圆括号保包装**。cellfun/arrayfun 可以对元胞/数组逐元素应用函数（[第 9 篇](09-vectorization.md)）。

## 6. 陷阱清单

- 冒号与 linspace 的端点差异：`0:0.1:1` 因浮点可能缺尾点；要确定性点数用 linspace。
- `A'` 对复数共轭：纯转置写 `.'`。
- 循环里 `x(end+1)=` 追加：每轮重新分配；zeros 预分配。
- 越界赋值静默扩展数组：意外扩出巨大矩阵；赋值前确认 size。
- 逻辑索引结果形状：矩阵的掩码索引拉平成列向量——需要保形时先 `find` 再用下标。
- `find` 滥用：只要值不要位置时直接逻辑索引（`v(v>0)`），别 `v(find(v>0))`。
- 字符串与 char 混用：旧 char 数组的 `'=='` 比较、strcat 的行为怪癖——新代码用 string（双引号）。
- reshape 后忘记列优先顺序：形状对但数据「乱序」；先 `A(:)` 想清楚展开序。

## 7. 小结

- 六族创建：手工括号、冒号（知道步长）、linspace（知道点数）、zeros/eye（预分配与单位阵）、randn（仿真）、拼接 `[A B; C D]`/cat/repmat。
- 三种索引：下标+end（几何位置）、线性（列优先展开序）、**逻辑索引（按条件说话——MATLAB 最惯用的过滤与替换形态）**。
- 修改纪律：先预分配再填充，`[]` 删除，越界扩展是性能陷阱。
- 形状族：size/numel 观察、reshape 重排（列优先）、`.'` 纯转置（与 `'` 共轭转置区分）、squeeze/repmat 服务多维。
- 元胞花括号解包、圆括号保容器；结构体点字段、数组化汇总。

## 8. 练习

**1.** 不运行代码预测 `linspace(0,1,5)`、`0:1/4:1`、`0:2:7`、`10:-3:0` 的输出，再验证——特别关注端点是否包含。

> [!TIP]
> 思路linspace 必含两端（11/5 皆然）；冒号在浮点步长下端点「尽力包含」但受舍入影响（`0:0.1:1` 的最后元素可能是 0.9999…）。需要「含端点」语义时 linspace 更稳。

**2.** 用一条语句把矩阵 `A` 中所有偶数元素替换为 -1，再用另一条语句统计正数元素的个数。只用逻辑索引。

> [!TIP]
> 思路`A(mod(A,2)==0) = -1;` 与 `n = sum(A(:) > 0)`。逻辑矩阵参与算术时自动转 0/1——`sum(条件)` 即计数，是 MATLAB 统计惯用法的基石。

**3.** 把 1×12 向量分别 reshape 成 3×4、4×3、2×6，验证三个结果的元素排列都符合列优先；再用 reshape 复刻 `A(:)` 的行为。

> [!TIP]
> 思路`reshape(1:12,3,4)` 的第 1 列是 1 2 3——列优先填充。「reshape 不搬数据只改视图形状（内存序不变）」的理解让多维数组操作不再神秘。

**4.** 构造 5×5 随机矩阵，完成：取出对角线元素、把对角线置零、找出每列最大值所在行（max 的双输出）、翻转左右。

> [!TIP]
> 思路`diag(A)`、`A(1:size(A,1)+1:end)=0`（线性索引步长 n+1 的对角线！）、`[v, r] = max(A)`、`fliplr(A)`。对角线的线性索引公式是「索引代数」的好练习。

**5.** 用 meshgrid 计算并可视化二维高斯函数 `exp(-(x²+y²)/2)`：生成网格、计算、surf 出图。

> [!TIP]
> 思路`[X,Y]=meshgrid(-3:0.1:3); Z=exp(-(X.^2+Y.^2)/2); surf(X,Y,Z)`。meshgrid 是「二维公式的向量化」的标准入口——配合逻辑索引可以再做一个「只画 |Z|>0.5 区域」的变体。

**6.** 讨论：元胞数组与结构体数组的选择标准。给出三个场景（一批不同长度的信号、一批带名字的学生记录、一个函数的多返回值打包），各自该用哪个、为什么。

> [!TIP]
> 思路异构无字段 → cell；带名字字段 → struct；「同构多值」其实考虑数值矩阵或 table。cell 是「自由容器」、struct 是「带模式的数据」——有 schema 就 struct，schema 会演化就 table。

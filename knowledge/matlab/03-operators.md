MATLAB 的运算符有两套：**矩阵运算**（默认，按线性代数规则）和**点运算**（逐元素）。用错不会报错，只会得到一个"看起来也像样"的错误结果——这是 MATLAB 最阴险的静默错误，必须第一天就分清。

## 矩阵运算 vs 点运算

`*` 是矩阵乘法，内维必须匹配；`.*` 是逐元素相乘，要求尺寸一致：

```matlab
A = [1 2; 3 4];   b = [10; 20];
A * b          % 矩阵乘法 (2×2)(2×1) → 2×1
A .* A         % 逐元素乘 → [1 4; 9 16]
A ^ 2          % 矩阵幂 = A*A
A .^ 2         % 逐元素平方 → [1 4; 9 16]
```

> [!WARNING]
> 逐元素运算遇到向量时最容易翻车：`(1:5) * (1:5)'` 是内积（标量 55），`(1:5) .* (1:5)` 才是逐元素乘。行向量乘列向量的方向差一个 `'`，结果从标量变矩阵——报错还好，不报错地算出错误维度才是事故。

速查表，写代码时对号入座：

| 符号 | 名称 | 规则 |
| --- | --- | --- |
| `*` | 矩阵乘 | (m×k)·(k×n)，内维匹配 |
| `.*` | 点乘 | 同尺寸逐元素相乘 |
| `/` | 矩阵右除 | 解 x·B=A（少用，见[线性代数与统计](08-linear-algebra.md)） |
| `./` | 点除 | 逐元素相除，`1./x` 是每个元素取倒数 |
| `\` | 矩阵左除 | 解 A·x=b，MATLAB 的招牌 |
| `^` / `.^` | 幂 | 方阵自乘 / 逐元素幂 |

逐元素运算在 R2016b 之后支持**隐式扩展**（自动广播）：尺寸不匹配但兼容时自动复制补齐。

```matlab
A = rand(4, 3);
A - mean(A)          % 每列减去该列均值：1×3 广播到 4×3
A ./ vecnorm(A)      % 每列除以列范数（R2017b+），列归一化
```

旧版本要写 `bsxfun(@minus, A, mean(A))` 才能实现同样效果。读老代码认得它，写新代码直接用广播。

## 关系与逻辑运算

比较运算符返回**逻辑数组**（true/false），配合掩码索引威力巨大：

```matlab
x = [1 5 9 12 3];
x > 5                % [false false true true false]
x(x > 5)             % [9 12]，筛选
sum(x > 5)           % 2，计数
find(x > 5)          % [3 4]，返回线性下标
```

逻辑运算符分两档：`&` `|` `~` 逐元素作用于数组；`&&` `||` 是短路求值，**只接受标量**：

```matlab
% (x > 0) && (x < 10)      % ❌ && 接到向量直接报错
all(x > 0) && numel(x) > 0 % ✅ 先把数组归约成标量，再交给 &&
```

> [!TIP]
> 记忆法：`&&`/`||` 为 if 条件而生（标量真假、短路省计算），`&`/`|` 为数组而生（逐元素出掩码）。写混了要么报错要么埋雷。

浮点数用 `==` 判等是经典错误：

```matlab
0.1 + 0.2 == 0.3                 % false！二进制浮点误差
abs(0.1 + 0.2 - 0.3) < 1e-12     % ✅ 容差比较
```

精确判等用 `isequal`（连 NaN 都不等），带容差用 `ismembertol` / `isapproximately` 一类工具，视场景选择。

## 掩码思维

把"循环 + if"翻译成一行掩码，是判断 MATLAB 功力的分界线：

```matlab
%% ❌ 循环找并处理
y = zeros(size(x));
for k = 1:numel(x)
    if x(k) < 0
        y(k) = -x(k);
    else
        y(k) = x(k);
    end
end

%% ✅ 掩码一次完成
y = x;              % 或直接 y = abs(x)
y(x < 0) = -x(x < 0);
```

`any` / `all` 负责把逻辑数组归约成标量：`any(x > 0)` 有正数吗，`all(x > 0)` 全是正数吗，都能按维度操作。掩码的性能细节与陷阱见[稀疏与性能](09-performance.md)。

## 字符数组与字符串

MATLAB 有两套文本类型，单引号与双引号不是风格差异，是**两种类型**：

```matlab
c = 'hello';          % 1×5 char 数组：本质是字符行向量
s = "hello";          % 1×1 string 标量（R2017a+）
arr = ["a", "bb"];    % 1×2 string 数组：文本的"向量"
```

| | 字符数组 `'abc'` | 字符串 `"abc"` |
| --- | --- | --- |
| 本质 | 字符行向量 | 独立的 string 类型 |
| 取长度 | `length(c)` | `strlength(s)` |
| 拼接 | `[c1 c2]`，要求行数一致 | `[s1 s2]` 组成数组；`s1 + s2` 连接内容 |
| 批量操作 | 要靠 cellstr 绕 | `contains`/`split`/`join` 原生向量化 |

新代码优先用 string：函数面向数组设计，处理一批文件名、一批标签时不用循环：

```matlab
files = ["a.csv", "b.csv", "c.csv"];
contains(files, '.csv')           % [true true true]
parts = split("2024-09-13", "-")  % ["2024" "09" "13"]
n = strlength(["ab"; "cde"])      % [2; 3]，按元素取长度
```

数字与文本互转：`sprintf('x = %.2f', 3.14159)` 格式化输出；`str2double("3.14")` 文本转数值。

> [!WARNING]
> 别用 `str2num` 转数字——它内部调用 eval 执行文本，处理来源不明的数据有注入风险，错误信息也难读。一律 `str2double`：逐个解析、安全、失败返回 NaN 而不是炸掉脚本。

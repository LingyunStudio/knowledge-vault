MATLAB 的运算符设计只有一条主线：**数学（矩阵）语义是默认，逐元素语义加个点**。`A*B` 是矩阵乘法、`A.*B` 是逐元素乘法——一个点号区分两个世界。这条主线背后是 MATLAB 的出身：让线性代数的书写直接可执行。

## 1. 两套算术：矩阵语义与逐元素语义

| 运算       | 矩阵（默认） | 逐元素（加.） | 说明                          |
| ---------- | ------------ | ------------- | ----------------------------- |
| 加/减      | `A + B`      | 同            | 加减本身逐元素（形状须一致）    |
| 乘法       | `A * B`      | `A .* B`      | ★ 线代乘法 vs 对应元素相乘      |
| 除法       | `A / B`      | `A ./ B`      | `A/B = A*B⁻¹`（右除）          |
| 左除       | `A \ B`      | `A .\ B`      | `A\B = A⁻¹B` —— 解方程的主角    |
| 幂         | `A ^ 2`      | `A .^ 2`      | 矩阵幂（A×A）vs 每元素平方      |
| 转置       | `A'`         | `A.'`         | 共轭转置 vs 纯转置              |

维度匹配规则：

```matlab
A = [1 2; 3 4];   % 2×2
b = [10; 20];     % 2×1
A * b             % 2×1：矩阵乘法（内维匹配 2=2）
A .* b            % ❌ 2×2 与 2×1 逐元素 —— 除非 b 也是 2×2

% ★ 标量与任意矩阵：两种语义都自然（标量扩张）
2 * A             % 每元素 ×2
A + 1             % 每元素 +1
A .^ 2            % 每元素平方 —— 逐元素幂最常见的用途
```

**隐式扩张**（implicit expansion，R2016b+）：形状不同的数组在逐元素运算时自动按需复制对齐——`A + [1 2 3]`（每行加同一行向量）合法。这消灭了大量 `bsxfun`/repmat 样板，但也让「形状写错」从报错变成「悄悄算了错的东西」——**逐元素运算前打印 size 的习惯比以往更重要**。

### 1.1 两种语义的真实分工

```matlab
% 例：直线 y = kx + b 对整个 x 向量求值 —— 逐元素
k = 2; b = 1; x = 0:0.1:10;
y = k .* x + b;           % 每个点都算一遍 —— 点号是「对每个元素」的记号

% 例：对角矩阵的平方 —— 矩阵语义
D = diag([1 2 3]);
D^2                       % D*D（仍是 diag(1,4,9)）
D.^2                      % 同结果（对角阵特例）—— 非对角阵就分道扬镳了
```

判读口诀：**看到向量/矩阵参与、意图是「每个元素」→ 点号；意图是「线性代数变换」→ 不点**。读别人的代码时，一个没有点号的 `*` 必须先问「这里真的是矩阵乘法吗」。

## 2. 函数的矩阵化：默认逐元素

MATLAB 的数学函数**天然接受数组并逐元素作用**——这是「一切皆矩阵」模型的红利：

```matlab
x = linspace(-3, 3, 200);
y = exp(-x.^2) .* sin(5*x);    % 一行 = 200 个点的高斯调制正弦
abs(A);  sqrt(A);  round(A);   % 全部逐元素

% 比较运算也逐元素 → 产出逻辑矩阵（逻辑索引的原料，[第 2 篇](02-matrices.md)）
mask = (x > 0) & (x < 1);      % 区间掩码
y(mask)                        % 取出区间内的点

% 汇总函数沿某个维度：
sum(A);  sum(A, 2);            % 各列和 / 各行和（dim=2）
mean(A); max(A, [], 2);        % 列均值 / 每行最大值
```

`sum/mean/max` 的 **dim 参数**（1 = 沿列压成行，2 = 沿行压成列）是「矩阵化统计」的开关——想清楚「沿哪个维度压」是列优先模型下最容易迷糊的点，打印 `size` 验证。

## 3. 逻辑运算的三层

| 层       | 运算符        | 收什么       | 用途                          |
| -------- | ------------- | ------------ | ----------------------------- |
| 逐元素   | `&`、`\|`、`~` | 数组（推荐） | 构造掩码 → 逻辑索引            |
| 短路     | `&&`、`||`     | **只收标量**  | if/while 条件的链式判断        |
| 三值     | `&&`/`\|\|` 短路 | —            | `exists && check()` 防空指针式 |

```matlab
if nargin > 1 && opts.verbose     % && 短路：第一条件假则不算第二个
    ...
end

mask = (A > 0) & (A < 100);       % 掩码构造必须用单 &（矩阵不能短路）
% ❌ if (A > 0) && ...：A 是矩阵时 && 直接报错 —— 短路版只吃标量
```

`&&`/`||` 与 `&`/`|` 的区分是 MATLAB 的强制纪律：**条件语句（标量真假）用短路段、掩码构造（数组）用元素段**。把「any/all」当作桥梁：`if any(mask)` 把数组判定折叠成标量。

## 4. 浮点比较：== 的陷阱

MATLAB 是 IEEE 754 双精度（与[C 篇](../c/02-types.md)、[Python 篇](../python/02-data-model.md)同一套浮点现实）：

```matlab
0.1 + 0.2 == 0.3                  % false —— 与所有语言一致
0.1 + 0.2 - 0.3                   % 5.55e-17：误差在 eps 量级

abs(x - y) < tol                  % 手工容差
isequal(round(x*1e10), round(y*1e10))   % 量化后比较
% MATLAB 内建：等价容差比较（推荐）
isequaltolerant = @(a,b) all(abs(a(:)-b(:)) <= 1e-10 * max(1, abs(b(:))));
```

浮点陷阱的 MATLAB 特有现场：**循环累加求和的顺序**（`sum` 有向量化的内部优化路径）、**整型数组运算**（int8 相乘会饱和/报错且不像 double——数值计算保持 double，仅在图像/接口处转 int）。

## 5. 集合运算：unique 与 ismember

```matlab
unique([3 1 2 3 1])               % [1 2 3] —— 去重+排序
unique(v, 'stable')               % 保持出现顺序的去重
a = [1 2 3]; b = [2 3 4];
intersect(a, b)                   % 交集 [2 3]
union(a, b)                       % 并集；setdiff(a, b) 差集 [1]
ismember([2 9], a)                % [1 0] —— ★ 批量「在不在」：逻辑索引的常客
data(ismember(data.ID, blacklist), :)   % 筛出黑名单 ID 的行（表/矩阵通用）
```

`unique` 的双输出（`[u, ia, ib] = unique(v)`）给出「去重后元素在原数组的下标」——分组统计（配合 accumarray）与「类别编码」的原料。`ismember` 的掩码用法是数据筛选的高频组合。

## 6. \：MATLAB 的招牌（预览）

```matlab
x = A \ b;        % 解线性方程组 Ax = b —— 一个符号背后是完整的高斯消元/分解调度
```

`/`（右除）与 `\`（左除）是「乘以逆」但**从不显式求逆**——它们根据矩阵形状自动选择 LU/QR/Cholesky/最小二乘路径，数值稳定性远好于手写 `inv(A)*b`。完整的机制与选型在[第 8 篇](08-linear-algebra.md)。

## 7. 陷阱清单

- 该点的没点（`A*B` 想逐元素）：形状巧合时静默算出错的结果；尺寸打印是自检习惯。
- `A'` 共轭：复向量转置用 `.'`。
- `&&` 收到矩阵：报错；条件折叠用 any/all，掩码构造用 `&`。
- 隐式扩张掩盖形状 bug：R2016b 后「尺寸不匹配」不再总是报错；关键运算前 assert(isrow(x)) 类断言。
- 浮点 ==：容差比较或 isequal 量化；涉及「和恰好等于某值」的判断一律可疑。
- sum/mean 的 dim 弄反：打印 size 验证「压成了什么形状」。
- 整型数组混入计算链：溢出与饱和语义；数值管线保持 double，边界处转换。

## 8. 小结

- 一条主线：矩阵语义默认、逐元素加点号；`./ .^ .'` 与 `* / ^ '` 成对出现，读写都要先分清「哪个世界」。
- 隐式扩张（R2016b+）让异形逐元素运算合法——便利与「形状静默出错」并存，size 自检更必要。
- 函数矩阵化是默认：数学函数、比较运算都逐元素，产出逻辑矩阵喂给逻辑索引；汇总函数的 dim 参数管「沿哪个维压缩」。
- 逻辑运算三层：`&|~` 造掩码（数组）、`&&||` 短路（仅标量）、any/all 做折叠。
- 浮点比较永远容差化；集合运算 unique/ismember/intersect 是数据筛选的代数工具。
- `\` 是「解方程」的专用符号——背后是数值稳定的标准算法调度（第 8 篇展开）。

## 9. 练习

**1.** 构造 A 为 2×2、b 为 2×1，分别执行 `A*b`、`b'*A`、`A.*b'`（说明哪个对、为什么对、各是什么形状）；再故意执行 `A.*b` 观察（R2016b+）隐式扩张的结果与直觉的偏差。

> [!TIP]
> 思路`A*b` 是矩阵乘（2×1）；`b'*A` 是 1×2 行向量（行乘矩阵）；`A.*b'` 是逐元素乘 2×2。隐式扩张会把 b' 扩张成 2×2 再逐元素——「碰巧能算」正是它危险的地方。

**2.** 用一条逻辑索引语句把 `x` 中所有 |x| < 0.5 的元素替换为 0；再用 find 版本实现同一件事，对比两种写法的可读性与速度（大数组计时）。

> [!TIP]
> 思路`x(abs(x)<0.5) = 0`；find 版 `x(find(abs(x)<0.5)) = 0`。逻辑索引版免一次下标物化，通常更快——且读起来就是「把小的置零」。

**3.** 实现「分段函数」：y = sin(x) 当 x<0、y = x² 当 x≥0，分别用逻辑索引两次赋值与一个循环实现，验证一致性并比较行数。

> [!TIP]
> 思路`y=zeros(size(x)); y(x<0)=sin(x(x<0)); y(x>=0)=x(x>=0).^2;`——三行向量化 vs 七行循环。分段函数的「掩码分区赋值」模板是 MATLAB 向量化的入门标本。

**4.** 验证浮点陷阱：累加 0.1 一万次与 1000 比较；`sum(0.1+0.2)` 类的组合；用容差方案修正。再比较 `sum(v)` 与循环累加的结果差异（顺序效应）。

> [!TIP]
> 思路累加顺序影响舍入误差（[C 篇第 2 篇](../c/02-types.md)的 Kahan 思想同样适用）。MATLAB 的 sum 对大数组有内部成对求和优化——「同一数学运算不同实现」的误差可以不同，比较浮点必须带容差。

**5.** 用 unique 的三输出给一组标签向量做「类别编码」：labels → 编号向量 code 与类别表 u，验证 code 的取值范围与 u 一一对应。

> [!TIP]
> 思路`[u, ~, code] = unique(labels)`——类别编码的通用手法（机器学习预处理的常客）。反向还原：`u(code)`。这个练习把「集合运算 + 索引代数」串成一个实用组件。

**6.** 讨论：为什么 MATLAB 把「矩阵乘法」设为默认而让逐元素加点？如果反过来（默认逐元素、矩阵乘另设符号），常见的数值代码会变成什么样？从目标用户（工程师而非程序员）的角度分析。

> [!TIP]
> 思路工程师读 `A*b` 期望线性代数语义（公式直译），逐元素反倒是特例。语言默认值的取舍 = 目标用户最高频心智模型的映射——这个设计判断与 Python 用缩进而非花括号是同构的。
